# MAX-STRUCT-R1 数据与物理合同

2026-11-02，首次数值运行前冻结于 `configs/initial_plan.json`。本轮机制开发锚点公开，全部标 `OFFLINE_DIAGNOSTIC`；它们不是盲成像确认集。历史数字不重算。若没有 M/T 扩展资格，`sealed_truth/` 与 `predictions/` 不伪造盲测产物。

时间因子 exp(−iωt)，λ₀=1，ε_b=μ_b=1，k=ω=2π，阻抗归一化 Z₀=1。长度单位 λ₀；E、H 以单位入射场/相应背景阻抗归一化；相对极化密度 j=(ε_r−I)E，电偶极矩 p=vj，归一化物理对比电流 J=−iωj。j 与 J 不混用。互易性是 εᵀ=ε；被动性是 Im_H ε≥0，且 Im_H ε⁻¹≤0。

三维适配使用出射 dyadic Green 和 CM/RR 自项的 DDA；它是有限近似模型。自项为 G_ii=−I/3+i k³v I/(6π)，非对角 G_ij=v(k²I+∇∇)exp(ikr)/(4πr)。内部 E 满足 E=Einc+Gj，另有激发场 Eexc，不能混用。无 PML：辐射由无限均匀背景出射核实现，PML 反射项为不适用；有限体素积分及曲面体素化误差仍存在。

源为外部合法横向平面波 d·p=0，未知域不含外加电流。接收器在已知背景中，近场全部矢量分量与远场切向幅度分别保存；有限近场矩阵不用于冒充单调性 far-field operator。

公开观测合同只允许 case_id、网格/几何、频率、源参数、接收/通道、背景、Y、噪声/校准、材料集合和公开 prior。开发锚点单独存 `data_public/dev_anchors/` 并明确披露。未来未知目标的真值只由独立生成/评分进程访问；本轮没有将公开锚点改名为未知目标。

F 线允许逐体素实对称 SPD 或复对称严格被动张量，另审已知轴对角/块常交集。空间 smooth bump 限制方向，仅是公开开发构造。公开本轮张量 box 为实部主值[1,5]、损耗主值[0,1]；复被动开发锚点与分支另保留严格正损耗裕量。所有分支保持同一材料类与 box；损耗与实部主值分别检查。报告张量 RMS Frobenius 距离（各点 Frobenius 平方平均后开根），实部/损耗分别列，归一化幅度固定为 1。无合法二值 support 任务，不报告 IoU。

F 噪声采用预声明有界球：每个复观测的幅度尺度 σ=0.001，W=I/σ，m 个复数据上的白化半径 ε_noise=√m。该球是确定性合同，不是 CN 噪声的高概率门；不得称 95% 覆盖。若做 Gaussian 扩展须用实/虚方差 σ²/2、2m 实维和相应 χ² 分位数重写。候选对距离≤2ε_noise 只保证噪声球可能相交；实际 y 还须各自满足 discrepancy。保持相同完整 Φ=.5||W(F−Y)||²+R，R=0（合法集合指示函数另计）。辅助目标不是 Φ。

F 只保留合法候选集合，不按 GT 排名。主动照明依据候选完整 transfer 差；新实测数据若执行，必须由独立生成端产生并提供给兼容成熟基线。候选库包含性未经证明，故预测最优源仅为候选内保证。

成本分 setup / online / validation / scoring。CPU/wall 为实际计时，worker wall 相加只叫进程耗时之和。LU、forward RHS、线性三角 RHS、Green 动作、小 SVD、FFT、椭圆解分别记录；未知字段 null+原因。无计费 API 定价访问，货币费用未知，不写零。无 SHA 验证；运行 code_hash/config_hash 设 null 并指向源码与冻结配置。
