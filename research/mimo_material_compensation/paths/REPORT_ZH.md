# 原生带噪观测允许的有限面积连续材料变化

两套原始布局 A 都允许把一整块原本归零的区域连续增亮。严格核验覆盖整段材料折线及其中每个未采样的材料配置。另一项固定点证书给出精确等复读数的连续曲线，证明的幅度小得多。原 B 的同一份带噪数据也允许零区和大斑块两个重新拟合的物理解。

在两张固定的原生标称校准网络上，采用 400 MHz 二维标量 TM、24 个 50 Ω 端口、独立实对比度 0 到 4.5 和原封存的复 Frobenius 球。A 或 B 各使用 8 次照明、64 个复读数，每次 0.125 W，源列可用功率共 1 W。源驻留时间未提供。原测量指保存在发布数据中的、已扣除空场并带噪的复端口观测。两套原生网格为不同对象。

## 精确等读数的固定点曲线

- `n32_c01` 的固定连接斑块在精确校准存储系数下保持复读数 F(x₀) 不变，严格幅度为 0 到 1.52588e-05。收缩上界 0.292259，外区材料余量占用上界 0.0016487。 [n32_c01 证书](n32_c01_exact_chart.json)
- `n96_c01` 的固定连接斑块在精确校准存储系数下保持复读数 F(x₀) 不变，严格幅度为 0 到 1.52588e-05。收缩上界 0.283212，外区材料余量占用上界 0.0050817。 [n96_c01 证书](n96_c01_exact_chart.json)
- `n32_c01` 允许任务区形状自由。数据雅可比选出的形状方向在各任务格介于 0.25 和 2.5，整区实际变亮。172 格任务区均值严格连续到 1.52588e-05，所有原复读数等于锚点。 [均值任务等场证书](n32_c01_exact_shape.json)
- `n96_c01` 允许任务区形状自由。数据雅可比选出的形状方向在各任务格介于 0.25 和 2.5，整区实际变亮。156 格任务区均值严格连续到 3.05176e-05，所有原复读数等于锚点。 [均值任务等场证书](n96_c01_exact_shape.json)

降阶计算使用原生锚点、全波支撑反馈和真实端口。端点电流、逆、接收伴随沿每段分别插值，保留材料变化与场变化的二阶交叉项。接收修正后的三次 Bernstein 系数保留复数正负方向，最后才取范数并加向外误差。精确等场管单独包围雅可比提升缺陷、切向缺陷、方向二阶反馈和横向余量。

## 原 B 和 A+B 重拟合

原 B 的同一份封存观测同时允许零区和 43 个连接斑块像素逐格不低于 2。两个严格残差上界分别为 0.770145 和 0.532545 倍 B 半径，全区均值为 0 和 2.65633。相对两端点的外区变化 L¹、L²、L∞ 分别为 3.62568、2.76188、4.5。旧研究的 B 真空搜索停在约 4.51 倍半径，这一较长的独立重拟合找出了球内材料。

同一对材料复查 A 的残差下界分别为 12.8449 和 12.6328 倍 A 半径。B 的另一条固定斑块折线严格覆盖均匀振幅 0 到 0.368164，包含 17 段，最大段残差上界 0.95368 倍 B 半径。

先封存 B 的两个材料，再用未参与求解的原 A 发射列与另外 8 个接收端口评分。两份材料的留出残差下界为 19.2005 和 21.7556 倍留出半径。这个独立留出结果只评分这里实际找到的两份材料。 [材料与留出复波形](B_refit_shapes.png) · [留出核验](B_independent_held.json)
