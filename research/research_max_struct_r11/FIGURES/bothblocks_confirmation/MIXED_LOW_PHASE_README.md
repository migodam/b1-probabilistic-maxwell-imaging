# Mixed low-phase display supplement

Both files cover every one of the8 mixed objects and every one of the5 frozen methods. No success-based filtering, new gate, solver or forward was used.

`MIXED_LOW_PHASE_SCALE_0_3p5.png/.pdf` is a low-phase visibility view. Orange means **all values above3.5 are saturated**; true high contrasts12/18 are deliberately not distinguished. It is not a replacement for the preserved quantitative0–20 plates. Color clipping changes only display, not data or the RMSE/mean labels.

`MIXED_LOW_REGION_RMSE_AND_MEAN.png/.pdf` directly plots the existing finite-noise/prior audit CSV. Each object group shares the same truth-low mask chi=2.5. RMSE is absolute chi error on those cells; means near2.5 do not certify spatial fidelity. All40 method-object pairs are included. Median values and provenance are in MIXED_LOW_PHASE_METRICS.json and the timing receipts.
