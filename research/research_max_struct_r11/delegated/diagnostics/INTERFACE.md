# R11 fixed-state diagnostic interface

Inputs are the ten real stage endpoint arrays listed in STATE_INVENTORY.json. Main objects are R10 `0001` annulus, `0004` slotted shell and `0022` bridge, using `matrix_green19`; confirmation objects are `r10_conditional_0000` annulus and `0003` coated inclusion using `conditional_fallback_G19_PGP`. All ten requested endpoints exist: stage 0/mf3 and stage 3/mf12.

`stage_XX_joint.npz` stores `m:(576,) float64`, `J,Q:(576,12) complex128`, `A:(nFourier,12) complex128`. The callback in R8 `experiments/run_case.py` writes this after the final material update in each stage. `Q=E+GJ` is tied to the saved auxiliary J; m is already updated. There is no saved same-state next material array. Later stage arrays contain intervening current iterations and cannot be called an observed next step. The diagnostic will propose a fresh fixed-current readout from each endpoint.

`SOURCE_METRICS.npz` stores diagonal `state_weights` and `data_weights`, each length 12. Use `Os=diag(state_weights)`, `Ls=diag(sqrt(state_weights))`, `rho=1`. Material bounds are [.02,20]. beta is read from each endpoint JSON, not inferred from mf. Physical Phi and gradient use R8's original inherited `MaxwellModel.data_value_gradient(m,Y)` with its matched regularizer. Raw Phi is normalized by `||Y||²`, not public noise sigma. The numerical schedule preserves beta_current=1 and beta_material=1 at stage0, .2 at stage3 for these G19 paths.

`DENOMINATOR_BASIS.npz` provides `U:(576,19)` and `B:(576,19)` with K=B U*. These paths use projected G19 PGP, not full-rank G. `LowRankDenominator.factor(m,beta)` returns a diagonal-plus-small-LU Woodbury factor and `.solve(factor,rhs,adjoint=True)` applies A^-*. `value_gradient` implements both derivative terms. The root's R11 `material_readouts.py` will define full and lagged candidate generation. Same J,Q,m,beta,Os,rho,box/prior are used for ordinary/full/lagged counterfactuals. GT will be opened only after candidates are generated and saved; labels are OFFLINE_DIAGNOSTIC and do not select steps/rules.

Gradient decomposition at each common starting m: e=J-diag(m)Q, w=A(m)^-1 e, a=A(m)^-*(w Os), g_const=-rho beta² Re sum conj(a)Q, g_metric=-rho beta² Re sum conj(a)(beta I-K)w. The prior is logged separately; full total=g_const+g_metric+g_prior, lagged total at reference=g_const+g_prior. Record norms, mutual cosine, physical-gradient alignment and box projection separately to avoid hiding cancellation.

The saved original R10 three-case interpretation distinguishes wrong-data stopping domains, budget-limited cases and noise-compatible material bias; this diagnostic does not presume denominator gaming. In particular 0022 Twofold maxed iterations while G19 stopped by relative-F with PG above 1e-8. Original 0004 G19 stopped by projected-gradient criterion but high data residual. Original 0001 G19 performed well. Those trajectory observations remain separate from local fixed-state counterfactuals.
