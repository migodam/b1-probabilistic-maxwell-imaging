Run a fullGreenBothBlocks task with `diagnose_bothblocks_run.py --manifest <manifest> --config <solver-config> --task-id <id>`. The wrapper changes only this process's `benchmark_solver.run_cie_fft` to `cie_feedback_current.run_cie_fft`, then delegates to `twod_run.main`. Therefore it MUST be selected only for the BothBlocks task. Ordinary CIE/Dual/Global and material-only fullG19 tasks use ordinary `experiments/twod_run.py`. Output must be a new directory under R11 RESULTS. The matrix operator is prepared from public G/S with frozen .1 Green threshold and G19 PGP basis. No family, seed, truth, clean data or support is an inverse input.
