## 1. 纤维判据：先区分三个层次

### 1.1 集合因子化

**ANALYTICALLY VERIFIED**。对任意集合映射 `F:Θ→Y`、`H:Θ→Z`，在 `F(Θ)` 上存在集合映射 `h` 满足 `H=h∘F`，当且仅当 `F(θ1)=F(θ2)` 蕴含 `H(θ1)=H(θ2)`。定义 `h(y)` 为任一满足 `F(θ)=y` 的 `H(θ)` 即可；纤维常值保证定义无歧义。此结果不需要微分、Maxwell 或概率结构。

`identifiability.tex:10–20` 对此定位正确：不自动得到可测性、连续性、Lipschitz 性、数值稳定性或新的 Maxwell 唯一性定理。后续若要推送概率、做 Bayes 决策，所用映射和核还需明确可测；一般集合因子化本身不能充当可测因子化证书。

### 1.2 导数核条件的正确逻辑方向

**ANALYTICALLY VERIFIED**。若在所讨论点附近，`F,H` 可微，且因子映射 `h` 具有足以使用链式法则的可微结构，则

`DH = Dh ∘ DF`，从而 `ker DF ⊆ ker DH`。

在有限维欧氏或明确加权 Hilbert 范数下，对固定线性映射 `A=DF`、`K=DH`，核包含等价于存在有限 `c` 满足 `||Kv||≤c||Av||`；最小常数是相容内积下的 `||K A†||`。这是单点线性代数结论，不是非线性纤维常值的充分条件。`A†` 必须和实际参数、数据及任务 metric 相容，不能直接使用坐标单位不同的未归一化矩阵。

**REQUIRES CORRECTION（任何不加正则性条件的必要性说法）**。取实数参数

`F(x)=x³`，`H(x)=x`。

`F` 单射，所以纤维判据成立，且 `h(y)=∛y` 是精确、连续的因子映射；在任意紧区间上它还一致连续，具有非线性稳定模数。然而 `DF(0)=0`，`DH(0)=1`，核包含在零点失败。因此：

- 精确集合任务可辨识，不蕴含导数核包含。
- 连续因子化或仅要求误差趋零的统一稳定性，也不蕴含该核条件。
- 若 `h` 局部 Lipschitz，则沿参数直线取差商可得 `||DH v||≤L||DF v||`，因而核包含成立；可微 `h` 是另一充分正则性条件。

原稿 `identifiability.tex:22` 已明确写出“若 F,H,h 可微”，故该处不是无条件错误。建议紧接该句加入上述立方反例，防止摘要、讲解或后续算法把“可微因子化必要条件”缩写为“任意可辨识性的必要条件”。可将“稳定”明确拆成连续模数稳定与 Lipschitz 稳定。

### 1.3 恒秩条件如何把局部线性条件积分起来

**ANALYTICALLY VERIFIED**。在有限维光滑参数域的一个内点邻域内，若 `F,H` 为 `C¹`，`DF` 在整个邻域恒秩，且每一点都满足核包含，则可缩小到常秩坐标图，使 `F` 只依赖前 `r` 个坐标。`H` 沿余下纤维坐标的导数为零；取连通的小纤维切片后，`H` 在每个切片上常值，得到局部 `C¹` 因子化。需强调“局部坐标图内的连通纤维片”，并不等价于整个邻域任意不连通纤维分支自动相同。

同样，若 `v∈ker DF(θ0)` 而 `DH(θ0)v≠0`，恒秩定理提供通过该内点、切向为 `v` 的局部精确等数据曲线。`identifiability.tex:45–56` 的证明正确。

**CONDITIONALLY DERIVED / UNTESTED（实际材料应用）**。报告尚未为不规则有限墙、共享色散材料、被动性边界或拓扑变化验证恒秩、严格核及内点条件。微小非零奇异值不是精确核；单点零导数也不够，`F(t)=t²` 在零点说明这一点。满列秩 Jacobian 不能被解释成存在正维 exact fiber。

## 2. 四块传播对象及非交换乘法顺序

**ANALYTICALLY VERIFIED**。在共同离散场空间、固定参考介质、固定任务注入和相同 nuisance 下，令

`L_X=L_W−U V U*`, `G=L_W⁻¹`, `d=b+RGQ`, `A=RGU`, `B=U*GQ`, `C=U*GU`。

假定所用逆存在，则消去任务域场，得到

`F_X=d + A V (I−C V)⁻¹ B`。

必须保留 **`V(I−CV)⁻¹`** 的顺序。等价形式是 `(I−VC)⁻¹V`；一般不能写成 `(I−CV)⁻¹V` 或 `V(I−VC)⁻¹`。不要求 `V` 可逆，也不要求 Neumann 级数收敛。

对共同目标 `V`，定义 `Ti=V(I−Ci V)⁻¹`，则

`T1−T2=T1(C1−C2)T2`。

因此在相容算子范数下，若目标类上统一满足 `||V||≤v`, `||(I−CiV)⁻¹||≤β⁻¹`, `||Ai||≤a`, `||Bi||≤b`，有

`||F1−F2|| ≤ δd + bv δA/β + av δB/β + abv² δC/β²`。

`probability.tex:24–53` 的顺序和界正确。`β>0` 必须覆盖两个环境及整个声明目标类，而非只在一组探针或一个 reduced core 上测得。共振附近该界可发散；有界体对比证明不自动覆盖 PEC 或改变实体边界的更新。相同四块是任务等价的充分条件，任务类看不到的自由度使其未必必要。

**CONDITIONALLY DERIVED / UNTESTED**。P0A 没有测得有限墙四块签名的压缩误差、统一 `β`、连续目标类覆盖率或低成本证书。因此当前只能保留条件推导，不能据此宣布强目标传播已安全压缩。

## 4. 后验 TV 界：正确，但不是无条件压缩证书

**ANALYTICALLY VERIFIED**。假设 `Φ, Φ̃` 可测，两个后验在同一个参数空间与同一个联合先验 `π0(dW,dX,dγ)` 上定义，正规化常数有限且为正，并且先验几乎处处有 `|Φ−Φ̃|≤ε`。则

`e^(−ε) ≤ Z̃/Z ≤ e^ε`, `e^(−2ε) ≤ dμ/dμ̃ ≤ e^(2ε)`。

以 `TV=sup_A |μ(A)−μ̃(A)|` 为约定，利用密度比期望为 1，可得保守界

`TV(μ,μ̃) ≤ tanh ε`。

补遗 A 的割线证明正确；`ε=0` 时按连续极限为 0。该常数没有被声称最优，审查无需为此另立更强命题。边缘化、可测任务推送及同一个预测核收缩 TV；`0≤ℓ≤L` 时损失期望差不超过 `L tanh ε`。若预测核本身也近似，则需另计核误差，不能只引用这一收缩结论。

保持联合先验意味着代表环境 `c(W)` 只改变 likelihood 的前向计算；不能同时把原墙体先验质量、`π0(dX,dγ|W)` 或拓扑权重替换成代表点值。改变先验要另外计入 log-weight 误差；删去支持则要控制被删去的后验质量。小先验尾部不足以控制后验尾部。

若界只在 `C` 上有效且两后验给 `C` 正质量，则对条件后验应用同一论证，安全界为

`TV(μ,μ̃) ≤ μ(Cᶜ)+μ̃(Cᶜ)+tanh ε`。

若近似后验明确截断到 `C`，可用 `μ(Cᶜ)+tanh ε`。尾质量没有估计时只能给条件结论。有限候选库没有找到别的分支，不证明尾质量为零。

白化 Gaussian potential 的误差传递亦正确：若 `||F−F̃||≤δ` 且 `||y−F||≤R`，则

`|Φ−Φ̃|≤Rδ+δ²/2`。

有分支误差 `δb` 和数值误差 `δn` 时，应取 `δ=δb+δn`；逐项算数值项要用 `(R+δb)δn+δn²/2`，不可遗漏 `δbδn`。这些界要在声明支持上统一成立才可直接给 uniform TV 结论。

**CONDITIONALLY DERIVED / UNTESTED**。P0A 未运行联合后验、覆盖检查或任何 `δb,δn,R,β` 的统一估计。报告中的 TV 定理及条件先验警告是正确理论接口；后验可靠压缩、已校准模式概率及低尾风险仍无本次实验支持。
