# 实现修订与失败保留

1. 系统 Python 没有 NumPy，首次冻结命令未生成配置即退出；改用已经存在的 A25 科学环境。不是物理失败，也没有新增物理解。失败说明保留，未安装新的框架。
2. 中断后检查没有仍在运行的物理进程。一维结果与源输入继续复用，没有重置实验费用。
3. 最初稠密全域 Green 保存方案在执行二维求解前被改为 Toeplitz 核＋精确活跃材料块。只移除 ε−1 完全等于0的自由度，不按微小阈值丢材料。
4. `wall-grid-001` 已执行，最大宿主进程 RSS 约2.05 GB，超过原1.5 GB内存目标（不是科学gate）。随后改为分块组装 Fortran 矩阵、原位 LU 与分块算子残差，避免多个完整材料矩阵同时存在。`assembly-parity-001` 对保存的同一材料重算，数据完全一致；这次求解也计费。
5. 接收端采用源单元积分、入射端只取中心值会产生离散源/接收不对称。`reciprocity-001` 对同一墙交换四个源/接收位置，原相对缺陷3.49e−7；匹配单元平均的入射端后为7.20e−16。源物理位置/谱没有改变，修的是离散接口。原版本保留在 `results/qualification/`，修订版独立保存在 `results/qualification_source_average/`。
6. 匹配源接口后只重核最细两层网格和必要的参考/导数检查，不降低噪声、精度要求或修改物理见证门槛。尚未通过资格的结果不能用于搜索或宣布GO。

没有运行 A17 ROM、后验采样、学习、三维或额外场景。源ZIP未改写，没有做文件哈希或备份流程。所有真实LU/RHS执行前统一预约；失败和修复不退费。
