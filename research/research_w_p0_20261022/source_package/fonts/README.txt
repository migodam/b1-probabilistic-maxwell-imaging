Fonts for recompiling the Chinese report

The delivered PDF already embeds the needed glyphs.
Font binaries are not duplicated in this research package.

Place these two files in this directory before running build_report.sh:
  NotoSerifCJKsc-Regular.otf
  NotoSerifCJKsc-Bold.otf

Official project:
  https://github.com/notofonts/noto-cjk

Download paths used in this research run:
  https://raw.githubusercontent.com/notofonts/noto-cjk/main/Serif/OTF/SimplifiedChinese/NotoSerifCJKsc-Regular.otf
  https://raw.githubusercontent.com/notofonts/noto-cjk/main/Serif/OTF/SimplifiedChinese/NotoSerifCJKsc-Bold.otf

The project distributes the fonts under the SIL Open Font License.
Consult the upstream license before redistributing font binaries.
The report additionally uses DejaVu Sans Mono and standard TeX math fonts.
