四方法完整新保留集的原始执行命令

原执行：

python experiments/generate_quotient_holdout.py
python experiments/run_quotient_holdout.py --freeze
python experiments/run_quotient_holdout.py

生成/执行脚本为保全原证据会拒绝在已完成目录重跑。实际一次driver guard预物理修复及--freeze-repair收据保留；它未改变核心求解器或参数。当前发布中的private/是运行期间隔离、预测封存后才供评分/复现使用的真值，现在随完整证据公开；重新读取这些值的重放应称exposed replay，不能重新称fresh blind。

重新计算相同四方法比较，使用独立输出的重放入口，无需修改原freeze或删除原结果：

python replay_holdout.py --output-dir /tmp/zalg_replay_new

该入口只读取公开观测和冻结的初始化，调用原四种求解函数，输出独立的逐例候选、物理费用与集合对比。它不读取GT；发布后的重放仍应标识为EXPOSED_REPLAY。源文件size/mtime freeze是原进程隔离的审计记录，在他机复制后会变化；不要伪造原freeze来声称新盲实验。要产生新的真正盲研究，应重新冻结合同并生成未暴露数据。
