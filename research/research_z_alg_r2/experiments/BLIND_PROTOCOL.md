# Frozen observation-only benchmark

The public input boundary is `contract.json`, `public/manifest.json`, and the `y` array in each public NPZ. The two presets, material box, initial midpoint, no-noise setting, hidden sampling rule, three cases per preset, tolerances and baseline budgets were fixed before the hidden generator ran. A cryptographically generated private seed is stored only under `private/`; it was not printed, read into solver processes, or passed to the orchestrator.

`generate_private.py` executes in its own process and writes observations to the public folder and material truths to a separate private NPZ. Solver files import only physics, public input loading, and observation-only validation. The scorer is a separate private executable. It requires an external algorithm/run freeze receipt before computing any material error. Recovered material vectors are public solver output, never used as new GT or initialization.

The exact Full-J baseline uses SciPy bounded TRF with the analytic adjoint Jacobian at every accepted iterate. Source and receiver labels are retained. The frozen-J comparator uses the single analytic midpoint Jacobian. Both start at the constant box midpoint 2.25 and receive the same bounds, 120 residual evaluations, tolerances, linear loss and observed-data norm scaling. All supplied material coordinates remain variables. E1 is intentionally underobserved: response-fit success is separate from imaging accuracy and does not prove uniqueness.

Each endpoint receives an independent fresh dense solve through the same shared physics equations; validation does not reuse the optimizer state or fitted current. Setup includes Green construction and receiver SVD. Full forwards cost one RHS per source; transpose adjoint solves cost one RHS per receiver and are shared by all sources. Every operation logs wall/CPU and total complex RHS. Per-source forward/validation and per-receiver adjoint attribution are derived exactly from these logs. Tiny-system wall times are reported as measured; no speedup claim follows from fewer RHS alone. The run output includes all failures and SciPy stopping status. No old study is rerun.

The baseline and generator may be run once per frozen filename. Any repair or rerun requires a new explicit run identity and preservation of the previous result. The current metadata-only source attribution annotation does not rerun the physics or optimizer.

The blindness claim is computational and procedural: solver processes receive observation-only public data. The shared filesystem is not an operating-system security sandbox. The separate generator, post-freeze scorer and post-freeze plotting process can access truth; they do not pass truth arrays or seeds to solvers. Post-freeze images intentionally disclose material maps for review after predictions are immutable.
