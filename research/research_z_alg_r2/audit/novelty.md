## 1. 代数检查

令 D=diag(δ)，K∈C^(k×k)，L∈C^(1×k)，q∈C^(k×s)，rank(q)=s，测量 y∈C^(1×s)。在 det(I−DK)≠0 的开集，

```
w = L(I−DK)^−1D = LD(I−KD)^−1,
w(I−KD)=LD,
w=(L+wK)D=:vD,
wq=y.
```

因此任何非奇异物理解均给出满足数据的 w。反过来，若 wq=y、所有 v_i≠0，定义 δ_i=w_i/v_i；只要 det(I−KD)≠0，则由线性状态方程唯一性恢复原 rational forward map。这一双向证明没有 Born 或弱散射近似，但仅适用于已经冻结的有限离散模型。

q 满列秩使数据仿射空间具有复维 k−s。选行零空间基 N∈C^((k−s)×k)，Nq=0，写 w=w0+c^T N。定义系数共轭的独立仿射函数

```
ŵ(d)=bar(w0)+d^T bar(N),   ṽ(d)=bar(L)+ŵ(d)bar(K),
F_i(c,d)=w_i(c)ṽ_i(d)−v_i(c)ŵ_i(d).
```

F_i 的双次数至多 (1,1)。在物理对角 d=bar(c) 且 v_i≠0 上，F_i=0 当且仅当 δ_i=w_i/v_i 是实数。**独立复变量 d 不是自动等于 bar(c)**；求出的复解必须再检查该反全纯固定点条件及材料范围。

把系统解释为复代数对应时，须同时使用 v_i≠0、ṽ_i≠0 以及两个 resolvent 非奇异条件。此时 δ_i=w_i/v_i=ŵ_i/ṽ_i，把 (c,d) 与满足原数据方程及其系数共轭方程的复 δ 对应起来。物理对角上两个 resolvent 条件互为共轭，一个非零即可。严格术语可写“两个开集之间的双有理对应”；仅对物理解的叙述可写“实有理解集对应”。

### 零分母饱和会不会漏掉孤立物理解？

若某物理解有 v_i=0，则 w_i=δ_i v_i=0。固定这个 w，只改变 δ_i 为 δ_i+t，其他材料坐标不变，恒等式 w=vD 仍然成立。非极点条件是开条件，所以充分小的实 t 仍有唯一状态解且 wq 不变。这构成一条实等数据曲线。

因此，在各材料坐标可独立局部变化的真实参数域中，任何非极点孤立物理解必有全部 v_i≠0。具有非零宽度的独立闭区间边界也保留单侧曲线；零宽度固定坐标、离散材料字母表、坐标耦合先验或额外等式约束则必须另论。本结论不能用来声称所有正维分支也由当前饱和图册覆盖。

### 6 的含义与证明缺口

当 k=2s 时，c,d 各有 s 个复坐标，2s 个方程双齐次化后位于 P^s×P^s。标准多齐次 Bézout 数为

```
[x^s y^s](x+y)^(2s) = binom(2s,s).
```

s=2 时为6。该数是这类起始系统的路径数，以及目标系统**孤立复零点**的上界（按重数计入时需使用相应交数陈述）。有限物理解只是其中满足固定点、非极点和材料域条件的部分。它不是“恰好6个物理解”，也不证明这类受物理约束系数达到通用双线性系统的最大度。

“实根孤立”一般不蕴含“复化后仍为孤立点”：例如 x²+y²=0 的实零点孤立，而复零集是两条直线。这个例子只证明逻辑蕴含在一般实代数几何中不成立，**不是已构造的 Maxwell 同结构反例**。当前最简修复是明确要求相关饱和复根孤立，或饱和系统为零维；若只想覆盖局部正则物理解，可用满秩实 Jacobian 保证复化后的孤立性。若希望覆盖任意物理孤立奇异根，需要额外证明本结构排除上述现象，不能略过。

全四变量通用 multiaffine 起始系统的24与这里的6都属于表示相关的上界。不能把24当成同一物理系统必然具有24个真根，也不能把6/24当成已实现的运行时间比。更强稀疏/消元基线可能利用同样结构。

## 2. 最直接的新颖性反例：转置后的 CSI/SOM

令 j=w^T、g=L^T、G=K^T、A=q^T。以上方程逐字变为

```
j=D(g+Gj),    Aj=y^T.
```

这就是单照明 contrast-current 状态方程与线性观测方程。这个识别是本次审查的代数推论；它不要求宣称物理上的源—接收互易性成立，也不要求 K 对称。再写 j=j0+Nc，就是熟悉的确定/模糊 current 分解的精确零空间情形。

[Chen、Zhong、Agarwal (2010)](https://doi.org/10.4310/MAA.2010.v17.n4.a6) 的作者全文，印刷页416–418，式(28)–(34)，给出了基于数据 SVD 的确定 current、剩余子空间系数以及共同材料的状态约束；页418还明确对照了已有的辐射/非辐射电流与最小范数/截断 SVD。TSOM 在页420–421、式(46)–(47)进一步限制内部场相关子空间。精确零空间、近零奇异值截断和第二重正则化并不完全相同，但“精确零空间所以新颖”仍不足成立。

因此 full-SVD 直接恢复 current 后逐行恢复材料、接收端转置、current lifting、空空间系数、双线性消元、多齐次起始系统，均不能分别计为原创点。当前可能的实质增量应接受最苛刻比较：**标准 CSI/SOM 对偶表示加标准多齐次路径法，是否已立即给出所有本轮推导？** 目前本审查看来其推导较短，强算法创新论证不足；应用定理、稳健饱和处理和经验证的总成本改善仍可有价值。
