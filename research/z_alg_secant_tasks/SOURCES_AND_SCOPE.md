# 本轮读了什么，使用到哪一步

用户提供的两个 ZIP 均已解压。第一份包含中文主报告、英文 TeX 定理、证明核查、先例、下一步检验、公式索引、交接、说明与机器化主张清单，共十个文件。其中结论依赖连续小区域的一致展开。第二份含连续 TM 折叠、二次分支、增测、文献、主张与来源等专题、合并报告和清单。两份都是本轮的理论输入；其中的实验想法没有自动算作已执行的实验。已取得所引用 ChatGPT 会话的历史消息；部分助手消息仅含内容引用，未从引用标记推断未展示的附件正文。两份本地 ZIP 提供了本轮真正使用的推导。

| 历史来源 | 已有证据与本轮处理 |
|---|---|
| R2、R3、R4 | 六槽商代数得到 2/1/1 个合法根，固定 64 起点 TRF 得到 1/1/1。R3 局部求根虽产生大量合法提案，完整高维恢复无新增成功。R4 的较低数据残差未能证明较好材料恢复。本轮没有重跑这三轮。 |
| R5、R6、已知宿主折叠 | 中央观测的条件全根计数和整个噪声域是两种证据。36 电磁状态、六个真实材料未知量的旧结果在给定观测线上认证 2→1→0。重新读取旧双根仅作两点接口核查，材料 RMS 差约 0.2292，旧端口差约 $1.65\times10^{-16}$，中点的全波预测偏离两端平均约 $5.94\times10^{-6}$。它是新拼接构造的种子。[历史网页](https://migodam.github.io/b1-probabilistic-maxwell-imaging/research/z_alg_host_fold/) · [本轮最小核查](history/known_pair.json) |
| R7、R9、R10 | 已有连续单接收、有限照明的局部抵消结果。代数割线恒等式及有限候选主动分割已有文稿，普通多起点在相应测试中能够复制分支覆盖。R10 的余子式排除及单个错误材料通过 190 个分项检验的结论继续有效。本轮把给定读数、共用噪声和完整任务可行域放在一起判断。[R7](https://migodam.github.io/b1-probabilistic-maxwell-imaging/research/research_z_alg_r7/) · [R10](https://migodam.github.io/b1-probabilistic-maxwell-imaging/research/research_z_alg_r10/) |
| R11–R14 | 新数据能区分材料时，联合优化仍可能困在错误极小。R14 首段窄带实验的 62 个对照均回退，未建立稳定优于固定宽带的自适应选频。后一阶段的按指定精度停测要单列。本轮把费用、先验、源数、任务和增益写进测量合同。[R12](https://migodam.github.io/b1-probabilistic-maxwell-imaging/research/research_z_alg_r12/) · [R14](https://migodam.github.io/b1-probabilistic-maxwell-imaging/research/research_z_alg_r14/) |
| R15、R16、MAX-STRUCT 和 GN–NN | 已有 2–30 GHz 的等能量宽带与空间观测比较，排序依任务与反演而异。576 维 R16 追加方向未超过成熟普通交替方法。低维电流表示、材料 Jacobian 的弱方向和有限幅度、带噪材料解释不能混用。本轮从已有带噪观测和原物理矩阵直接检验。[R16](https://migodam.github.io/b1-probabilistic-maxwell-imaging/research/research_z_alg_r16/) · [逐例来源与独立复算](highdim/REPLAY_ZH.md) |

本轮没有采集新实物数据。圆盘脉冲的严格证书、连续圆柱的谱收敛检验、独立网格合成观测、以及依据已存复数所做的测量重放，各自有不同的误差合同。高维旧观测已暴露，不能算独立盲测。新的研究问题、完整证据、剩余缺口和模型分工由[任务记录](TASK_RESUME.md)和[研究交接](NEXT_PRO_HANDOFF.md)保持联系。
