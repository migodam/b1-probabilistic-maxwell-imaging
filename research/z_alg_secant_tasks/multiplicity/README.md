# 分离宿主组件的同读数多解

**两组件在间距 40,000 个背景波长处有至少四份物理材料，三组件在 200,000 个背景波长处有至少八份。** 这些材料在各自配置中对应同一组精确的局部复散射读数。正演保留全部盘之间、发射到全部盘及全部盘到接收的出射 Hankel 传播。证书在完整宿主消元后的等价方程上给出相异的简单实根。两种布设各自的跨组件接收可以逐对区分这些根。

## 几何与读数

每个组件由历史 30 个已知材料盘、6 个独立未知盘、3 个外部线源和 1 个接收器组成。把整个组件沿 x 轴平移，两个相邻组件相隔 R。圆盘半径 0.04 个背景波长，波数为 2π，无损标量 TM。每根线源独立曝光一次。保留每次发射在本组件的一个复读数作为反演数据，所以两组件各有 12 个可变材料和 12 个实读数，三组件各有 18 个。跨组件的接收值逐个保存，完全留出。读数为完整散射场，采用历史模型的观测约定，入射直达项未纳入。

各组件目标都取同一个历史负侧读数 y₋，按已归档的复二进制数精确定义。[历史宿主、原两根和读数说明](https://migodam.github.io/b1-probabilistic-maxwell-imaging/research/z_alg_host_fold/) · [提取的输入](historical_inputs.json)

## 全矩阵阶梯与严格证书

| 组件数 | 相邻间距 R / 波长 | 相异严格根 | 最小材料 L2 距离下界 | 全部跨组件端口的最小复 L2 差下界 |
|---:|---:|---:|---:|---:|
| 2 | 40,000 | ≥4 | 0.390872 | 1.00925×10⁻⁵ |
| 3 | 200,000 | ≥8 | 0.516289 | 5.18622×10⁻⁶ |

全矩阵 Newton 对每一份历史根组合冷启动，并受材料 χ∈[0.5,30] 约束。原定阶梯 R=20、200、2,000、20,000、200,000，从前四个距离未找到收敛候选，到最后一个距离分别找到 4/4 和 8/8 个相异候选。两组件在追加的 40,000 与 80,000 处也各找到四个。较小距离的迭代失败保留在原始回执，区间证明覆盖上表中实际认证的距离。两组件在 40,000 处完整物理状态最小奇异值的数值最小值约为 0.2610，材料到读数的 Jacobian 最小奇异值约 4.77×10⁻⁶。

初始材料使用独立组件的历史根积。对原阶梯的后三个距离拟合，其局部读数差的对数斜率两组件约 −1.0001，三组件约 −0.9987。状态传播矩阵的离块 Frobenius 范数斜率约 −0.5000。局部回到原组件需要两次越过组件边界，量级与读数阶梯吻合。这里仅考察组件数固定、组件间距随 R 增大的几何。

Arb 从十进制坐标、精确 2π 和整数平移重新计算整套 Hankel 系数。以 192 位定向舍入做已知材料消元、合法性检查和 Krawczyk 认证。严格内含与收缩给出每个小盒内的一个简单实根。跨组件端口的球区间在任意两份根之间均可分，连用单个端口也可实现。在两组件的六个跨端口中，区分余量最大的端口为全局接收 0 ← 发射 5，逐对复差至少 3.46991×10⁻⁶。相关端口差是无噪声可分的保证，量级也为后续选择噪声条件保留了实际尺度。

## 复算与成本

在本目录中用 Python、NumPy、SciPy、python-flint 与 threadpoolctl 执行。脚本复用小型提取输入。没有该文件时，首个命令会从原研究的两份归档文件提取，无需重算历史根。

```sh
python separated.py
python separated.py --sizes 2 --spacings 40000 80000 --output results/intermediate
python certify_separated.py
```

- 主阶梯 3,898 次完整状态 LU、31,722 个复发射 RHS、1,550 个复接收转置 RHS 和 553 次小实 Newton 线性解。Apple M4 单线程内计约 0.565 秒墙钟、0.557 秒 CPU。[主阶梯回执](results/numeric_ladder.json) · [材料、几何及所有端口](results/materials_and_ports.npz)
- 补充两距离 64 次完整状态 LU、384 个复发射 RHS 和 72 个复接收转置 RHS，约 0.021 秒墙钟。[补充回执](results/intermediate/numeric_ladder.json) · [对应数组](results/intermediate/materials_and_ports.npz)
- 12 个严格根和跨端口隔离的认证共约 0.684 秒墙钟、0.661 秒 CPU。[根盒、端口外包及认证回执](results/krawczyk.json)
