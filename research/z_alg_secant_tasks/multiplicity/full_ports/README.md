# 全端口下的共同误差球

同一组已认证根的本地读数精确相等。把这些本地读数按实际曝光次数重复，跨组件端口取全部根的保存区间中点的均值，就得到一份共同的完整散射矩阵。该矩阵的 Frobenius 范数作为归一化信号。入射直达项沿用原观测约定。

| 认证组 | 容纳全组根的最小半径界（约） | 相对完整共同信号 | 最近一对根的复矩阵距离 |
|---|---:|---:|---:|
| 历史六槽，两组件，40,000 λ | [7.83654, 7.86114] × 10⁻⁶ | [0.004726%, 0.004741%] | 1.00926 × 10⁻⁵ |
| 历史六槽，三组件，200,000 λ | [6.32671, 6.32925] × 10⁻⁶ | [0.003115%, 0.003117%] | 5.18622 × 10⁻⁶ |
| 偏置两槽，两组件，30 λ | [0.00699331, 0.00753255] | [27.0677%, 29.1548%] | 0.00403703 |
| 偏置两槽，三组件，30 λ | [0.00998759, 0.01009783] | [31.3390%, 31.6849%] | 0.00678048 |

对于任意球心，两根最远端口间距的一半给出下界。指定共同中心到全部根的最大距离给出上界。原始 JSON 保留区间向外舍入值、共同矩阵、逐对距离及每根到共同读数的距离。严格计算直接读取保存的端口区间。

在固定参考范数的 10% 预算下，历史两组分别可在一个球中容纳全部四根与八根。偏置两槽的两组件中，最近一对可共球，全体四根排除。偏置两槽的三组件中，八根的误差球逐对分离。均使用一个联合 Frobenius 球衡量读数误差。
