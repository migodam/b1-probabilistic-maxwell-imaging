# 30 波长双圆柱组件的连续界面对照

在二维无损标量 TM 的圆柱 Fourier–Bessel 多重散射模型中，30 个背景波长处得到 **2 组件 4/4 个、3 组件 8/8 个彼此不同的实材料数值根**，各自在共同的有限局部复散射读数下成立。提高角阶后，同一组根和跨端口差稳定。结论是谱截断的数值证据，缺少无限角阶的严格尾界。

## 物理合同与独立核对

每组两个等半径 \(0.04\lambda\) 圆柱中心在 \((\pm0.18\lambda,0)\)。线源为 \((0,-0.85\lambda)\)，接收点为 \((0.013\lambda,0.95\lambda)\)，整体按 \(30\lambda\) 沿 \(x\) 平移。背景 \(k=2\pi\)，圆柱实对比度 \(\chi\) 取在 \([0.5,30]\)，内波数为 \(k\sqrt{1+\chi}\)。每组独立激励，保留点源到所有圆柱、圆柱之间及圆柱到全部接收点的传播。只用同组收发的复散射读数求根。 [原圆盘脉冲与几何合同](../conditioning/README.md)

圆内用正则 Bessel 函数，圆外用出射 Hankel 函数。连续 \(E_z\) 和法向导数给出各模式散射系数，圆柱间用 Graf 加法定理转换坐标。直接验算在每个圆柱边界取 48 个角度，从原始线源和所有 Hankel 多极子重算外场及法向导数，再和内场比较，两种组件数各取一个收敛根检查。接收点回到 \(x=0\) 时，交换 \((2,8)\) 与 \((8,2)\) 的读数差约 \(2.45\times10^{-18}\)。 [NIST DLMF Graf 加法公式](https://dlmf.nist.gov/10.23.E7)

每个截断阶均把本模型单组件 \((2,8)\) 的读数作为共同目标，从 \((8,2)\) 单启动求另一根。两份局部材料根按所有组合拼接，沿已存盒约束 Newton 和回溯合同独立冷启动。原圆盘脉冲读数用于模型差异比较。

## 截断阶验收

\(|n|\le M\) 依次取 \(M=0,1,2,3,4,6,8,12,16\)。九个角阶均得到独立单组件伙伴和全部多组件数值候选。低阶已有相同根数，直接边界核对仍有差异。两组件首根在 \(M=0\) 的最大相对场跳约 0.212，法向导数跳约 2.64。到 \(M=8\) 分别降到约 \(10^{-10}\) 和 \(4.13\times10^{-9}\)。

最高阶 \(M=16\) 的共同目标为 \(0.009089565053698+0.014448915857861i\)，交换起点找到 \((7.89972926563,\ 2.37992889764)\)，材料雅可比最小奇异值约 \(9.92\times10^{-4}\)。连续界面谱解和原圆盘脉冲的单组件目标场差为 0.00148621，局部伙伴材料 L2 差为 0.02849。两个模型各自采用其定义的共同读数。

| \(M=16,\ R=30\lambda\) | 两组件 | 三组件 |
|---|---:|---:|
| 相异数值根数 / 独立根积初值 | 4 / 4 | 8 / 8 |
| 最大局部复读数残差 | \(2.46\times10^{-14}\) | \(2.01\times10^{-17}\) |
| 最小成对材料 L2 差 | 8.42928 | 8.61873 |
| 最小成对跨组件端口复 L2 差 | 0.00365456 | 0.00616110 |
| 所有材料根的最小 Jacobian 奇异值 | \(8.58\times10^{-4}\) | \(8.07\times10^{-4}\) |

| 直接核对的最大相对 \(E_z\) 跳差 | \(6.13\times10^{-15}\) | \(1.06\times10^{-14}\) |

跨组件端口差为所有跨端口组成的复向量距离。边界跳差按圆柱、全源组和 48 个角度直接计算。高阶间的变化达到双精度数值地板。这给原圆盘脉冲机制提供了独立数值验证，也留下离散证书与连续散射精确根之间的证据差距。

## 复跑与数组

从本研究包根运行 **python multiplicity/continuum/cylinders.py**，依赖 NumPy、SciPy 和 threadpoolctl。单线程完整角阶试验最后一次重跑用了 0.872 秒 CPU，逐次数值停止、账本、残差、边界核对和材料差见 [机器结果](results.json)。[材料、全端口和 Jacobian 数组](materials_and_ports.npz) 以 M〈阶〉_L〈组件数〉_〈根积〉 加上 __m、__ports、__J 保存。固定几何输入和圆盘脉冲参照来自 [两槽条件对照结果](../conditioning/results.json)。
