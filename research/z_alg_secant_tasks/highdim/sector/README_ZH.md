# 从已有带噪复场界定材料峰值

只用五份保存的带噪观测，就能排除某些过低的全域对比度上限。对 24² 环，至少有一格的实对比度必须大于 **4**；对 32² Austria 和 SRAP 壳核全环，至少有一格必须大于 **0.5**。这三项均通过区间认证。结论的条件是冻结二维离散模型、非负实材料，以及全波预测与保存观测的误差不超过原预算。推断仅约束峰值，位置和像素仍未知。 [扫描、未成功项与严格证书](results.json)

## 物理和数据合同

直接使用高维复现包的两份冻结 Green 矩阵、逐观测入射场和接收矩阵。$B=E_0$，$G$ 沿用保存的符号。$J$ 的列是各入射源的电流，离散场方程为 $J=\operatorname{diag}(m)(B+GJ)$，端口读数为 $SJ$。测试只读旧观测 `Y_archive` 及保存的球半径，不使用候选材料或参考材料像素。环的原绝对半径为 .01051718，Austria 同时报原 R8 半径 1.05289187 及 R12 工作半径 1.27247658。三个 SRAP 半径见下表。实际材料数为四个，壳核的全环与半环属于同一材料的配对观测。细网生成而粗网复算的建模差未纳入下界。 [高维复现包](../REPLAY_ZH.md) · [算子、采集及历史输入](../REPORT_ZH.md)

## 从材料上限到场距下界

若所有格点满足 $0\le m_i\le u$，则各格点有 $m_i^2-u m_i\le0$。对全波电流和总场 $E=B+GJ$，这给出

\[
q(J)=\|J\|_F^2-u\operatorname{Re}\operatorname{tr}(J^*E)\le0.
\]

对观测距离平方加上 $\mu q(J)$，其中 $\mu\ge0$，再允许电流在整个复空间变化，可以得到所有合法材料共用的下界。设 $G_H=(G+G^*)/2$、$K=S^*S+\mu(I-uG_H)$、$L=S^*Y+\mu u B/2$。当 $K$ 正定时，下界为 $\operatorname{tr}H$，其中 $H=Y^*Y-L^*K^{-1}L$。如果经验证的下界大于对应的噪声半径平方，则任何球内材料的峰值都大于 $u$。该推断也适用于资料中已有正材料下限的模型，因为这里检查的是放宽到从零开始的整盒。

同一材料也满足任意复线性照明组合 $Ja$。令 $D=SJ-Y$，由此得到 $D^*D\succeq H$ 以及 $D^*D\succeq0$。同一次 $K$ 分解给出四种可比较的距离平方下界。

| 端口方向处理 | 距离平方下界 |
|---|---:|
| 原标量迹 | $\max(0,\operatorname{tr}H)$ |
| 原发射坐标中只保留为正的列 | $\sum_j\max(0,H_{jj})$ |
| 最强单个相干照明组合 | $\max(0,\lambda_{\max}(H))$ |
| 累加正的相干方向 | $\sum_j\max(0,\lambda_j(H))$ |

相干方向是在已保存复场列上做复数线性组合，比较沿用原联合 Frobenius 噪声球。 [小 Gram 矩阵](gram_matrices.npz)

## 区间认证及费用

严格证书把保存的复二进制算子和任意浮点候选矩阵当作精确输入，再用 96 位 Arb 球算术重算。对浮点候选 Cholesky 因子 $C_0$ 和正移位 κ，包住 $\|K-\kappa I-C_0C_0^*\|_F$。这给出可核查的严格正下界 $K\succeq\alpha I$。对环 $u=2$，α 至少 .00196660，矩阵余差至多 $1.967\times10^{-16}$。对 Austria $u=.1$，α 至少 .39153109。严格下界从任意近似解 $X$ 处的二次值扣掉完整余差项 $\|KX-L\|_F^2/\alpha$。这样浮点分解和特征值只用于提议候选，证书不依赖它们的误差估计。

正谱和与单一照明证书分别选取浮点提出的正空间和最强单位方向。用 Arb 单独验证投影矩阵 $V$ 的范数上界 β，从而 $0\preceq VV^*/\beta\preceq I$。随后在 $XV$ 上用同一余差公式认证 $\operatorname{tr}(V^*HV)/\beta$ 的下界。无需验证全谱，也无需为单一方向再分解完整矩阵。三个严格正谱证书的距离下界约为 .02509299、2.06841945、.93616284。 [移位、残差与投影字段](results.json)

双精度五份总计 180 次 $K$ Cholesky 尝试，56 次通过，使用 710 个源右端与 56 次最多 $20\times20$ 的照明谱分解。失败 124 次均有记录。幅值对照为两份共享 Green 矩阵各做一次 SVD 和一次 Hermitian 谱分解，另有五个接收 SVD 及七个小接收谱分解。五个 Arb 审计各重建一次完整乘积 $C_0 C_0^*$，再验证电流残差。两个投影复用这一阶段。保存的一次单线程完整运行使用 44.0 CPU 秒、48.0 墙钟秒。费用按准备、逐格扫描、候选提议、Arb 矩阵运算及投影分列。 [费用与停机](results.json)

用安装了 NumPy、SciPy、threadpoolctl 和 python-flint 的 Python，从研究包根执行。只需重放网格可加 `--numerics-only`，可用 `--output` 将结果和对应 Gram 数组写入指定目录，保留原证书。

```sh
python highdim/sector/sector.py
```
