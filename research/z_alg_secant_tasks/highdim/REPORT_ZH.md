# 全波材料割线的高维见证

在 **24² 环形材料的实际旧观测球**中，两份合法材料的中心方区平均对比度相差 **0.37646**。在 **32² Austria 的实际旧观测**中，沿同一种取向方法找到一对相差 **0.08998** 的材料，两端达到原 150² 合成数据的精确噪声上界。三份 SRAP 旧观测只在重建中心的全波预测附近得到见证，保存的旧观测球内未找到见证。和同空域、同全波调用数的带任务约束 Gauss–Newton 比较，24² 相同，在 Austria 的 12% 容差球里投影跨度较大，在原噪声球里 Gauss–Newton 跨度较大。

## 观测与任务

全组为四个独立材料、五份观测。偏心壳核的全环和半环是同一材料的配对采集。每份都来自已经在历史项目评分的带噪合成观测，本轮用于机制诊断。R10 的细网和反演网格相同，另外四份用较细网格生成观测。

## 全波试验

对保存的合法中心 `m₀`，`Dᵢᵢ=min(m₀ᵢ−lo, hi−m₀ᵢ)`。把接收复场雅可比实虚拆分，对 `JD` 做完整 SVD。把 `Dq` 正交投到小于等于 `10⁻³σmax` 的右奇异空间及零空间，得到 `z`，按 `||z||∞=1` 归一化。实际材料端点为 `m₀±αDz`，`α∈{.25,.5,1}`。直接 ROI 方向使用同一 `D` 乘方区指示函数。另用较小 ROI 直接步匹配投影端间任务差。匹配任务差时允许材料 RMS 不同，数组与逐行表给出实际差。

每一端以独立 LU 求原始全波 VIE `j−diag(m)Gj=diag(m)E₀`，预测 `F=Sj`。一阶代理、实际端间场距、每端距中心预测、端点平均场的偶位移及每端距实存 `Y` 都保留。另复核交叉端点恒等式 `F(m₊)−F(m₋)=S A(m₊)⁻¹ diag(m₊−m₋) Q(m₋)`，其中 `Q=E₀+Gj`。45 对端点中恒等式最大差为 `7.34e−14` 场范数，单个端点最大状态相对残差为 `7.55e−15`。

端点把已表示的离散 `G,E₀,S,m` 视为精确输入。设 `B` 是同一 LU 解得的近似逆。若 `||AB−I||₂≤η<1`，则 `||A⁻¹||₂≤||B||₂/(1−η)`。以 Frobenius 范数、矩阵乘的双精度舍入界以及 `A,b` 的组装余量保守包住上述各项。再以 `||S||₂ ||A⁻¹||₂ ||Aĵ−b||F` 加矩阵乘舍入包住复场误差。逐例记录近似逆缺陷界和预测误差界，单端最大场误差界 `3.78e−5`。端点间和端点到参考读数的区间由三角不等式给出。这个数值区间针对指定离散算子，不包含 96² 或 150² 到 32² 的建模误差。

只有两端的场距区间上界均小于同一个观测半径，才把一半任务差计为该读数下的确定性最坏误差下界。若两端只进入 `F(m₀)` 为中心的等预算球，见证只针对这个理想化读数。即使两端足够靠近而存在中点读数让它们同时合格，该中点也不必等于 `F(m₀)` 或旧 `Y`。这些下界沿用有界噪声解释，未从固定范数高斯方向推断覆盖概率。

表中 Austria 的归一化除数固定为 R12 的 `.12||Y||`。原生成器给噪声方向 `u`（其用途限于封存后的半径复算），解 `δ=.1||Y−δu||` 得原半径 `δ=1.05289187=.09929222||Y||`。该原噪声球内，第一批 α=.25 的两端上界约 `1.04035/1.04044`，半个任务差为 `.04499`。`α=.5` 在 R12 12% 容差球的下界为 `.08998`。

24² 的原 CIE 父解残差为 `13.684%`，高于原球 `1.0491%`，其中央 64 格都没有对称余量。预指定 R12 G19 中心仍有 41 格余量，残差为 `.96014%`。在 α=.25，任务差相同的直接 ROI 两端距旧 `Y` 上界为 `.07862/.08398`，而修正投影端间场距为 `[.00037416,.00037539]`，直接 ROI 为 `[.16041826,.16041948]`。该同任务对照的实际端间材料 RMS 为 `.49605`（投影）和 `.19962`（直接）。α=.5 的端间场距只约 `.120` 倍预算，但偶位移约 `1.487` 倍，已使中心读数无法容纳两端。该例直接区分端间割线小与中心兼容。

SRAP 的三个固定 Dual 中心距旧 `Y` 球分别为 `3.62/3.76/4.22` 倍半径。三组各四个历史 Dual/SRAP 原始与校正端点均出球。壳核的半环和全环差异同时受不同中心、不同收发通道和独立噪声实现影响。用壳核全环里半环从未使用的五个平面波和十个接收点，重算半环 α=1 的端点，两端相对留出复场残差为 `.4536/.4560`，端间差为留出观测范数的 `.02069`。这是同一合成材料的实际保存留出读数，读数匹配仍不足。

封存全部端点后，24² 的参考任务值 `3.446875`，见证两端相对材料 L2 为 `.272/.275`，目标内 L2 为 `.236/.237`，背景 RMSE 为 `.758/.777`。Austria 粗参考相对观测残差 `.22526`，SRAP 三视图粗参考残差 `.13714/.14946/.11816`，均超过对应原噪声上界。粗参考超出球只能证明这个特定参考在球外。Austria 投影 α=.25 两端相对材料 L2 约 `.828/.828`，背景 RMSE 约 `1.374/1.371`。公开图同色标展示端点全图和差值，参考用于离线评分。 [同色标候选全图](results/HIGH_DIMENSIONAL_ENDPOINTS.png) · [逐端点评分](results/PAIRS.csv) · [历史基线评分](results/BASELINES.csv)

## 同物理调用数的任务约束 Gauss–Newton

对上面的两个合格旧中心做单独配对。普通更新在同一对称盒内，分别以固定两端任务改变量 `±.75`（24²）和 `±.175`（32²）解一次阻尼线性化最小二乘，拟合的是实存 `Y`。归一化 `JD` 的首奇异值后，用 `10⁻⁴` 的缩放坐标二范数正则，正负各 256 步加速投影迭代，投影在盒和任务等式的交集。等式误差小于 `2e−16`，停止时投影梯度步范数约 `6e−5`，因此按固定计算包络的普通 GN 结果报告。投影臂使用原弱方向匹配相同任务尺度。两臂各计算一个中心全波场、一个完整雅可比、每端三次原全波回溯，并对这七个场分别做逆残差复核。取通过同一个球的最大和最小任务值，允许来自两端不同的回溯比例。

| 固定球 | 弱投影实际跨度 | 任务约束 GN 实际跨度 | 历史保存端点最大跨度 |
|---|---:|---:|---:|
| 24² 环 CN99 | .37500 | .37500 | .16954，R12 G19 / DR |
| 32² Austria，R12 12% | .35000 | .26250 | .81388，R8 CIE 单 β / Global Dual |
| 32² Austria，R8 原噪声上界 | .08750 | .13125 | .01568，R8 CIE 单 β / CIE 双 β |

两个 24² 臂实际均用 7 LU、84 源 RHS、48 个接收转置 RHS 和 4032 个逆验算 RHS。32² 各用 7 LU、140 源 RHS、40 个接收转置 RHS 和 7168 个逆验算 RHS。计入对照各自的方向求解，24² 单臂 CPU 秒为 `.171/.189`，32² 为 `.840/.785`，对应投影/GN。方向内部线性代数的时钟不同，结果支持调用数口径下的跨度比较。历史端点来自原独立时钟和求解协议，表中用于说明已有合法材料的范围。这个对照给出普通 GN 在原 Austria 精确噪声球中也能找到任务跨度，且在这次固定预算下跨度更大。 [配对候选、原工件路径和费用](results/GN_BUDGET_COMPARISON.json)

## 复现入口

公开包可独立正演重放所有 45 对端点及两个等预算比较，也可重做方向和 GN。 [独立复算与公开历史资料](REPLAY_ZH.md)

在项目根顺序运行以下命令。读取原历史数据和已保存端点，所有新文件写入本轮结果目录。`run.py` 的全部候选落盘后写入端点封存，`score.py` 才打开历史材料参考。`compare.py` 的新方法是在看过第一阶段汇总后加入，本次两个臂生成候选的代码均不读取材料真值。

```sh
Gaussian/.venv_nn/bin/python -B research/z_alg_secant_tasks/highdim/run.py
Gaussian/.venv_nn/bin/python -B research/z_alg_secant_tasks/highdim/score.py
Gaussian/.venv_nn/bin/python -B research/z_alg_secant_tasks/highdim/compare.py
```

五份观测的第一阶段在线主体 CPU 时间为 `14.11 s`，含读取、组装、端点序列化。各观测文件另列 CPU 时间和内部算子费用。含额外壳核留出复算，共 135 LU、1614 源 RHS、6 个完整雅可比、196 接收转置 RHS、116800 个近似逆复核 RHS 和 558 个交叉端点复核 RHS。大量 RHS 用于数值误差界，历史恢复费用与本轮另记。数值和材料参考的适用范围是四份已曝光的独立二维材料及对应离散算子。 [在线封存](results/ENDPOINT_SEAL.json) · [离线评分](results/OFFLINE_SCORE.json)
