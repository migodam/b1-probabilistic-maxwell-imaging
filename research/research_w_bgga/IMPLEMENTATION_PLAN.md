# 本轮实现与顺序执行

本轮对象始终是同一个静态墙体 W、同一个静态目标 X=(p,m) 和共享仪器 gamma。源编号不是运动时间。固定 y 上的求解/表示更新不创建信息。

1. 从用户指定两个 Git 提交读取证据，不借用 main 中未来结果。提取32页附件并核读核心公式；输入PDF不改。核对旧资源scope、新环境及原始2950表。
2. 先完成可审查实现：固定公共目标ROI网格；目标多边形/三角形交集的P3质量与真实incident forcing；普通full、background-LU、resolvent、Schur、Krylov、goal-ROM共享接口。数学单测不能升级为Maxwell资格。
3. 使用散射场的正确增量式：
   `(L_W−V_X)u=b_W+b_X`，`delta_u=G_W(b_X+V_X u_W+V_X delta_u)`。
   `b_X`由解析incident单独积分。不能丢掉它，也不能用节点incident插值替代。所有观察包含direct+scattered。
4. G0获明确资源授权后：先固定网格与interface-fitted参考的弱/强目标、不同位置/半径对照；失败只做一次限定修复。资格失败不启动跨目标速度主张。端口数、实际矩阵秩、内存与独立误差都保存。12个预声明机制fixture（9独立物理parent）的类别是待检验假设，不是预写结果。
5. G0合格后才运行正式G1。有限原子interval likelihood先用默认未查询[0,1]，保留joint权重、条件lift、同因子版本替换与完整费用。重放开发严格标为REPLAY_NOT_NEW_PDE_SPEED_EVIDENCE。reference不得进入在线query/action选择。
6. 只有概率正确且明确能避免的FE/RHS大于准备/核验时才在已批准条件额度内启动G2。普通加权伴随、Schur、cache、goal-ROM享有同等权限。不会拿旧每条6次未收敛A0当强FWI上限。
7. 无资源或门失败时：保留NOT_RUN/FAIL/UNRESOLVED，发布已完成的代码、测试和成本；后续不自动启动锁定确认。

所有数值/概率门仅采用用户给出的建议并标记为本轮工程门，未改旧门。没有新增拓扑、显著性、hash或continuum certificate要求。
