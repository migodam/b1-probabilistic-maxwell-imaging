# Independent pretraining source review

Disposition: **no blocking scientific implementation defect found in the inspected source contracts**. This was a read-only review of `networks.py`, `train.py`, `predict.py`, `anchors.py`, `data.py`, and their experiment launchers. No tests, numerical reruns, precision checks, training, or edits to those files were performed. This conclusion covers implementation logic, not model accuracy, convergence of every future anchor, or generalization.

## Findings requiring accurate reporting

1. **Training `material_nrmse` is not the amplitude-normalized study metric.** `src/train.py:133–136` computes `||prediction−GT||₂ / ||GT||₂`. The official joint/expansion gate instead uses RMSE divided by GT amplitude in the offline scorer. Training selection currently uses the declared material L1 + .1 edge loss (or projected-current loss), so the naming difference does not itself corrupt checkpoint selection. Do not compare training-history `material_nrmse` with .15, use it to decide the amplitude-NRMSE expansion gate, or silently combine it with offline NRMSE curves. Owner may rename it to `material_relative_L2` for clarity.

2. **The `v_image` baseline retains known noise.** `src/networks.py:133–140` zeroes physics channels `[1:26]` but retains channel26, the observation's scalar noise level. Its effective inputs are m0 plus known noise, although all arms retain the same 27-channel backbone. This is a legitimate declared control, but it is not strictly an m0-only input baseline. No GT amplitude/background/family enters that channel.

3. **Mature-anchor eligibility is a cohort-release obligation, not enforced by the training loader.** `src/train.py:36–44` validates finite array shapes but does not read the anchor receipt's `final_stage`, `all_unknowns_released`, stop status, or cost qualification. `src/anchors.py:122–205` preserves actual accepted endpoints and can legitimately end early under a global budget, including before a full-grid solve. Such finite endpoints would still be accepted by training. Release/audit the actual selected cohort before describing every m0 as a mature 24×24 GN endpoint; retain early/budget-stop cases explicitly. The inspected existing DEV batch records final_stage24 for all8. This review did not re-audit all main-training receipts.

4. **Costs distinguish incremental work from shared setup.** `src/predict.py:74–99,126–139` records checkpoint/operator setup separately in `inference_setup.json`, base GN cost separately, and feature construction/normalization/inference/output transfer in the per-observation preparation cost. Feature LU/RHS are zero because the fixed-J transpose matvec is not another solve. Dense G/null-project products incur time and the architecture arithmetic estimate, rather than being mislabeled complex solve RHS. Anchor loading IO is separately timed and not included in preparation; shared reference-J setup is also separate. State the 10-second result as incremental warm-model computation with these separately invoiced costs; do not call it a cold, end-to-end IO-inclusive latency measurement.

5. **Representation comparison does not imply equal output degrees of freedom.** The image head has576 raw real outputs; a full current head has13824, and a receiver-null head has12672 effective real outputs before shared-material readout. `architecture_cost` reports this distinction and the additional fixed dense-matrix arithmetic. The common backbone and same training schedule do not make this a strictly parameter-/FLOP-matched comparison.

## Contracts examined and found consistent

- **Source/ReIm ordering:** `networks.py:98–104` encodes Q0 as 12 real source channels followed by12 imaginary source channels, with each channel's cells in row-major order. `networks.py:229–231` decodes the current head in exactly that order and transposes to batch×cell×source. `predict.py:40–45,118–122` converts MPS's final Re/Im pair dimension back to complex cell×source arrays without swapping sources and cells.
- **Observation/J packing:** the fixed reference-J feature is `J_ref.T @ Model.pack(Y−F(m0)) / ||Y||²` (`anchors.py:224–225`). The inherited Model packs source-major, receiver-major, real/imag interleaved, consistent with its analytic J rows. No complex-vector flattening is silently substituted for this realified pack.
- **One shared real material across all sources:** `networks.py:194–204` forms q=E+Gj and sums the numerator `Re(conj(q)*j)` and denominator `|q|²` across all12 sources. The MPS pair representation sums source and Re/Im dimensions, giving the same real least-squares readout. It returns one576-vector, clips to [.02,20], and does not create independent materials per illumination.
- **Exact receiver-null formula:** `networks.py:181–192` implements z−V48(V48* z). The MPS adjoint uses transpose with the correct negative imaginary sign. The formula retains all48 receiver right singular vectors, with no weak-spectrum truncation. The generated dataset receipt says `one_economy_S_SVD`; its V48 was computed from the public S. The source's optional historical-cache branch only checks cached basis shape, so a future operator change must not blindly reuse a same-shaped foreign cache. No such mismatch is established for this dataset.
- **TRAIN-only calibration:** `train.py:169–178` separates TRAIN/VAL and rejects shared parent IDs before fitting feature statistics on TRAIN anchors only. `networks.py:107–130` uses only public anchor m0/gb/Q0/noise, fixes the material normalization scale to .4, and derives current_scale from TRAIN Q0. GT amplitude/background/mask/family are not inferred from evaluator metadata or fed into the model. Validation affects checkpoint/early-stop selection as declared, not normalization.
- **GT split boundaries:** `SupervisedAnchors` accepts only TRAIN/VAL (or explicitly authorized debugtrain/debugval). Truth opens happen only after that split guard. Parent grouping in `data.py` keeps noisy/stress variants in their parent's split. `predict.py` accepts explicit public anchor paths, opens no manifest/truth, and uses the checkpoint's frozen statistics.
- **Loss meaning:** image/physics/current-material arms optimize shared-material L1/.4 + .1 edge L1/.4. The `j_null_current` ablation instead fits Pnull(jGT−j0), with complex magnitude L1 (equivalent pair-vector norm on MPS) divided by TRAIN current_scale. It logs material losses but does not backpropagate them. No data residual or constitutive defect is secretly treated as the same loss. A good current objective remains insufficient to establish full-VIE material qualification.
- **Zero head initialization:** the final weights/bias are zero, so the first output is the identity proposal up to the current readout's arithmetic. The first backward pass can give a nonzero head gradient and zero upstream gradients because the head weights are zero. AdamW then changes the head, allowing later backbone gradients. First/last head/stem norms are recorded per epoch; a zero first stem norm alone is expected and is not evidence of permanently frozen training.
- **GN budgets and endpoints:** anchor CountedModel checks prospective LU/RHS before operations. The8→12→24 schedule uses cumulative phase fractions .20/.45/1, bounded analytic TRF, and strict1e-12 tolerances. Accepted states are saved when SciPy requests a Jacobian; rejected residual trials are excluded from the reported endpoint. Budget stops remain explicit, and wall overshoot is recorded for noninterruptible calls. `best_valid_*` is saved separately and is not silently substituted for the actual endpoint. No physical data-gate early stop is used to disguise a lightly solved anchor as an optimizer-converged endpoint.

The owner retains final scientific qualification. In particular, successful algebraic current readout, no source-order bug, and valid split handling do not establish that learned proposals improve the fresh held-out material reconstruction.
