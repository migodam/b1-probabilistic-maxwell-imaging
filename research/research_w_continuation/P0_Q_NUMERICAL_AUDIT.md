# P0-Q 数值审计：为什么这次能继续，仍有哪些限制

日期：2026-10-23。本文只整理已保存结果，没有新增物理解。主线程已将 P0-Q 判为 **PASS / QUALIFIED_DISCRETE_FULLWAVE**：两个原世界、两带、cal/task 共 8 个完整数据检查的最细差为 **0.006533–0.033224**，全部小于原门槛 0.1。它允许继续独立的 P0-B，不代表已经发现二维歧义、获得连续 PDE 误差证书或完成成像。本文不判断正在进行的 P0-B 结果。[判决](P0_Q_QUALIFICATION.json)、[冻结协议](P0_Q_PROTOCOL.md)

## 1. 先把“矩阵解准了”和“物理近似准了”分开

旧 VIE 的线性残差已经很小，但格子里的材料和场仍被简化。把这个矩阵解到机器精度，只说明解准了该离散模型；如果圆形界面被切成混合方格、单元内的场变化没有表示出来，接收数据仍会离连续参考很远。Q 的工作是分别改变积分、界面表示和场空间，保留所有不改善的尝试，再用独立解析参考和原墙体完整数据检查选择后端。

旧 P0 的 nx128 圆柱相对散射误差 7.00361% 是审计起点，不是本轮已解释清楚的单一误差项。圆柱参考始终是相同的半径 0.3、中心 `(0,1.5)`、`εr=4+0.03i`，没有拟合复幅或相位把曲线对齐。[旧证据审计](docs/OLD_EVIDENCE_AUDIT.md)、[归因实现](src/wq/experiments.py)

## 2. 更准的积分没有消掉主要误差

固定 nx96、圆面积 fraction 和平均平面入射，只提高非自项 Green 积分阶数，结果如下。

|核积分阶数|圆柱相对散射误差|白化误差|
|---|---:|---:|
|GL4|0.0984519026|9.84887344|
|GL8|0.0984374343|9.84742607|
|GL16|0.0984374312|9.84742576|

GL4 到 GL16 只改变约 0.001447 个百分点，无法解释约 9.85% 的主要差距。单核检查也支持这个有限判断：最近邻 GL4 对 GL96 的相对差为 `8.24e−6`，GL16 已到 `1.70e−15`；远单元 GL4 约 `1.80e−12`。自单元直接 GL4 会有约 1.54% 积分误差，但生产 VIE 已用真实方格的解析径向自项，不能把这条“如果直接用 GL”的误差记到实际自项上。[归因结果](results/attribution/RESULTS.json)、[核积分结果](results/kernels/RESULTS.json)、[旧 VIE 自项](vendor/p0/vie.py)

## 3. 界面和场空间都重要，尚无精确占比分解

同样 nx96/GL4，圆柱中心二值材料的误差为 `0.125881028`，使用精确交叠面积 fraction 后为 `0.098451903`。界面表示确实影响结果，但 fraction 后仍有显著误差。对原墙体只增加单元内材料采样，4→8、8→16、16→32 的单频完整数据白化变化分别为：seed 2026102201 的 `0.691284 / 0.243701 / 0.036029`，seed 2026102202 的 `0.207766 / 0.074118 / 0.033233`。这些是固定 nx96、f=1、cal 状态的系数敏感度，不能外推为全部频率或任务状态的误差百分比。[归因结果](results/attribution/RESULTS.json)

双重平均 VIE 仍只保留单元常数场；nx64/96/128 的相对误差为 `0.402508 / 0.183931 / 0.118240`，比对应原方案 `0.226095 / 0.098452 / 0.070036` 更差。这个负结果否定的是本次具体改法的改善，不能概括所有 Galerkin 或高阶 VIE。非求解积分审计虽核对了自项、微单元划分和加权积分，也没有建立 PDE 精度。[双重平均结果](results/galerkin-cylinder/RESULTS.json)、[实现与限制](research/delegated/wq_vie/REPORT_ZH.md)、[非求解检查](research/delegated/wq_vie/NON_SOLVE_AUDIT.json)

## 4. 界面贴合与高阶场给出了更强的外部证据

未贴合界面的 P2 FEM，h=0.12/0.08/0.06 的相对误差为 `0.030719 / 0.056079 / 0.016172`，并不单调。简单缩小一个网格标签不保证切割界面与积分的误差同步下降。改用贴合界面的 P3 后，圆柱平面波和实际线源都有独立参考；h=0.13、圆周 512 节点的 FE 点接收相对误差分别降到 `0.000342321 / 0.000271229`。[未贴合 P2](results/fem-cylinder_fem-cylinder-002/RESULTS.json)、[独立参考](results/independent/RESULTS.json)

早期拟合网格比较同时改变了 P2/P3 和圆周节点，不能独立归因。新增对照已经完成，固定 h=0.16、圆周 256 节点、相同积分阶数和接收方式后，P2→P3 的平面波体积分接收误差为 `0.020291927→0.001366590`，线源误差为 `0.016953868→0.001068067`。这是该固定圆柱上提高场阶数的直接证据；不是新定理，也没有把所有墙体误差唯一归给场阶数。[同几何对照](results/circle-controls/RESULTS.json)、[对照脚本](tools/circle_controls.py)、[完成凭据](results/jobs/circle-controls-001/RECEIPT.json)

## 5. 接收方式与离散导数已经分别核对

FEM 的入射线源用解析自由空间 Green，数值部分求散射场；这样不必在网格上近似一个奇异 delta 源。接收同时保留 FE 点插值与材料体积分两条路径。后者把材料内总场通过同一个自由空间接收 Green 积分回接收器，没有改变天线位置或源谱。两条提取方式使用同一个已求解状态，所以它们的差主要用于检查输出离散的一致性，不能充当新的独立物理解。[FEM 源码](src/wq/fem.py)

在固定平滑材料 fixture 上，体积分接收的源收互换缺陷为 `3.9048e−15`，点插值路径仍为 `5.4972e−5`；严格实伴随 dot 缺陷为 `3.1502e−14`，材料方向中心差分最佳相对误差 `1.4889e−9`（步长 `1e−4`）。这支持已实现材料导数和源收接口的一致性，不验证形状重网格或拓扑变化的导数，也不替代完整前向精度。[导数/互易结果](results/fem-derivatives/RESULTS.json)

## 6. 可以采用的结论

当前可采用贴合界面的 P3 scalar-TM FEM，并将体积分接收作为已审核的输出路线。原两世界的完整多频网格、PML 和输出提取检查相容，主线程因此给出离散全波资格；精确 8 格、PML 厚度检查、费用与内存超目标记录见[误差与费用文档](P0_Q_ERROR_BUDGET.md)，路线对照见[求解器比较](P0_Q_SOLVER_COMPARISON.md)。

资格只覆盖冻结两个 seed、固定 cal/probe8 task、原采集和材料约定。新的 P0-B 端点需要自己的细化/独立审核；不能把当前资格当成整个未知材料类的统一证书。没有连续 PDE 上界，没有新颖性或算法加速结论，也没有在本文中启动 P0-C、posterior、A17 ROM、网络或三维。
