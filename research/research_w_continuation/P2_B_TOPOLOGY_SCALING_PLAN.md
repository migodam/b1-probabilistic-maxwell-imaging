# P2-B：未知拓扑支持与规模扩展（未来计划）

**状态与进入条件。** 本阶段没有新拓扑生成、训练或高维 posterior 实验。先完成 P0-Q/P0-B，保留 qualified JOINT 世界；当前 Q 不被假定通过。概率结论还要求 P1-A 有独立参考、P1-B 已明确多假设与递进各自贡献。若只有可行端点，就只研究 candidate 搜索与覆盖，不能提前称全材料 posterior。P2-A 未有同费用优势时，不强制把 A17 加入本阶段。

**共同材料测度。** 在全未知域定义允许空气成核、合并和消失的被动 level-set/连续材料 prior，明确相关长度、最小特征、exact-air 相、跨频共享色散及占据限制，不向算法提供真墙 mask、孔数或 topology 标签。不同网格通过同一连续几何/latent prior 投影；确需扩大 latent 支持时，另标新的先验问题。每个固定支持内所有对照使用同一 prior 和完整 likelihood，不能把窄 shape family 与宽拓扑 prior 的差异写成算法增益。

**最小扩展矩阵。** 两个冻结的合法世界 × 两级已 qualified 前向/材料分辨率 × 两类 proposal：共同 prior 内的局部连续 pCN/MH/梯度 proposal，以及在同一局部库上增加空气成核/合并/分裂提案的混合方案；跨拓扑提案必须给出合法接受率或可核对的密度/Jacobian。选取世界的孔结构只供离线描述，不输入推断。先复现 P1 的小维可积分子问题，再单独报告扩维与计算成本，不把更多网格节点自动当更多观测信息。

**任务与概率诊断。** 主任务仍为 T 内总材料质心、占据事件及完整目标传播；拓扑事件可用预先固定阈值和前景/背景连通性定义的孔数/Euler 特征，阈值在看结果前声明。报告在线任务损失、拓扑事件质量、proper score、分支回访、遗漏状态和局部/跨拓扑提案贡献。独立 reference 存在时沿用 P1 的事件/CDF≤0.02目标；高维部分无 reference 或尾质量无法估计时写 unknown，不把 MH 形式、ESS、候选数或拓扑新颖度当成概率准确度。

**成本比较与产物。** 在每个分辨率/先验支持内给两方法相同的实际 RHS、分解和 process CPU 权利，费用包括全局探索、失败提案、细化、物理验证、basis、校验与 fallback；报告随自由度和活跃材料数增长的 wall/CPU、内存与任务误差曲线。任何压缩效率主张沿用 P1 同准确度总费用减少≥20%的已有目标，不新增拓扑成功率或扩展倍数 gate。输出每格先验支持、候选/后验身份、原始数据一致性、任务质量与全费用表。

**停止与解释。** 若资格无法保持、跨网格 prior 不相容或预算不足，停止对应尺度而不自动加预算。若只增加候选/孔结构而无可验证的质量或任务收益，保留搜索结果，停止“可靠拓扑 posterior”主张；若普通共同 prior 基线同费用达到相同结果，不主张拓扑提案的独立优势。不存在参考或未覆盖质量证据时，不以更多网络、Flow/Diffusion 或更长链补造成功；扩展只覆盖实际核验的二维材料类。
