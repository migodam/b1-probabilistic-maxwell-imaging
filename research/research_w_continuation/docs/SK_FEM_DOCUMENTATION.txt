### Access derivatives in BilinearForm

Source: https://github.com/kinnala/scikit-fem/blob/master/docs/api.rst

Accesses gradient components directly via the .grad attribute of basis function arrays.

```pycon
>>> @BilinearForm
... def form(u, v, _):
...     # u.grad[0] is first derivative with respect to x, and so on
...     return u.grad[0] * v.grad[0] + u.grad[1] * v.grad[1]  # laplacian
```

### Project and probe functions on a mesh

Source: https://github.com/kinnala/scikit-fem/blob/master/docs/extended.rst

Projects a function onto P1 and P0 bases and visualizes the results alongside probe values along a line.

```python
N_query_pts = 100
x1_value = 0.25
query_pts = np.vstack([
    np.linspace(0,1,N_query_pts),  # x[0] coordinate values
    x1_value*np.ones(N_query_pts),  # x[1] coordinate values
])
p1_probes = basis_p1.probes(query_pts)
p0_probes = basis_p0.probes(query_pts)

def f(x):
    return 4 * abs(x[0] - 0.5)

projection_p1 = basis_p1.project(f)
projection_p0 = basis_p0.project(f)

fig, ax = plt.subplots(2, 2, figsize=(12,12))
skfem.visuals.matplotlib.plot(basis_p1, projection_p1, vmin=0, vmax=2, ax=ax[0][0], shading='gouraud')
skfem.visuals.matplotlib.draw(mesh, ax=ax[0][0])
ax[0][0].plot(query_pts[0], query_pts[1], '--r')
skfem.visuals.matplotlib.plot(basis_p0, projection_p0, vmin=0, vmax=2, ax=ax[0][1], shading='gouraud')
skfem.visuals.matplotlib.draw(mesh, ax=ax[0][1])
ax[0][1].plot(query_pts[0], query_pts[1], '--r')
ax[0][0].set_xlabel('x[0]'); ax[0][0].set_ylabel('x[1]')
ax[0][1].set_xlabel('x[0]'); ax[0][1].set_ylabel('x[1]')
ax[0][0].set_title('projection_p1'); ax[0][1].set_title('projection_p0');

ax[1][0].plot(query_pts[0], p1_probes @ projection_p1)
ax[1][0].set_xlabel('x[0]'); ax[1][0].set_ylabel('f')
ax[1][1].plot(query_pts[0], p0_probes @ projection_p0)
ax[1][1].set_xlabel('x[0]'); ax[1][1].set_ylabel('f');
```

### Define and assemble a BilinearForm

Source: https://github.com/kinnala/scikit-fem/blob/master/docs/api.rst

Demonstrates creating a BilinearForm using a lambda function and assembling it with a basis.

```pycon
>>> from skfem import BilinearForm, Basis, MeshTri, ElementTriP1
>>> form = BilinearForm(lambda u, v, _: u * v)
>>> form.assemble(Basis(MeshTri(), ElementTriP1())).toarray()
array([[0.08333333, 0.04166667, 0.04166667, 0.        ],
       [0.04166667, 0.16666667, 0.08333333, 0.04166667],
       [0.04166667, 0.08333333, 0.16666667, 0.04166667],
       [0.        , 0.04166667, 0.04166667, 0.08333333]])
```

### Get all boundary DOFs

Source: https://github.com/kinnala/scikit-fem/blob/master/docs/api.rst

Retrieve all boundary degrees of freedom for a triangular mesh basis.

```pycon
>>> import numpy as np
>>> from skfem import MeshTri, Basis, ElementTriP1
>>> m = MeshTri().refined()
>>> basis = Basis(m, ElementTriP1())
>>> basis.get_dofs().flatten()
array([0, 1, 2, 3, 4, 5, 7, 8], dtype=int32)
```
