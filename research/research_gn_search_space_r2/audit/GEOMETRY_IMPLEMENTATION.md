# E1 implementation and evidence audit

`src/space.py` is GT-free: it does not import endpoint metadata, errors, observations or truth. `prepare_geometry(model,state,...)` requires the existing R4 model's matching retained LU. The caller controls state construction. The fixed G/S right singular vectors are reused from the prior saved `fixed_spectra.npz`; no fixed Green spectrum was recomputed. Complex current complement dimension is 67 and its orthogonal complement has dimension 509 at tau 0.1 and numerical null rtol 1e-12.

The exact tangent is `W diag(h) Q` with `W=(I-diag(m)G)^-1`. One inverse solve against the identity costs 576 complex RHS with the retained LU. The realified source-stacked leakage map contains `U^* W diag(Q_s)`; its direct SVD, rather than a squared Gram eigenvalue, defines the reported numerical material kernel. `HT=Re[(W^*W) .* (QQ^*)^T]` is positive definite for all evaluated anchors; no ridge or jitter is added. The generalized leakage vectors solve `HC v=mu HT v`. Their Euclidean spans are orthonormalized before error energy is measured. New implementation uses positive Gram Cholesky whitening, without regularization, for the full-rank selected columns. Earlier saved QR spans and later whitening spans have the same subspace semantics.

API returns `approx_basis` (alias `U_dark`), ascending `eigenvalues`, `leakage_vectors` (HT-orthonormal generalized eigenvectors), `numerical_kernel`, unsquared `leakage_singular_values`, full real `J`, descending `J_singular_values`, corresponding `J_right_vectors` as columns, `HT`, `HC`, `W`, `Q`, diagnostics and operation-count deltas. The main threshold is mu<=0.01; sensitivity is mu<=0.1. The module never selects vectors by GT. Material/Jacobian null ranks are explicitly numerical at rtol1e-12, not symbolic rank theorems.

The offline E1 runner uses the old frozen error archive for endpoint/GT labels, and public R4 observations for noise-relative scales. Its 52 anchors comprise all48 A=0.4 CPU Native/Reciprocal clean/noisy endpoints plus Native clean digit7/ring at A=2.5 and12. Sixteen distinct GT material arrays occur. Exact full-J singular spectra are evaluated at anchors, unique GT states, the fixed public mref=0.1 state, and Born linearization. Source subsets are [0], [0,4,8], [0,2,4,6,8,10], and all12. Real rows preserve the complex-data Euclidean norm. `d_weak` counts `r sqrt(576) sigma(J)/norm(Ysubset)<=epsilon`; `d_soft` sums its smooth reciprocal-square version. Reported RMS values are0.01,0.03,0.1 and epsilon values1e-5,1e-4,1e-3. Numerical zero padding is retained for wide matrices.

Error coverage is offline scoring after basis construction. Weakest-J bases are nested orthogonal right singular vectors. Generalized leakage prefixes are Euclidean-orthonormalized at ranks8,16,32,64,128,256,576, and at both relative-current thresholds. Bounds are the existing frozen box0.02..20; projected directions are scored without clipping or basis adaptation. Current leakage and J response are tangent quantities. Per-case NPZ files include offline projected directions at ranks32/64 and threshold0.01/0.1; their finite nonlinear VIE responses are outside this worker's initial E1 scope and are evaluated by the parent. Fixed-reference versus anchor drift uses projector distance and principal angles at ranks32/64. Fixed-reference Green error coverage was added from cached reference vectors without new physics.

## Native failures and accounting

Runtime is Apple arm64, Python3.13.13, NumPy2.5.3, SciPy1.18.1, macOS Accelerate, CPU with VECLIB/OMP/OPENBLAS thread environment1 (`threadpoolctl` reports no recognized pools). Several original multi-case processes failed natively: exit139 after14 saved cases; exit133 during redundant reference preparation; another segfault after30 cases; allocator-debug runs confirmed memory corruption while processing Euclidean orthogonalization. Replacing divide-and-conquer SVD/eigensolver drivers alone did not remove the failure. No deterministic physics case failure was established. Logs `run.log`, `resume01.log` through `resume05.log` retain the failures. The last original multi-case process was explicitly interrupted after47 saved cases to apply the parent's fresh-process requirement; final5 cases completed in separate processes. No extra scientific search or tolerance sweep was used to rescue the experiment.

The final numeric code uses SVD `gesvd`, generalized eigensolver `gv`, positive Gram whitening, and fresh-process isolation for supplemental work. This is an execution workaround; no claim is made that the precise native bug has been identified.

Saved-output checks are substantive and limited: all52 NPZ arrays are finite; all saved J right bases and approximate bases pass orthogonality; stored generalized eigen residuals are below1e-10. Max observed J orthogonality error7.77e-14, approximate-basis error3.65e-14, generalized eigen residual3.31e-15. `integrity.csv` records case-specific values. These are checks of the saved numeric artifacts, not a claim that native memory failures are impossible.

Original E1 counters are a LOWER BOUND: completed-case counters plus the first paid public reference. Failed uncheckpointed operations, retried preparation and repeated reference preparation add costs that cannot be recovered exactly. `RUN_SUMMARY.json` explicitly leaves total retry and aggregate operation timings unavailable. Successful-case wall times sum to55.07s. Do not describe this original run as a complete-cost benchmark. Reused fixed G/S spectra are immutable offline setup, not per-target geometry.
