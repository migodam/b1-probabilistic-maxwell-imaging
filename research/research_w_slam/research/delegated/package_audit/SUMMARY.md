## 5. Small posterior reference recommended by the package

Begin with **2×2 public regions / four occupancy bits**, enumerate all 16 raw masks, then apply the same geometry validator and explicitly record the legal count. Do not assume 16 valid supports. Use the shared two-parameter material prior first, target-center coordinates, and the declared shared gain/phase nuisance; this keeps the intended reference smaller than regional independent material models. Then extend separately to **3×3 / at most 512 raw masks** and to wide ROI support search. The package does not equate these classes with two handpicked historical walls.

Integrate each legal support's proper prior and continuous likelihood; use successively refined quadrature as the initial independent reference, cross-check with temperature-bridged SMC and/or independent MCMC. Record evidence per support, continuous coordinates and reference errors. Two random samplers agreeing does not prove global coverage; audit tails/undiscovered modes. Reference accuracy must be below evaluated tolerances, not merely equal to 0.02. A0 success requires both fitted/posterior-predictive compatibility and independent held-out prediction, using preregistered prior-predictive calibration rather than ||y−F||<=1. Small and wide A0 are separately gated.

## 6. Explicit unresolved choices and ambiguities for parent resolution

1. **Physical blockers are deliberately null:** PML/exterior values, source normalization and observation units, full geometry rules, event boundary, rank/discrepancy rule, and seeds/preregistration. Formal data generation is disallowed until frozen and numerically qualified (`Codex_Experiment_Prompts.md:63`; `experiment_contract.example.json:306-312`). Other nulls include likelihood/reference tolerance, holdout design, important-mode definition and loss maximum (`experiment_contract.example.json:207-227`).
2. **Small-region partitions need explicit boundaries.** The example lists 2×2/3×3 shapes but no region-to-macrocell map, whether empty wall is legal, or legal-mask list. Enumerating a shape count alone is not a completed geometry/normalization contract (`experiment_contract.example.json:64-98`).
3. **Per-support unused materials must be integrated consistently.** Report warns that air-cell unused parameters must be integrated out or assigned a fixed auxiliary prior; otherwise evidence is distorted. The JSON has no explicit empty-support treatment (`Research_W_SLAM_Report_ZH.md:201-209`; `experiment_contract.example.json:92-111`).
4. **Dynamics are not instantiated.** Motion covariance, unknown-pose anchors, prior correlation, and proposal/Jacobian fields remain null. They block only dependent extensions; initial known pose/shared static target can be separately declared (`experiment_contract.example.json:154-174`).
5. **The broad ROI family is not concretely specified.** Multiresolution/level-set/reversible occupancy are alternative candidates; broad regional material correlation is null. Do not call the small-reference prior the general wall class (`Codex_Experiment_Prompts.md:187`; `experiment_contract.example.json:111`).
6. **Stored numerical tolerances have differing semantics.** Observability JSON records absolute operator-norm errors while report prose calls them normalized errors. Maximum full-rank/singular errors are 1.0763e−14/3.1364e−14; freezing uses an explicitly normalized relative-error helper with denominator max(1,||a||,||b||). Preserve the exact metric when quoting (`code/observability_toy.py:75-91`; `code/freezing_toy.py:23-25`; `Research_W_SLAM_Report_ZH.md:770-774`).
7. **Toy D8 cost/certification is limited.** Dense exact eigenvalues and perturbed exact duals in the toy are formula checks, not evidence that cheap partial iterative duals and rigorous Maxwell lower bounds exist (`code/freezing_toy.py:79-91`).
8. **Package date/command path inconsistency:** metadata says 2026-10-24 UTC while both toy seeds are 20261025; seeds alone do not establish execution date. Source docstrings say `deliverables/code/...` whereas current package uses `source_package/code/...`; actual output paths are resolved relative to the script (`code/observability_toy.py:4-5`, `63-64`, `163-165`; `code/freezing_toy.py:5-7`, `19-20`, `183-185`).
