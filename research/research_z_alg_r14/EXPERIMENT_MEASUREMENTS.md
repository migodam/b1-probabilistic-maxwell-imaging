# 六材料加频实验

主频带内，候选分离和局部 Fisher 没有降低固定对称双频的材料误差尾部。R12 的 36 份带噪读数上，固定 ±2% 的普通八起点把材料 RMSE 的 90 分位降至 **0.00557**，最差为 **0.00835**，36 份预测均与新旧数据的共同增益合同相容。有限孔径组在同样动作上仍然有大误差。扩频后的四频逐次累计把该组的 90 分位降至 **0.0993**，但其中一份旧替代材料在全部已测频率下仍可解释同一批观测。

## 观测与比较

- R12 使用 `spectral_online.json` 全部 36 份旧复读数，涵盖六套布局、两侧各三次。旧中心方程找到零、一、二、三个合格根的案例分别为 18、6、10、2 份。重复旧频和固定 ±2% 的新增两块读数直接复用 R12，独立按原采样重算的逐通道差为 0。R10 自然组使用原始的 18 份带噪 `y_old`，有限孔径组使用原始的八份带噪 `y_old`。后两组新增的是改频观测，发射位置保持旧组几何。
- 动作先由几何、旧观测、公开噪声参数和旧材料候选确定。之后单独生成新增物理读数。恢复只读取该动作的读数，完成预测后才用离线材料、另一侧见证评分。区域选频可以沿用同一个读数库和恢复器。
- 六维实材料盒为 `[0.5, 30]^6`，保持无色散、相同圆盘、源和接收位置。每频率重新计算完整 Hankel VIE，发射系数乘 `√(1+δ)` 保持背景参考功率；所有频率使用同一个复增益。主菜单允许 0.025%–2% 的九档绝对频偏，每档均可选单高、单低或正负各一半。另有旧频重复和四个等间距新增频率。主比较共加一个能量单位，一频一次整曝、二频两次半曝、四频四次四分之一曝。固定功率下总有效积分时间相同，单独报告曝光次数；频率切换开销没有物理装置数据。放宽至 ±4%、±8% 只做带宽敏感性。
- 每臂对应曝光槽复用同一标准复高斯噪声样本，数据除以曝光幅度表示时，协方差为 `σ²/E`。恢复使用 `√E` 白化，解一个按标定先验精确剖面的公共复增益。R12 每复通道 `σ=3e−7`，增益标定尺度和硬幅值上限为 `4e−4`。旧评分椭球轴为 `√2 r99(3)`、`√2×4e−4`，并保留增益硬幅值约束。R10 旧评分椭球轴沿用 `2e−4`、`.01`。R10 新频率用同一个真实旧增益和新增高斯样本，令三复通道的 `r99(3)=2e−4`；各新增臂的半径按通道数计算。R10 原始旧误差分布与新增高斯对照分开处理。
- 盒约束解析 Jacobian 最小二乘，普通起点为常数 12 加固定 Sobol 起点。旧候选恢复对旧中心同伦根按所获全部读数选初值，不足时补普通起点。无根时先从三个普通起点拟合旧数据。局部 Fisher 最大化剖面信息最小特征值，候选间距最大化共同增益剖面后的最小增量差，无候选对时回退 Fisher。几何对照只用三个预定均匀材料，随机对照分别在全菜单和 2% 最大频偏的子菜单抽签。
- 累计对照从低到高逐次把新频率纳入目标，频率为零时加入已测旧块。FBCH 对照依据 Sun 的 [IEEE 原论文摘要](https://doi.org/10.1109/TAP.2025.3592795) 对分箱累计与长波长加权的说明，把相同读数分成两个低到高的箱并递增保留。使用相同盒约束恢复器，附加 `(λ/λ₀)^n` 的损失权重，取 `n=0、1、2`，对最终起点仍用同一个白化目标排序。出版社全文未能取得，分箱边界、权重公式和求解器是本实验适配。

## 同一批数据仍可有不同材料

相容性逐材料检查是否存在同一个复增益，使旧加性误差与标定项落在旧椭球内，并且全部新增白化残差范数不超过对应 `r99`。每项约束在复增益平面中是一个圆盘，判据是这些圆盘有公共点。这个评分和用于选择起点的平方目标分开计算。

在 `confirm6-00`，R10 档案替代材料与真材料相距 **0.12538 RMSE**。二者通过主频带内单高、单低、两频、四频以及放宽到 ±8% 的联合观测。在 ±8% 双频，甚至使用同一个归档增益，两个旧椭球分数均为 0.93982，新增白化范数与半径之比分别为 0.5203、0.6902。对这两份同样解释所见数据的材料，任何单点输出在两种解释中的最坏误差至少为 **0.06269 RMSE**。这是在实际合成观测上的浮点见证。

在 `confirm6-05`，已有的另一材料相距 0.95352 RMSE，在每个新增动作上都不相容。但固定 ±2% 的三起点恢复仍在别的不相容局部点停止，误差为 16.55。相对地，`fresh6-09` 固定 ±2% 的输出误差为 4.82，仍满足共同合同。这三个例子分别展示观测歧义、数值搜索失败以及在噪声合同内的大材料偏差。

## 用后验保留区域精修材料

后续对照使用 `posterior_joint` 和 `validation_regions` 保存的全部保留盒。对每个观测阶段，取盒并的坐标包络中点，用该包络限制单起点的同一公共增益剖面 TRF。普通八起点使用相同的读数与 780 因子化上限。保存预测和计时后再评分真值。此前半曝序贯规则使用原设定的区域上界。

## 剂量、恢复计算和指标

每臂共享 780 个 Maxwell 因子化的恢复上限。三/八起点及各累计阶段在同一上限内分配预算；设计和旧根扫描单独计费并计入总成本。普通八起点在 R12 固定 ±2% 平均使用 522 个因子化，普通三起点约 186 个。另计同伦多项式路径与路径 Jacobian 计算。单案例的设计和恢复墙钟时间均记录，重复求解相同物理频率共用一次算子应用，模拟生成观测与离线评分的开销并未加给某个恢复臂。

固定 ±2% 旧候选三起点在 R12、自然、有限孔径组的共同相容为 34/36、16/18、6/8，生成材料在这三个队列分别为 36/36、18/18、8/8。对应 NRMSE 90 分位为 0.000568、0.231、0.244。错侧按结果更接近已有另一材料计，固定 ±2% 的三组比分为 1/36、1/10、0/2，分母只包含具备可评分替代材料的案例。R12 固定 ±2% 普通八起点的错侧为 0/36，相容 36/36。

逐案保留 RMSE、NRMSE、IoU、SSIM、合同相容、错侧、RMSE 超过 0.1、频率跨度、能量、曝光次数、实际因子化和复右端数与实测用时。六个圆盘的几何支持已知，IoU 在对比度至少 10 的圆盘上算，SSIM 用六个材料值的全局均值、方差和协方差，以材料盒的跨度定标。结果属于历史队列的协议重放，适用范围是这里的六材料几何、共同增益和噪声条件。

## 复现

在本目录运行以下命令。依赖为 NumPy、SciPy、pypolsys、threadpoolctl 和 Matplotlib。

```sh
python src/measure_select.py
python src/measure_acquire.py
python src/measure_recover.py
python src/measure_score.py
python src/measure_plot.py
```

区域动作已生成时可以运行 `python src/measure_recover.py --external results/region_actions.json --external-only --tag _region` 和 `python src/measure_score.py --tag _region`。第一块读数对照使用 `--half-only --tag _half` 和 `python src/measure_score.py --tag _half`。

独立噪声对照依次运行 `python src/measure_validation.py generate`、`python src/measure_validation.py fit`、`python src/measure_validation.py score`。各阶段通过公开读数和完成后的预测传递结果。

保留区域生成后，可运行 `python src/measure_region_refine.py fit` 及 `python src/measure_region_refine.py score`。新材料组对两个命令都加 `--validation`。区间半径计算另用 python-flint。

成本消融使用 `python src/measure_posterior_ablation.py fit`、`python src/measure_posterior_ablation.py fit --validation` 和 `python src/measure_posterior_ablation.py score`。逐案保留盒与测量决策按案例写入同一结果目录。
