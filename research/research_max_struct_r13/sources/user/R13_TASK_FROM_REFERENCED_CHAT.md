## 2. Pro最新研究：需要继承什么

最新 Pro 研究提出 **Finite Normal-Memory Material Events**。

基本思想是：在共享材料场—电流投影中，DR会积累传播—观测约束与材料本构约束之间的法向gap。材料投影在一定距离内保持原分支，随后可能发生有限材料分支切换。

对于近似AP停滞对

\[
c=P_{\mathcal C}(a),\quad
d=a-c,\quad
e=P_{\mathcal A}(c)-a,
\]

可以利用每个cell的共享材料几何，计算首次分支竞争阈值 \(t_{*,i}\)，并考虑事件式DR proposal。

该阈值进一步可以通过 Maxwell 接收伴随场与源场联系起来，从而不只是普通的几何外推。

Pro已经完成：

- 解析的有界实材料首次事件推导；
- 与Maxwell源—接收伴随结构的联系；
- 近似停滞对误差分析；
- 三个真实576材料未知量Maxwell状态的事件预测与继续实验；
- G19辅助current表示、AP/DR候选池和corrector机制审查。

三个已暴露对象的首次大材料跳变索引预测全部正确。

但算法恢复结果有限：

- 开缝壳：事件方法与普通DR接近；
- 持续失败对象：预测正确，但所有方法仍失败；
- NN受损对象：事件方法成功改变恢复分支，但原始NN初值直接运行已有DR仍更好。

因此，**数学事件预测已得到初步验证；事件能否真正改善材料恢复、降低计算成本，还没有证明。**

特别注意：

1. 精确AP最近点对上的整数跳步，只能省略普通DR中投影影子不变的迭代，不产生新的恢复能力。
2. 近似AP对上的事件外推属于新的有限状态扰动，可能改变basin，但没有恢复保证。
3. 预测材料分支改变不等于预测正确材料。
4. AP准备成本、完整物理审计、corrector、setup和失败运行必须全部计入。
5. 当前结果来自已暴露对象，不是独立确认。

请独立检查Pro的数学结论、代码与数据，不要直接把研究报告中的假设当作最终结论。

## 4. 核心任务B：研究G19、DR与辅助表示的根本差异

G19是我从CIE发展出的非局部Green材料反馈算法，而非外部方法。

R11/R12已经表明：

- G19在部分高对比对象上能显著改变恢复结果；
- DR可以从部分G19坏状态找到不同材料分支；
- 相同材料初值不等于相同完整辅助状态；
- 受限Fourier/DPCS可能引入材料依赖的profile偏差；
- 初始current损失大小本身不能有效预测最终恢复差异。

请严格区分以下因素：

1. 完整current与受限辅助current表示；
2. Fourier截断与DPCS硬锁定；
3. G19材料反馈；
4. AP与DR反射动力学；
5. 物理候选审计次数和选择规则；
6. 最终corrector。

特别希望实现有资格的 **full-current/NFFT G19** 对照，并尽量保持原有G19材料更新、β、先验和计算预算。

同时比较成熟NFFT-SOM，而不是把解除DPCS本身当作新发现。

重点探索受限current的材料profile惩罚，是否会系统性改变某些可观测材料方向的可访问性。

如果发现真正的新结构，可以据此设计更简单的新算法；不必强制继续使用G19或DR。

## 7. 非常重要：失败后的自主研究与迭代

**不要设置莫名其妙的gate，然后gate未通过就停止整个研究。**

例如：

- 事件预测不准确：分析近似误差、状态度量、法向偏离和材料投影分支；
- 预测准确但恢复失败：分析事件之后访问了什么材料区域，为什么不是正确分支；
- 事件方法不如普通DR：尝试改变触发时机、搜索动作或研究路径，检查是否应该放弃事件加速而保留其理论解释；
- 新算法增加大量成本：调查是否可以省去AP准备、复用投影、采用FFT/Krylov或设计更便宜的触发；
- G19与DR差异不明显：检查表示空间、候选审计和初始化混杂因素；
- 三维或Fresnel失败：检查物理模型、标定、离散和预算，尝试合理修正；
- 新独立对象没有优势：研究反例，判断理论是否过窄，必要时开发替代机制。

**失败应该触发诊断、修正、重新实验或有根据的路线转换，而不是直接终止。**

允许自主探索新的数学结构和算法，不必只执行上述清单。

但必须遵守科学实验规范：不能使用测试GT做在线选择，不能看到独立确认结果后修改规则再称其为盲测，不能隐藏负结果或削弱成熟基线。

必要的物理与数值检查必须做，但检查失败应当先分析和修复，而不是人为把整个任务卡死。
