# R13 A+ 全48对象补充

本补充保持原A+、物理观测、576实材料空间、prior、初始化、选根和120秒整进程CPU合同。原16份A+运行复用，补跑同48集合中的32份；CIE、Dual-CIE、G19、DR使用原主比较的完整48份，不重复计算已经付费且来源相同的基线。

这是既有公开对象上的后续扩展，不称新盲确认。参数不会根据新A+评分调整。完整性能结果先封存，再离线评分；额外动力学采集属于单独收费的OFFLINE_DIAGNOSTIC，不替代未插桩的主结果。

失败诊断保留材料误差、原物理Phi、数据项/先验、投影梯度、辅助状态及活动box，区分预算停机、表示偏差、错误分支和候选/corrector选择。不会把较低残差或一次材料跳变自动解释成恢复。
