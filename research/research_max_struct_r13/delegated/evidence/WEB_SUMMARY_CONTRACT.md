# Optional parent-authored WEB_SUMMARY contract

Source-only website extension; no page rendered or published in this change. Parent may create R13-root WEB_SUMMARY.json after sealed scoring. If absent, builder retains ordinary evidence navigation without conclusions. The builder performs no scientific synthesis.

Fields: optional title string; lead string; findings list of objects with text string and optional label string; optional table object with columns string-list and rows equally sized string-lists; figures list (at most4) with path string and caption string; limitations string-list. Supply only actual reviewed conclusions and exact table values. No placeholder numeric example or summary file was created.

Summary lead/findings/comparison and curated figures precede complete navigation. Every curated figure must resolve beneath actual analysis/, exist, have an image extension and contain no fixture/fake path component; absolute/escaping paths are refused. Captions/text are HTML-escaped. Analysis data tables and truth/prediction arrays are never opened by this builder. Existing Chinese report and GitHub project links appear in primary navigation. BASELINE_AUDIT/METHODS_AND_ABLATIONS/BENCHMARKS/CHAT_HANDOFF/THEORY_STATUS/PRIOR_ART links appear only when files exist.
