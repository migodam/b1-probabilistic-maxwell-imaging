# Additional continuous point control — implementation only

`python -m wr.continuous_point_control` is an explicit future serial-queue entry. It was **not run**. Import/AST checks and one explicitly synthetic affine complex-array check constructed no Book and paid no RHS. The synthetic check verifies interpolation derivatives, shared-gain profiling, recovery of a property-boundary minimizer, and required `best` fields; it is not Maxwell evidence.

Inputs are the frozen P1A probability gate/public paid full9 tensor bank, P1B observation-only `OBSERVATIONS.npz` (`y`, `parent_ids` only), complete inference results, and complete original point validation. It checks 32 observation IDs and 16 parent IDs with two observations each. Before new physics it verifies the existing bank's literal public-family, wall arrays and seven physics-source snapshots using the existing read-only `_contract(...,create=False)`. No prior, protocol, accounting or physical source is changed.

Each branch optimizes scaled coordinates in [-1,1]^2 corresponding to u in [-.01,.01], contrast in [2.94,3.06]. The existing barycentric tensor Lagrange basis supplies responses; exact polynomial derivatives plus the shared-gain profile envelope supply the array gradient. Three deterministic starts are full9 best, center and one property boundary (choose the better endpoint at the best-grid offset using only proxy Phi). Bounds include the property endpoints. Initial points remain eligible if numerical optimization deteriorates. The final reported proxy gradient is projected in scaled coordinates; it is not an actual Full gradient or a global MAP certificate.

Exactly one proposed point per branch/observation can reach `Family.point`. Shared amplitude/phase are profiled jointly across all five frequencies and four sources in the original [.99,1.01] × [-.01,.01] box. After actual evaluation, shared gain is fitted again to actual F. Actual profiled Phi selects between both branch candidates and the already Full-checked direct-grid point, including its existing full9 fallback when present. The validated direct point is also reprofiled, strengthening it without changing old result files. Selection never uses truth/material error.

`results/P1B/continuous_point_control/RESULTS.json` is a list of 32 rows with:

- `observation`, `parent` and `best`.
- `best`: `branch,u,contrast,amplitude,phase,x,Phi,physical_source,response_error_white,potential_error,actual_full_response=true,actual_Full_KKT_certified=false,selection_source`. It may be the old validated direct point. Its response/potential errors are zero when it is the unchanged actual baseline; candidate errors refer to full9 proxy versus actual F, after reprofiled gains for potential.
- `baseline_direct_grid`, `candidates` (two records), `actual_Phi_improvement`, `cost`, `truth_access=false`, `inference_frozen=true`, `global_continuous_MAP_certified=false`.
- Each candidate retains the three array starts, optimizer exits, array evaluation/CPU/wall costs, proxy gradient, exact floathex reuse flag, response/potential error, new RHS and evaluation CPU/wall time. Error >.05 in either response whitening or profiled potential sets `proxy_geometry_qualified=false` and `UNQUALIFIED_PROXY_GEOMETRY`; this does not erase the paid actual point from selection.

Per-observation/branch folders preserve `PROPOSAL.json`, `PROXY.npz` (F/q), `FULL_EVALUATED_POINT.npz` (actual F, proxy F, q, latent coordinates/gain), and `RESULT.json`. A newly paid `physical/` folder retains all original Family/Forward frequency field/current arrays and receipts. Exact cache hits retain `physical_source`/`fields_source` references to already paid archives rather than claim a fresh LU or fabricate fields. Existing successful point-validation endpoints and public bank indices may supply only identical floathex tuples. Array preparation and all total elapsed CPU/wall time are recorded; the queue wrapper remains responsible for whole-process root job CPU accounting, avoiding a second nested solver charge.

The independent `P1B_CONTINUOUS_POINT_CONTROL_V1` scope reads cumulative reservations and attempt markers from the root ledger each time, serializes checks through a persistent scope lock, and delegates to the original Book('P1B') stage limits. At most 64 started vectors (including failed/partial ones), 1280 new complex RHS total, and sufficient space for a full 20-RHS vector before its start. There is no budget transfer/reset. Existing output causes refusal; partial/failed jobs never retry automatically. `FAILURE.json` preserves active observation/branch and completed rows/remaining endpoint artifacts. Final `COMPLETE.json` exists only after 32 finished observations and has status `FULL_CONTINUOUS_POINT_CONTROL_COMPLETE`, `truth_access=false`, `inference_frozen=true`, `observations=32`.

This is an extra strong ordinary point baseline. Original four arms, Bayesian probabilities, prior/noise, pass thresholds and independent scientific verdict remain unchanged. No automatic GO is produced.
