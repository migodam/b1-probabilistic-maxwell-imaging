已定位的具体实现问题

自己的 src/solver.py:157-186 并不是成熟的反射信赖域约束 GN。它对无约束耦合 LM 解逐分量裁剪到盒内，最多尝试八次阻尼；没有有界子问题、反射步、有效集再求解、显式步长信赖域或投影梯度方向备用。小投影步分支在 166-170 增加阻尼，从而通常使步长更小，随后可进入 GN_NO_ACCEPTED_STEP，即使前面的投影梯度检查尚未满足。这个分支是可产生假停止的实现缺陷；不能把该停止视为局部最优证明。

原始 max_gn_iterations=1000 又构成了已被运行记录证实的预算失配：部分方法在仍接受改进步时达到循环上限，提前于 90 秒退出。独立 BUDGET_FILL 补充保留了这些额外计算与结果，不能抹去原始主批次的失配。

但这两张 Native 高残差图的直接记录不是八次拒绝停止：它们在第 999 步仍接受，阻尼约为 489 和 224。补足到 90 秒之后仍只是缓慢改善。这说明当前观察到的是严重受限的小步/边界轨迹；以上代码问题不能单独证明它是全部原因，更不能先宣布物理问题本身困难。

公开在线材料显示：obs_a63df7f20566 的 Native 补充端点约 93.1% 单元位于盒边界，obs_42c48e795766 约 64.1%；对应状态线性方程相对残差分别约 1.69e-15、2.03e-15。低线性求解残差不能证明 Jacobian 在该端点正确，也不能证明优化收敛。

对照 Route B 与 Route A 的代码差异

Route B 的 shared/invert_digits.py:64-86 有显式信赖域范数限制、多个 alpha 的回溯线搜索，拒绝后同时缩小信赖域并按 patience 继续；不是我们的八次阻尼裁剪循环。它的物理/参数问题也不同：已知 ROI 上的 256 个占据变量与复对比参数，不能把它的图直接当作本任务 576 个自由实材料变量的同等证据。

Route A 的 src/gsda/fwi.py:153-202 使用缩放坐标下的成熟 L-BFGS-B、显式有界参数、缩放投影梯度和两个公开起点；还具有不同的墙体/目标参数、物理频段与先验。它是优化实现的参考，不是可直接复制数值或判定材料恢复成功的公平基线。

隔离诊断

trf_diagnostic.py 使用 scipy.optimize.least_squares(method='trf', tr_solver='exact', x_scale='jac') 替换三个材料层的自制 GN，保持本任务完整 576 物理网格、盒 [0.5,20]、均匀材料 1、8/12/24 双线性材料族和原始 generic smoothing/TV 目标，仍为每图 90 秒。阶段累计墙钟比例保持 .23/.27/.50。不再保留自制粗层的 320 次 GN 上限；这是明确披露的优化器诊断变化。

平滑项和 TV 以完全等价残差及解析 Jacobian 加入：令 q=sqrt(d²+eps²)，rTV=sqrt(2 lambdaTV/nedge)*d/sqrt(q+eps)，其导数为 sqrt(2 lambdaTV/nedge)*sqrt(q+eps)/(2q)。因此 .5||rTV||² 正好等于原始 TV 项，没有更换先验或做数值差分。

所有前向 LU、源 RHS 和完整 Jacobian 接收转置 RHS 仍由原物理账本计数。SciPy exact TRF 内部使用的密集子问题分解未逐次插桩，整体 wall/CPU 已计入；不能把它当成零成本。

来源冻结在 audit/FULLJ_DIAGNOSTIC_SOURCE_SNAPSHOT/FREEZE.json，时间早于两张诊断预测，但晚于主批次评分。诊断病例是根据已可见的高数据残差选取，不能伪装成新盲测。尚未据此恢复 Gram 的优势归因。

两张成熟 TRF 结果与一次端点核验

obs_a63df7f20566：TRF 用时 90.152 秒，完整数据相对残差 0.8901475；640 次 LU / Full-J、38,400 个复物理 RHS。obs_42c48e795766：TRF 用时 17.540 秒，在 ftol 条件下结束，残差 1.0582021；89 次 LU、86 次 Full-J、5,196 个复物理 RHS。后者最后一级有 571/576 个活动边界，SciPy scaled optimality 约 1.21e-7。这些结果不支持把原始坏结果全部归咎于自制 GN，也不支持将其宣布为强普通优化器已被排除。

针对第二张失败端点，执行唯一一次获准的方向导数核验：相对 Jv 误差 1.36e-9，通过宽松接线核验阈值 1e-3。该核验另付 3 次 LU、84 RHS、0.064 秒 wall，记录在 FULLJ_DIAGNOSTIC_ENDPOINT_DIRECTION.json。它仅检查一个端点一个方向，不构成收敛或全局证明。

因此不运行九图 TRF 扩展。下一项获得授权的控制是改变前向材料幅度的低对比度物理区间敏感性；必须独立标注为 POST-GT 开发，不能替代原高对比度恢复任务。生成器掌握两张原材料，求解器只接收重新匿名化的 Y。

从完全相同公共粗层初值启动的 TRF

补充控制只取 obs_42c48e795766 原始冻结 Native 记录中 stage24.initial_material，不读取真值。它与同图 GlobalDual 的公共细层初值逐单元最大差为 0.0。不重跑粗层，仅给新 TRF 分配 90−27.3601567=62.6398433 秒；新建模型与新 LU 均付费。原粗层计数仅作分配参考，不能再次加入整个研究成本。

新细层实际用时 62.865 秒，338 次 LU / Full-J、20,280 RHS，数据相对残差 0.3909565；分配的粗层参考加细层实际为 90.225 秒。它比自制 Native 补足预算后的 0.4217865 好一些，但仍未恢复低残差，因此“完整 TRF 失败只是换了粗层初值”不能单独解释。这个单例仍不排除其他普通初始化、频率/对比度延续或更强有界优化方法。

低对比度两图控制的公共数据残差分别约 2.125e-4、1.883e-4，用时 8.593 秒、0.558 秒；同一自制 Native 在较弱材料幅度下迅速拟合。二者最终 576 维都构建了完整 Jacobian，并在第一次梯度检查停止，细层没有接受新步；不能描述为已进行大量独立细层优化。材料图像是否恢复由生成器一侧独立评分，求解器没有读取该真值。
