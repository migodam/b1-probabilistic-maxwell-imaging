# Local synthetic digit generation

Pillow renders locally installed macOS fonts at 12x supersampling; no MNIST, network dataset or downloaded glyph is used. A glyph is fitted inside an approximately 18-by-20-pixel interior, then transformed by a small subpixel shift, rotation within ±7 degrees, width scaling 0.9–1.1 and stroke dilation 0–0.5 final pixels before antialiasing to 24x24.

Each target mixes a constant background sampled in [0.8,1.5] with a constant stroke value sampled in [8,18] using the alpha image. The material bounds [0.5,20] hold. The truth mask is alpha≥0.5; reconstruction IoU uses fixed material threshold m≥5. DEV uses digits 2 and 7 in Times New Roman Bold and Courier New Bold. Holdout uses Arial Rounded Bold, one target for each digit 1–9, randomized in order with independent opaque IDs.

Private entropy, labels, mapping and rendering parameters stay in `private_truth`. Public observation NPZ files contain only complex Y, scalar sigma and ID. Shared operators are stored once. The primary nine holdout observations and corrected two DEV observations are exactly noiseless (sigma=0). The original two DEV observations were generated with 1% relative circular complex Gaussian noise before the parent corrected the main contract; they remain explicitly unused noisy DEV draft in `dev_noisy_draft`, with correction recorded in `audit/EXPERIMENT_NOISE_CORRECTION.json`. Their truth is never scored and they are never relabeled noiseless. Truth generation and endpoint validation costs are separate from optimization. Holdout generation requires a parent release and a source/configuration freeze record.
