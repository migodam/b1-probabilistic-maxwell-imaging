# 二维阵列数据冻结合同

本轮二维确认组是在 24 个独立材料上各测量七种 10×20 阵列。同一对象跨阵列共用细网材料及物理参数，各阵列独立抽取 10% 定范数复白噪声。实验使用 400 MHz、边长 2 m 全空间标量 TM，细网 96² 正演，粗网 32² 反演。相对介电对比度 m = εr − 1，粗网评分真值由细网 3×3 面积平均给出。历史两件 120° 失败材料补做开发组的 180°/120° × 10×20/7×14，保留原始 150² 和 96² 细网，并让两个采样密度的角度包络一致。已有 12 件合成及 6 件实测保存于原有限视角实验目录。

沿用历史合成算子的 c = 3×10⁸ m/s、外部接收半径 R = 3.75 m、等面积圆盘脉冲积分及 FFT Toeplitz Green 核。平面波 e^(ik d·x) 中的 d 是传播方向，波从 −d 一侧进入。PW180 和 PW120 的 d 与接收位置均置于上侧名义弧，因而实际收端朝向传播的前方。PW180_FLIP_RX 只把接收弧转至对侧。平面波阵列 PW180/TX 用 [0°, 162°]，RX 用 [0°, 171°]，PW120 对应 [0°, 108°] 与 [0°, 117°]，均保留历史名义孔径的物理端点。PW360 使用半开均匀满周。相同角度包络的开发组按各自端点等距抽样。历史两点 120°×7×14 使用原噪声种子，为开发复现对照。

线源组从 y = R、x ∈ [−R, R] 的十个等距单元中心发射柱面波。二十个接收点沿同侧或对侧的同等跨度直线布置。弧参照把每个同侧直线接收点沿原视线投影到半径 R 的圆弧，保持所有源位置、入射强度、接收角度和通道数一致。每个合成源在同一固定 128² 方域校准网上具有单位均方入射场强。平面波天然满足，柱面波用一次无目标归一化系数。接收场沿用单元积分系数，无几何后增益修正。相对噪声水平针对该阵列的干净散射场范数，绝对噪声幅值随阵列信号幅度而改变。

反演程序可读布阵、网格、测量和已知噪声协议。离线生成种子为材料 20261121021、族分配 20261121022、测量 20261121023。六个材料族分别为缺口偏心壳、偏置双椭圆环、三簇椭圆、错接折臂、偏心核壳、中空多边形与分离条。每族四件独立抽样。族和参数规则只属数据生成及事后评分。公共对象号已置换。无求解器输出参与材料抽样和筛选。

Fresnel Twin 8 GHz 追加数据只选原测量的真实通道。历史连续上半环取九个连续 Tx 和每 Tx 全部可用上半侧 Rx。交错组取九个间隔 40° 的 Tx，从规则的偶数度 Rx 候选中按接收角度均匀抽取，与连续组逐列通道数匹配。共同留出由两者都未看到的 Tx 全可用 Rx，以及两者共同训练 Tx 的下半侧奇数度 Rx 构成。空场入射拟合、60² / 0.2 m 成像窗口、15% 投影球和散射场复共轭约定沿用历史适配器。空场校准与目标散射掩码是两个不同的数据接口。

公开文件必须存放在 data/public，评分时才读取 data/truth 与 data/heldout。准确对象族仅在真值和生成记录中。公开病例的 case_json 仅写实际传感器、通道、网格和已知噪声／校准协议。

## 文件接口与复现

从 Inv_SLAM 根目录运行。实际生成使用 Python 3.13.13、NumPy 2.5.5、SciPy 1.18.1、threadpoolctl 3.8.0，每进程单线程。

```sh
uv run --no-project --with numpy==2.5.5 --with scipy==1.18.1 --with threadpoolctl==3.8.0 \
  python research/srap_cie_array_study_20261121/data2d.py
```

历史算子入口为 [本研究保留的历史 runner 与物理接口](legacy_la.py)，原始 Fresnel 数据路径写入生成成本。可用 `--output` 指定另一输出目录，也可用 `--cohort development`、`--cohort confirmation` 或 `--cohort fresnel` 单独生成。生成结果按对象追加至病例清单。

| 文件 | 字段与作用 |
|---|---|
| `data/cases.json` | 病例清单及公开采样信息。确认 168 例，开发 8 例，补充实测 2 例 |
| `data/public/{case}.npz` | `E[n,nt]`、`S[nr,n]`、`Y[nr,nt]`、`centers[n,2]`、标量 `k,radius,delta`、JSON 字符串 `case_json`。Fresnel 的 `S` 含全部接收位置，训练实际通道由 `rx_ids[nt,nr_col]` 和 `valid_mask[nr_col,nt]` 指定 |
| `data/truth/{case}.npz` | `m[n]` 面积平均对比度，确认组另含材料族 |
| `data/heldout/{case}.npz` | Fresnel 共同未见源的 `E,S,Y`，以及共同已见源的 `E_train_hemi,Y_train_opposite_rx`。复场用有限元素表示真实留出通道，其余为 NaN |
| `data/generation_cost.json` | 算子组装、逐对象正演次数和 GMRES 残差、实测校准次数及开销 |

## 生成与核查记录

24 个确认对象共用一次算子组装，耗时 0.386 秒。744 次独立右端正演合计 24,663 次 GMRES 迭代，墙钟 20.434 秒、CPU 18.144 秒，最大状态相对残差 1.997×10⁻⁸。两个开发材料的算子组装合计 0.442 秒，38 次右端、1,874 次 GMRES 迭代合计 1.732 秒墙钟、1.692 秒 CPU。两件开发材料的 120°×7×14 噪声数据与原病例的相对差分别为 5.47×10⁻¹⁶ 和 4.28×10⁻¹⁶。上述合成计时按算子组装和正演分项记录，文件写入和调度另有开销。

Fresnel 两掩码合计耗时 0.418 秒墙钟、0.341 秒 CPU，完成 18 个空场源拟合。每个训练掩码有 733 条真实通道，共同未见 Tx 有 1,205 条通道，共同已见 Tx 的接收留出有 390 条通道。连续掩码的训练复场、掩码及噪声球半径与历史双半环病例一致。

180° 与 120° 布阵保留历史同一角窗起点，实际角窗中轴相差 27°。固定孔径的密度比较保持中轴和端点一致。孔径比较反映这两个具体角窗，包含中轴随角窗改变的影响。Fresnel 比较同时改变 Tx 和 Rx 掩码，所得结果对应整套布阵变更。

独立 GitHub 布局缺少历史实验目录时，脚本使用同目录的 `legacy_la.py`。可将 `FRESNEL_2005_DIR` 指向含 `FoamTwinDielTM.exp` 的解压目录。合成组可用相同入口单独重建。实测输入来自 IOP 的 [Geffrin 等 2005 论文](https://doi.org/10.1088/0266-5611/21/6/S09) 附件 `supp.zip`。本实验使用项目已保留的 IOP 附件原文件。2026-11-21 原补充材料地址的命令行访问返回 HTTP 403，下载成功取决于读者的访问条件。[IOP 补充材料页](https://iopscience.iop.org/article/10.1088/0266-5611/21/6/S09/data)
