# 二维研究的先例与比较口径

| 先例 | 已有思路 | 本轮可验证的差异 |
|---|---|---|
| Zhong 与 Chen，2009，TSOM | 从接收算子奇异谱取得可直接定位的对比源部分，再迭代更新信息薄弱的部分 | SRAP 在迭代里显式截取沿内部 Green 算子传播较强的弱接收方向，再在该子空间回注一次投影更新。[论文](https://doi.org/10.1088/0266-5611/25/8/085003) |
| Zhong 等，2016，NIE | 从原 Lippmann–Schwinger 方程引出一族变换方程，用于强非线性逆散射 | 本轮保持原物理审计，在成熟 CIE 双参数迭代中比较受限投影对材料图的影响。[作者机构论文记录](https://cv.hal.science/dominique-lesselier) · [论文 DOI](https://doi.org/10.1109/TAP.2016.2535492) |
| Zhong 与 Xu，2019，Dual-CIE | 电流与材料可用不同的收缩参数，结合 FFT-TSOM 处理二维和三维逆散射 | 对照两臂共用双参数框架、源列更新、切换日程和预算。本轮对照检验路由投影的净效应。[论文 §2.4](https://www.mdpi.com/2313-433X/5/2/27) |
| Xu 等，2023，有限视角 CIE-SOM-NET | 在 CIE 框架下用学习式展开处理有限视角定量成像 | SRAP 以已知接收和传播算子构造一次无训练投影。范围由匹配通道数量的阵列实验检验。本研究未测其公开数值优势。[IEEE 论文](https://doi.org/10.1109/TAP.2023.3305834) |
| Zhong 等，2020，IMSA–CIE | 在 CIE-I 中集成迭代多分辨率，已有数值与实测对照 | 本轮主要比较统一固定反演网格上的投影规则。合成正演细网用于模拟与反演的离散化差异。[作者机构记录](https://iris.unitn.it/handle/11572/260153) |
| Geffrin、Sabouroux 与 Eyraud，2005 | 提供非均匀柱体自由空间散射测量和实验精度描述 | 本轮固定相同训练通道数量，比较连续与交错阵列，并在共同未见通道上评分。[实测来源](https://doi.org/10.1088/0266-5611/21/6/S09) |

这里的 Dual-CIE 指沿上述双参数思想、经本项目实现与冻结日程定义的对照。有限视角 CIE、接收弱子空间、双参数日程、FFT、多分辨率和 Fresnel 验证均有先例。可单独检验的新干预是源列 Dual-CIE 内的一次弱接收且强内部传播子空间投影，以及它在孔径和照明变化下的材料恢复结果。
