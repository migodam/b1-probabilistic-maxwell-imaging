## Available extension seams and important limit

1. **Basis/material factory:** R13 `src/full_current.py:36–47` privately rebinds function globals with `_local_function`. R14 `supplement_observable19/src/observable19_factory.py:47–169` uses this to replace `prepare_full` and observe the original `full_material_readout`, leaving original R8 PR code and R10 material derivative intact. Actual setup operations and inherited nominal labels are kept separately by its receipt observer. R10 `src/lowrank_denominator.py:16–34,113–128` already implements `prepare_twofold`: strong right singular vectors of S plus orthogonalized residual of strong right singular vectors of G, each initial strong cutoff.1, residual cutoff1e-10. This is a **variable-rank** union, not the fixed19 R14 single-basis construction. No new R15 rank/cutoff rule is chosen here.
2. **Per-update observer:** R8 `src/cie_fft.py:320–322` calls `iteration_callback({stage,iteration,m.copy(),J.copy(),coefficients:A.copy(),operation_counts})` after material update and history append, before iteration counter/convergence check. Its return value is ignored. Q, PR gradients/directions, JD/Vd and frequency map are absent. R13 `src/full_current.py:183–193` first increments progress and performs its normal paid periodic physical audit, then invokes the supplied observer, then checks the budget. An observer can generate additional candidates; it cannot replace/restart the native PR state via an existing API.
3. **Material callback:** R8:282–295 accepts returned `(m,inner)` from `readout(blocks,J,Q,m,beta_m,Os,Ls,rho,(lo,hi),reg,config,cost)`. It provides Q but only writes back m. Mutating J/Q in place would leave Fourier coefficients A inconsistent; this is not a valid current-restart seam. Original PR memory is then assigned at296 and is not reset by the material callback.
4. **Stage observer:** R8:332–337 exports copied m/J/Q/A, both betas, receiver rank and basis_info. Return value is ignored. It occurs after stage physical validation and before saved-frequency transfer.

The minimum candidate-only wiring can reuse the per-update observer and original DR projector methods, with an R15-only addition of `Q.copy()` to the payload to avoid a fresh uncounted reconstruction. Any paid physical audit must pass through the original candidate accounting under the same absolute budget. A trajectory-changing integration instead needs an explicit consumed-state/restart hook in an **R15 copy** of R8: writeback of m/A/J/Q, PR memory reset and convergence-delta semantics must be defined. Reprojecting a DR current into the restricted affine Fourier/DPCS family is a separate paid operation, not something the current callback already supplies. These are API constraints; parent decides which behavior to freeze.

## Native PR state and numerical definitions

R8:154–218 builds fixed DPCS `Vd`, affine `JD`, cached `GJD/SJD`, stage `U=NativeFourierAPCS`, selected frequencies and A. `J=JD+U.apply(A)` and `Q=E+GJD+green.apply(U.apply(A))`. A has complex[k,ns]; m is real[N]; J/Q are complex[N,ns]. At24² N=576, but k is a native coefficient count, not independent spatial rank. R13:195–225 records actual independent rank and real source-current DOF separately.

R8:221 resets `old_grad=old_direction=None` at each stage. R8:241–276 computes the original coefficient-space gradient, PR+ ratio using real Hermitian products (globally or sourcewise), a non-descent reset, and exact quadratic line step. R8:296 retains grad/direction after material readout. Exact replay requires A, m, JD/Vd/U frequencies, stage and iteration counters, old_grad/old_direction, source metrics Od/Os and roots Ld/Ls, rho, current/material betas, bounds/prior/config, cached actions and counters. Existing callbacks are **not full PR checkpoints**; final return only provides stage snapshots, scalar history/candidates and last_joint_m. R8's inherited stop uses the global coefficient_tol at326; per-stage tolerance fields are inactive on this backend (R13 receipt:266–268).

The scalar history fields at R8:306–319 already include data/state before and after current step, final current/material state terms, prior, PR_plus, alpha, restart flag, coefficient-relative squared change and material movement. They support paid-history bookkeeping without recomputing a physical forward. They do not export gradient/direction arrays. Exact source signatures/line ranges in JSON distinguish metadata from live numeric state.

## Reuse exact DR projectors and scaling

R12 `src/field_current.py:125–425` implements `DenseFieldCurrentProjectors` and is byte-identical by direct text comparison to the existing portable R14 supplement copy. R14 `runtime/equal_budget_C2_runner.py:173–176` constructs it with `grouped_ports=True`; class default is False, so callers must retain the intended path explicitly.

- State is `(X,Q)` with `X=J/scale`, not `(J,Q)` at unchanged scale. The metric is `||J/scale||²+||Q||²`; default scale6. Material shadow is shared real m, and uses alpha=m/scale. Port map T=scale*S before mask/whitening (R12:201–213).
- `material(X,Q)->(cx,cq,cm)` reuses stable bounded-real stationary roots plus both endpoints, all sources/components per cell, deterministic first minimizer (R12:387–425).
- `affine_ball(X,Q)->(ax,aq)` projects to propagation graph intersected with **one global** whitened data ball. It uses retained `H=I+(scale G)* (scale G)` Cholesky, unique-port eigensystems and one shared multiplier. R14 uses the grouped source path; no sourcewise independent noise balls should be substituted.
- Inherited DR order is `cx,cq,cm=material(X,Q)`; `ax,aq=affine_ball(2cx-X,2cq-Q)`; `X+=omega*(ax-cx)`, `Q+=omega*(aq-cq)` (R12:515–521; C2:246–248 uses omega1). The material shadow cm here is from the **pre-update iterator**; C2:249–251 audits that cm, not an automatically recomputed shadow of the new reflected state.
- `run_projection(...)` (R12:428–532) reinitializes by physically auditing an initial material; it does **not** accept an arbitrary supplied reflected X/Q state. For periodic continuation, reuse projector methods and inherited update order rather than pretending this driver resumes X/Q. It starts its own relative clocks after separately measured setup and checks budgets at iteration boundaries; the C2 wrapper instead uses an absolute process clock. A nested call must not create a new120-second allowance.

DR setup counters are `H_cholesky`, `H_setup_rhs` (one RHS per receiver of each unique port map), `port_eigh`; step counters include `H_iteration_rhs` (ns each A projection), C/A projections, Green/adjoint/receiver actions/RHS and multiplier evaluations. These are background projection/auxiliary costs, **not** the physical Maxwell model's material-dependent LU/RHS. Setup, failed and overrun operations stay paid; don't add role RHS again to an existing aggregate or add wrapper CPU to child CPU.

## Budget and physical candidate accounting

R14 C2:23–98 starts absolute `time.process_time()` cap including imports/setup. Proposal deadline is cap×.6; corrector sets `deadline=cap` at259, preserving unused proposal time without restarting the clock. `BudgetEnd` inherits BaseException. R13:164–179 checks before physical state, after it **before dispatch**, and after audit callback; an overdue physical solve is charged but not forwarded as eligible. A new callback must retain these checks, including final receipt handling.

C2 record77–97 stores m/j/Q/Y_prediction plus original Phi=D+R, D/R, absolute CPU, phase, residual/noise feasibility, legal/eligible, deadline and cumulative physics counters. Global primary is minimum Phi among legal eligible completed candidates. Raw is the best after proposal **including initial**; corrected is phase-best corrector or earlier incumbent if no corrector candidate. Secondary minimizes original `(R,Phi)` among legal eligible CN99 candidates. These are different fixed views, not interchangeable online selectors.

C2:267–300 exports lower-case views, HISTORY and `CANDIDATES.npz:m` in matching candidate-index order. Prefix15/30/60/90/120 picks already-paid eligible minimum Phi. `whole_process_CPU_seconds`, physical_cost, projector_cost and auxiliary_receipt are separate; the external Windows whole-child OS CPU includes final serialization. Full reflected X/Q and full PR history arrays cannot be reconstructed from selected physical m/j/Q alone.
