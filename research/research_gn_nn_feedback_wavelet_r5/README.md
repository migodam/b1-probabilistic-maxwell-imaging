# GN–NN R5：正反向耦合、完整小波与物理闭环 CNN

[中文结果与真实成像](RESEARCH_REPORT_ZH.md) · [数学推导](MATHEMATICAL_THEORY.md) · [算法](ALGORITHM.md) · [复现](REPRODUCE.md) · [权重与数组](ARTIFACTS.md) · [下一步理论交接](CODEX_TO_PRO_HANDOFF.md)

GN输出为起点；全部学习模块为CNN。训练每批实际计算完整非线性Maxwell材料场并通过解析伴随反传。完整Haar/db2保留全部576个系数；闭环采用固定条件先验、正定CNN度量及合格物理下降，无需在每轮补偿中求完整L逆。

实际完成两种GN输入、11次从头训练、78个VAL母体的156份观测、792个匹配物理校正任务。属于DEVELOPMENT，不是新鲜TEST；所有图明确标注VAL用于选择模型，具体图像／母体未进TRAIN。

同一Haar模型的noisy原始材料，在加入完整场Loss后数据合格数1/78→58/78；材料NRMSE仅略改善。共同噪声感知GN的匹配72观测联合成功21，Haar闭环校正后25；单种子、有限训练、实际成本不同，普遍成像优势HOLD。辅助能量下降不保证真实场随循环深度改善。

旧R4/R12冻结实现未修改。全部新实现、原始失败、权重、预测、在线候选、离线评分及费用按来源保存。没有NN训练图冒充独立测试，没有Weak64/128。
