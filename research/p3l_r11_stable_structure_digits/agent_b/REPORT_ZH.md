# R11 Sol-B：固定总场基在真实形状更新上的有限检验

**结论：固定总场坐标解决了 R10 旧加权状态的输入支持障碍，但本轮指定的固定 Krylov 子空间仍不足以支持可靠加速。** 在 R10 已暴露的 24 个路径形状、每形状 8 个既存属性节点上，锚点总场基的 32/64/96 维分别只有 0/1/5 个节点通过原白化响应界 0.01 与势函数界 0.1。可选的 128 维通过 14/192，仍有 178 个节点必须真实全阶回退。固定 Green 多项式基在 32/64/96 维均为 0/192。这里没有运行 TSOM 的共享材料与电流系数联合反演，TSOM 状态为 **NOT_RUN**。

本分支使用 27,568 个保守跨阶数 RHS，低于自己的 30,000 配额，新增 RHS576=0。另一个独立审计发现主反演的全阶数 LU 已超过研究合同的 12,000 上限；主线程已停止所有新增物理计算。这个资源合同失守必须保留为 **FAIL_CAP_EXCEEDED**，不能把下面数值输出写成整轮协议 PASS，也不能事后把 LU_all_orders 改释为 LU256。

## 为什么更换状态有意义，但没有自动成功

R10 旧基作用在加权状态上，注入是 P E，其中 P=diag(sqrt(a))。锚点中 a 为零的格点使旧基在这些行恒为零；材料更新激活这些格点后，输入本身就离开旧空间。

本轮直接使用总内部场：

\[
 e=(I-\delta C A)^{-1}E,\qquad F=F_h+\delta O A e,\qquad A=\operatorname{diag}(a).
\]

注入 E 不依赖材料。固定正交基分别为

\[
 V_{a_0,r}=\operatorname{orth}[E,CA_0E,(CA_0)^2E,\ldots],\qquad
 V_{C,r}=\operatorname{orth}[E,CE,C^2E,\ldots].
\]

每个新形状仍重新形成当前的 C A V、O A V 和 V* C A V；没有冻结当前传播矩阵或端口。对每个属性节点解

\[
 (I_r-\delta V^*CAV)z=V^*E,\quad \widetilde e=Vz,
 \quad r_E=E-\widetilde e+\delta C A\widetilde e.
\]

门使用完整 256 行残差。因为 E 已包含在基中，源注入投影缺陷在精确算术下消失；但新 C A 的作用不必保持在固定空间内。因此“输入相同”是一个有利变化，并不是所有材料下的低维不变性保证。固定 C 的多项式空间也不会自动包含所有 C A 交替传播方向。本轮结果仅限定以上基、有限形状与节点；没有证明所有固定总场基、短重用窗口或 TSOM 不可能。

## 门、回退与精确导数

令 B=P C P，beta=lambda_min(Im_H B)，b_delta=Im(delta)/|delta|²+beta。对 b_delta>0，使用当前形状的数值耗散界：

\[
 \epsilon_W=\frac{\sqrt2}{\sigma}\frac{\|OP\|_2\,\|Pr_E\|_F}{b_\delta},
 \qquad \epsilon_\Phi=\|W(\widetilde F-y)\|_2\epsilon_W+\tfrac12\epsilon_W^2.
\]

仅在 epsilon_W<=0.01 且 epsilon_Phi<=0.1 时接受；实际配对误差仅用于事后诊断。所有已计算节点的数值上界都覆盖了保存的实际误差。这是有限浮点离散条件界，不是区间算术或连续 PDE 证书。

每一次失败都另行预留并执行一个 256 维 LU 和 8 个 RHS；没有免费借用已计算的参考响应。固定 rank 不可用时直接回退。生产接口按 32→64→96 有限增阶，所有失败后精确回退；没有无限增阶或运行中扩预算。

`TotalFieldSolver.evaluate(a,delta,need_jac=False,y=None)` 返回 F、可选 J_occ/J_delta 及成本与回退诊断。F 为 (32,8)，复数 J_occ 为 (256,256)，J_delta 为 (256,)，观测行按源优先排列。需要 Jacobian 时，返回精确且相互一致的 F 与 J：1 个全 LU、8 个正演加 32 个转置 RHS。降阶导数没有受控误差界，故状态为 **NOT_CONTROLLED_NOT_USED**。这条实现没有声称降低全 Jacobian 成本。

独立 API 对照使用主线程的电流状态 ExactSolver，而本模块使用总场状态；在一个真实留存形状上的白化 F 差为 3.098e-13，J_occ 相对差 1.059e-15，J_delta 相对差 3.895e-16。它验证接口与排序，没有被扩成全部材料上的数学证明。

所有分母均为 192。`实际误差<=0.01` 不是接受门，也没有用于调参。

| 总场 anchor32 | 0 | 35 | 0.120279 | 1.151694 | 192 |
| 总场 anchor64 | 1 | 63 | 0.041986 | 0.424803 | 191 |
| 总场 anchor96 | 5 | 85 | 0.016462 | 0.258289 | 187 |

重建控制的 8 个未计算节点来自实际基秩为 61 的一个形状；没有把 Fh 占位值当作执行过的 rank64 误差。该控制的误差统计只覆盖 184 个实际小核。

这些数据同时显示真实截断误差与门的保守性。anchor96 有 107 个节点的实际误差已超过 0.01；因此不能把它的 187 次拒绝全归于保守界。anchor128 有 73 个真实超限，另有 105 个实际小于白化门但仍未获完整门接受的节点；因此也不能忽略界与势函数要求造成的额外拒绝。所有最终返回响应均受回退或接受门控制；128 补充窗口最大返回白化差 1.2231e-5。

## 费用与测量范围

主匹配窗口的精确总场 A 参考任务为 0.379320 秒。六个固定总场方法包含必要冷基构造、当前投影、当前 beta/端口范数、每节点完整残差门和实际独立回退后分别为：anchor32 0.714525 秒、anchor64 0.710325 秒、anchor96 0.726678 秒；Green32 0.709422 秒、Green64 0.688723 秒、Green96 0.724460 秒。没有出现冷任务加速。旧加权 anchor64 为 0.697580 秒，每形状重建加权64为 0.380432 秒。

每个总场 rank 都保守计入整个 build-to96 和 projection-to96，而不是把共享成本除给多个 rank。Green 的固定基整个任务只建一次；anchor 的固定基每个 parent 建一次。各方法独立计入必要的当前 beta 与端口范数。参考响应从未充作免费回退。此处不是全部反演与磁盘 I/O 的端到端部署时间。C/O/E/Fh 读取 R9 的历史宿主消元缓存；该缓存原始取得费用为 264 RHS576 与 1 LU576，本轮没有重新取得，不能据此称物理冷启动免费。

128 维在另一个补充窗口测量。按与主窗口一致的小核分项、排除追加日志开销后，冷基 0.103596 秒，当前投影 0.061966 秒，求解与门 0.393547 秒，真实回退 0.530536 秒，总计 1.089646 秒。包含接口日志等全部 evaluate 开销的冷任务为 1.324560 秒。不同窗口不支持统计显著的速度比较。

两次作业合计：RHS256=13,808，RHS32=3,072，RHS64=6,080，RHS96=3,072，RHS128=1,536，总数 27,568；LU256=1,718，LU32=384，LU64=760，LU96=384，LU128=192，全阶数 LU 总数 3,438。跨阶数 RHS 是保守调用计数，不能称为 256 维等价工作量。核心匹配作业 wall=6.7767 秒，补充/API 作业 wall=1.7322 秒。所有数值计算已停止。

## 与真正数字反演的连接

主线程的 N/P 两套数据内，所有物理后端使用相同 decoder、初始化、正则化、投影阻尼 GN、线搜索与预算。N 为新 258 维原生占比材料模型，P 为原 66 维 Gaussian decoder，两套模型之间本来就不同，不能称 N/P 使用同一个 decoder。在线代码只读取观测 y，没有读取数字标签、模板、真值材料或真值 latent。N 的九个精确反演输出实际存在 98—143 个严格零 ROI 占比，确认没有用正数 floor 偷换原生支持。

在已完成的主反演中，Sol-B 对 N 的 1,317 次和 P 的 383 次前向 trial 全部实际回退；每次 Jacobian 调用均精确。因此复用基没有带来反演加速，输出数值上与精确基准一致；Sol-B 与精确基准的最大占比差为 1.030e-11。这个比较不依赖真值读取，不等于重建美观性、材料识别或泛化通过。

审计还发现共享计时器把 `CURRENT_SHAPE_PROJECTED.wall_seconds` 和已经包含它的 `EVALUATE_COMPLETE.wall_seconds` 同时相加，导致 B/C 的原始 `physics_kernel_wall` 重复计入投影。原始文件保留；`MAIN_MODEL_AUDIT.json` 给出仅按父级完成事件加最终精确验证的派生修正值。总端到端 wall、RHS、LU 和科学结果不受此修正影响。

主反演 72 个留存预测的 RHS 总数为 301,056；全阶数 LU 总数为 22,544，单主反演已超过合同 12,000 上限。这是资源协议失败，已报告主线程并停止新计算。数值预测可以作为明确带此限制的诊断证据保留，不能将其包装为预算合规的实验通过。
