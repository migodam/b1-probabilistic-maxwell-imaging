# MAX-STRUCT R10：Green材料分母、能量归因与条件补偿

全部科学任务已完成：24新二维材料×7方法、4个最后独立确认材料、18条真矢量3D主反演及3条固定预算续跑。成功、失败与费用全保留，旧R1–R9未改写。

新矩阵分母恢复了CIE失败的高对比环，也损害其他路径。最后四对象以冻结噪声规则补偿CIE，成功2/4→3/4，同触发Dual重试仍2/4，费用为CIE的1.46倍。小样本支持条件增量，尚不支持普遍替换CIE。原A+本轮没有整体材料恢复优势。
