# MAX-STRUCT R10 — Green material denominators and conditional CIE fallback

Completed evidence: 24 new 2D materials × 7 methods; one exposed three-case PGP→GP correction; four separately frozen conditional-fallback materials; 18 true-vector 3D primary inversions; and three equal-budget 3D continuations.

The default matrix denominator does not beat mature CIE overall. A conditional Green19 fallback recovers one additional independent high-contrast annulus: 3/4 versus CIE 2/4 and a similarly priced Dual-CIE fallback 2/4, at 1.46 times standalone CIE child CPU. All failures and unselected candidate costs are retained. These four cases do not establish a population-wide advantage.

CUDA retained dense LU accelerates the same completed v08 CIE task from 882.21 to 200.07 seconds with similar endpoint residual. This is backend engineering, not a material-recovery claim.

Third-party paper fulltexts, Python caches and duplicate transport archives are excluded; original scientific arrays, partial/failed runs, configurations, receipts and model states are included.
