# 实验、误差口径与复现

全部输入均为 MAX-STRUCT 已保存的复数带噪仿真读数。主比较取 R10 全部 24 个、R11 全部 48 个和 R12 确认组全部 24 个同网格对象。另对 8 个跨网格对象运行了同一求解器，并保留这 8 个对象的同网格观测作为配对参照。6 个已知开发对象用于检查实现。各方法只读算子、观测、噪声尺度和合法材料盒；保存整幅预测之后才运行含真值的评分。开发、局部几何、频带消融和重启可重用同一对象，样本数分开计算。[数据索引与形状](DATASETS.md)

## 计量方法

- 历史幅度 NRMSE 为每格材料 RMSE 除以该物体的最大真值减去背景 0.1。固定支撑 IoU 比较预测与真值各自大于 1 的像素集合，1 为完全重合。历史双判据要求材料合法、幅度 NRMSE ≤0.15 且 IoU ≥0.7。图像相对 L2、整个读数相对误差与幅度 NRMSE 各有分母，逐案文件分栏保存。
- 实际物理读数总由 576 维 VIE 在输出材料上重新计算；噪声单位为每个复通道的 RMS。主结果另报告落在两倍期望联合 RMS 内的份数。这项宽松诊断与历史 CN99 阈值、材料误差达标各自统计。
- 所有当前空间方法从均匀 0.1 起步。这里的“60/180 次”指每案至多允许多少次 576 阶完整系统分解。每份正演含 12 个源，普通数据梯度再用 12 个伴随右端。搬运新读数的做法还要用 48 个接收右端，选物理切线还需解当前状态或约束的系统。记录同时给出完整 RHS 和实测 CPU、wall time。缓存的首次 SVD 约 0.006 秒/组。机器为 Apple M4，线性代数单线程，计时含该方法失败的提案和回溯。各臂独立运行，CPU 秒和允许的分解次数是不同的成本指标。
- R16 的直接比较共用光滑邻差与弱背景先验、物理校正和起点。另将两者一起换成 R10 原材料先验和优化器目标尺度重新比较。原生 FFT-CIE 实验直接调用历史程序，保持每阶段电流共轭梯度、全部材料格点的 Möbius 读出和同一套源权。历史长预算行单列。所有比较均使用旧测量，新增曝光次数为零。

## 先做实际的电流—体素交替

在 R10 和 R12 共 48 例上，先固定材料求电流，后固定电流更新 576 个实材料。开 49 个 Fourier 暗方向后，比锁死电流降低材料相对 L2 的分别为 22/24、23/24。幅度 NRMSE 中位数为 .277/.263，同起点的全波体素 GN 为 .203/.178。暗电流交替 CPU 约 .074 秒/案，材料经全波计算后 0/48 落入原 CN99 球。以实际环形读数为例，源 1 的第一步电流变化量是原电流范数的 80.6%，接收端变化只有该源噪声 RMS 的 0.465 倍。这个例子解释了在电流图上看到大变化时为何还要读回材料。[48 案与原生环图](ALTERNATING.md)

## 用同一个物理目标接受更新

### 是否只是体素优化器的参数碰巧不合适？

把四种代表性方法都接回 R10 原档案的空间先验和全波校正数值尺度，重新跑这 96 案。该先验在历史定义的差分算子上使用平方项和平滑 TV；原目标与梯度同乘 \(10^6\)，原盒约束与停止准则一致，各次完整求解仍按相同上限计费。下表每格为幅度 NRMSE 中位数 / 达标案数。

| 原档案先验与求解尺度 | 60 次 | 180 次 | 180 次 CPU 秒/案中位 |
|---|---:|---:|---:|
| 全体素物理拟合 | .3678 / 6 | .3705 / 8 | 1.379 |
| 48 个 Fourier 方向的顺序两步更新 | .3210 / 9 | .3296 / 11 | 1.382 |
| 用当前更新的总场传递数据 | .3175 / 7 | .3295 / 9 | 1.408 |
| 按当前本构求出最优暗电流 | .3375 / 6 | .3407 / 9 | 1.363 |

同预算的普通两步更新在这个设置下比直接体素更新多 3 案达到材料标准。180 次时，R10、R11、R12 的普通两步达标数依次为 2/24、6/48、3/24；同组直接体素拟合为 4/24、2/48、2/24。180 次时，顺序两步比体素法材料误差改善至少 .01 的有 28 案，恶化至少 .01 的有 8 案；同档 8 个跨网格对象的四臂仍均 0/8。成功数增加和误差中位数略升可以同时发生，因为两者统计的是不同对象。这里的“原档案先验”仅指同一完整物理目标与校正设置，独立的原生 GlobalDual-CIE 阶段对照见后文。[60 次原目标](results/current_summary_archive60.json) · [180 次原目标](results/current_summary_archive180.json) · [逐案 CPU、物理误差与评分](results/current_cases_archive180.csv)

## 输入相同、直接问新方向能做什么

1. **保持同一材料方向。** 在 56 个读数的均匀初值和体素拟合后分别计算可表示比例。均匀初值时旧 48 个 Fourier 方向中位 33.11%，全部暗方向的严格上限 33.48%。拟合后有 55 个非零可行材料梯度，旧 48 个中位 33.95%，欧氏投影加入至多 12 个切线方向为 75.08%，按照 \(L_m\) 的本构度量选取为 78.96%，达到全部暗方向的理论上限。放开强接收方向后对指定方向为 100%。第 56 例 \(\texttt{r10_twod_0010}\) 的盒可行梯度为零，保留在谱统计，不为零向量定义比例。对照中，随机实材料方向仍只约 8%–9%；数学最优字典对一个指定单格变化的拟合后比例从 8.13% 变为 6.37%。[112 个位置的原始谱与方向](results/current_geometry.json)
2. **保持同一批待选材料。** 对 R10 与 R12 的 48 案，分别在背景及体素拟合后生成相同的候选。完整正演只用于这项离线预测检验。以“预测误差/实际读数变化”为量纲为一的误差，在每个位置先取候选中位数，再跨对象取中位。在背景处普通一阶、用新电流传递、按本构误差混合三者为 .689/.672/.379。到体素拟合后变为 .143/.566/.160，误差最小的混合系数中位从 .421 变为 .086。此时材料变动常已很小，额外的辅助电流自身仍有误差。混合降低部分预测误差，实际材料达标为 5/96。[逐候选全波对照](results/receiver_predictions.json)
3. **保持历史坏端点和目标函数。** 在 R10 用归档 TV 先验和求解器照原尺度重新启动。高对比环 0001、包覆包体 0016、G19 开缝壳 0004 的材料 NRMSE 保持 .423、.465、.515；桥 0022 从 .337 到约 .336。各电流臂在这些坏端点均无可接受的有限电流提案。以同一壳案的 CIE 好端点（.111）重启仍保住原解。改成 R16 的先验时，环可降到约 .294，直接续做体素也到 .297；已恢复的壳反而从 .111 升至约 .224。久经优化的原端点、换过目标函数的初值、真正的非唯一解应分别解释。旧 R3 弯条按自身口径，截取 R16 先验后体素续算和各电流方法都从 .511 到约 .404，各电流提案在旧端点均被拒绝。[原目标重启](results/current_restart_scores_original.csv) · [改变先验重启](results/current_restart_scores.csv)
4. **保持原生求解器和阶段数。** 在 R10 原 GlobalDual-CIE 上，每案 24/40/56/80 次更新，各臂实际总 200 次。末段 FFT 模式数从 576 个坐标降到 144 个（全档末段因接收投影有效秩为 \(576-L\)），24 案 CPU 由 24.71 降到 23.92 秒，完整读数误差中位由 2.84% 升到 14.32%。窄频中替掉 6 个 Fourier 模式后为 22.87%；保持原 144 个，再加 6 个 Fourier 模式为 12.79%，再加 6 个首阶段梯度方向为 13.32%。原生每轮仍在全网格做 Green 变换和全像素材料更新。[五种同预算原生运行](NATIVE_CURRENT.md)

## 固定物理开销的频率和发射角对照

上轮 2–30 GHz 板的仿真原档还可以检验电流选模在宽带下的作用。48×48 网格生成、24×24 网格恢复。均使用相同 8 个接收端、8 次发射及单位总发射能量；一次选一个频点和一个发射角。单频、双频、四频分别给 8、4、2 个角，每种有 64 个复通道。每个频率用自己的 Green、源与接收；在所有频率上物体共用 576 个实材料。8 份缺陷分别在无损和已知 Debye 模型下计分，另保留两个空板读数。平衡各频本构权重或在固定49维下纳入强接收分量，均未改善宽带的阈值检测；后一变动还使每个非空对象配置的完整物理残差上升。新增子实验成绩独立于 MAX-STRUCT 96 案统计。[宽带设置、原始分数和解图](BROADBAND_CURRENT.md)

## 可以直接找到的成功和失败

- R12 高对比连续材料 \(\texttt{r12_confirm24_0018}\) 在 60 次 R16 比较中，体素法的幅度 NRMSE .448、IoU .210，传递候选后为 .110、.708，跨过原材料判据。另一个新增达标案例是 R11 的混合开缝壳 \(\texttt{r11_independent_0009}\)。
- R10 低对比穿孔星形 \(\texttt{r10_twod_0018}\) 的 NRMSE 从 2.789 到 .220，尽管支撑 IoU 从 .313 到 .800，材料幅值仍超出 .15 的标准。
- R12 混合水平集 \(\texttt{r12_confirm24_0002}\) 的 NRMSE 从 .453 升到 .540。单个方法既有明显救回的对象，也有引向错误更新的对象。在精确匹配原目标的已知坏端点上没有发现新的合法材料分支。

## 复现

下载研究交接 ZIP，解压后在它的根目录执行以下命令。压缩包含本轮需要的 MAX-STRUCT 固定算子、逐案观测、单独的真值、历史原生求解代码与结果。本次使用 Python 3.12.13、NumPy 2.5.5、SciPy 1.18.1、Matplotlib 3.11.2 和 threadpoolctl 3.8.0。下例中的目录变量仅指解压出来的项目文件。

~~~sh
export R16_MAX_STRUCT_ROOT="$PWD"
export OPENBLAS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 OMP_NUM_THREADS=1
cd research/research_z_alg_r16
python src/check_identities.py
python src/current_cycle.py --cohorts r10_twod --arms voxel_only lagged48 shared48 shared_cubic shared_linear shared_transport --cycles 10 --polish 100 --full-budget 60 --tag _equal_r10_twod
python src/current_cycle.py --score --tag _equal_r10_twod
~~~

用户可自行设定电流自由度。例如使用 \(\texttt{--current-rank 32 --bright-ratio .01 --arms lagged_current tangent_dark}\)。此时两个电流方法都至多使用每发射 32 个复电流模式，材料仍有 576 个实像素。也可用 \(\texttt{--current-modes-file modes.txt}\) 明确传入自己选择的电流空间频率，每行两个整数 ky 和 kx，文件行数决定本次电流阶数。历史标识如 \(\texttt{shared48}\) 中的 48 是本文归档配置；运行时数组中的实际阶数随参数写入。简单交替脚本还可直接选择二维傅里叶窗的半宽和本构权重。

主比较依次更换队列名，60 次普通、切线、最优暗、混合的标签分别是 \(\texttt{equal},\texttt{tangent},\texttt{exactdark},\texttt{blend}\)。180 次上限使用 \(\texttt{--polish 220 --full-budget 180}\)、标签 \(\texttt{long}\)。档案目标使用 \(\texttt{--native-objective}\) 和标签 \(\texttt{archive60}\) 或 \(\texttt{archive180}\)。各文件名后追加队列名。附录每项试验可独立运行，普通队列的逐案数据已随包提供。

~~~sh
python src/summarize_current.py
python src/summarize_current.py --long
python src/summarize_current.py --archive-budget 60
python src/summarize_current.py --archive-budget 180
python src/current_geometry.py
python src/current_geometry_figure.py
python src/receiver_predictions.py
python src/historical_restarts.py --original
python src/historical_restarts.py --original --score
python src/native_current.py run
python src/native_current.py score
python src/native_current.py run_additions
python src/native_current.py score_additions
python src/native_current_analysis.py
~~~
