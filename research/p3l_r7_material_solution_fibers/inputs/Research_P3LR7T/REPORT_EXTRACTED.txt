1       结论与证据资格：哪些演化值得保留

1.1     先给明确判断

这条研究路线发生了三种性质不同的变化。
第一，多解探索转向材料测度与概率体积，是理论深化。 原先的问题“还有什么材料能解释观
测”并未消失。F/F3 已经发现坐标冗余、材料像曲率和非均匀商先验；P3‑L/R4 又表明，相容候
选、轨迹长度和相对 NLL 改善都不能直接充当后验质量。R5/R6 的原子、重叠原像、条件依赖，
正是在修正“应该给谁分配概率”这一基础问题。[证据 H1–H8,R6‑A]
第二，完整后验转向材料任务，是有实证理由的分叉。 R2、R4 和 R5‑B 已独立确认材料平方风险
改善；完整后验仍未合格。这个分叉说明“学到有用的条件统计”与“恢复整个概率分布”需要不
同资格，不说明完整 posterior 没有价值，也不说明剩余多解不重要。[证据 H6,H7,R6‑D]
第三，材料任务转向缩短 Native 阶段，目前主要是工程优化。 R6 的费用收益真实存在，但
Direct Probit、强化 Full‑q 与计时漂移都削弱了“新的任务最优 Maxwell 原理”这一解释。
没有证明概率体积理论导致了这项加速，不能把三个并行结果写成一条已成立的推理链。[证据
R6‑C,R6‑D]

    建议：先集中证明一个物理核心，再决定分成两篇。
    优先做非均匀材料上的“表征冗余 / 真正材料变化 / 强方向补偿 / 有限噪声有效阶”区分；
    随后检验这套几何是否改变可信材料任务积分的成本。当前不建议把 A、B、C 合成一篇总
    论型 TAP 论文。Paper C 保留为计算模块；Paper B 的风险成像结果是较快的算法基础；
    Paper A 中的补偿后响应结构具有更强的理论潜力。

2     Research Evolution：研究理想与每次转向的因果关系

2.1   起点：单幅好图不是全部材料信息

单幅物理最优解只回答某个目标函数的极小点在哪里。它并未回答：还有多远的材料可以解释数
据、这些材料是否属于原先验、它们是否连通、哪类任务在它们之间保持不变，以及不同解释应占
多少概率。一个低残差但先验极小的点，和一大片稍高残差但先验质量很大的区域，可以具有完全
不同的 posterior 重要性。
最初理想应保留为：研究观测仍然允许的不同材料世界，并把几何相容性、概率质量和工程任务的
可判断程度分别量化。 这里“世界”是物理材料，而不是 latent 坐标、current 的任意独立扰动
或网络输出像素。


2.2   L/X/Z：合法材料、局部候选与全局提案

原始设想是从准确 N3 图附近探索，再用全局提案跨越解族。实际审查表明，N3 在指定原 prior 中
未必是合法 anchor：development32 仅两例进 noise‑ball，零例满足原相位必要条件。低 MAE
和原 prior 合法性是两回事。任意复像素补偿破坏固定相位时，不能作为原 prior 内多解。[证据
H1]
这否定了具体的候选解释，不是否定多解。径向 proxy 中正确 global‑MH 的 event MAE 为
0.004364，优于 local 的 0.012039 和 hybrid 的 0.007243，说明全局提案加正确概率修正有受控
正例；复杂 TM 中未找到显著新结构，不能外推为所有问题都没有新结构。

9     三个机制不同、可以实现的算法方案

9.1   方案一：材料补偿 chart 与多解探索

原始问题： 在正确 prior 的材料空间内，寻找具有实际材料距离而仍数据相容的候选，并预测不
同采集如何破坏补偿。历史动态 SVD 只给一阶方向；四段轨迹没有定义概率密度；直接 current
路径可能不对应共享材料。
构造： 在材料 regular strata 建立有限域 response‑aligned charts，使用命题 2 计算各方向的强
补偿与剩余系数；在 rank/seam 变化处开新 chart。选择方向的依据是可行任务位移、响应界及
预计物理费用，不是固定 bottom‑k 名称。

    算法 1：compensated material chart

    输入：合法材料中心、prior/decoder、采集、材料度量、任务、预算。
    1. 分析 DG，验证有限同材料 gauge；只在确认后消去，记录材料 prior 权重。
    2. 在材料正交 frame 上求一阶强/弱结构，选定可行 v, U ，归一化材料弧。
    3. 用同一背景 LU 递推到三阶；给每个系数及余项的误差状态。
    4. 求低阶/高阶/余项共同允许的非空区间；区间为空时使用普通 nonlinear corrector。
    5. 以预测器提议端点，用真实 Maxwell 校正/验证；保留失败和实际费用。
    6. 达到 seam、边界或采集改变时更新 chart；分离等材料副本与真正材料候选。
    7. 若要 posterior，另计算合法 proposal 密度与 prior/chart 权重，做 MH/IS 或可信求
    积；否则仅交付候选及相容性。

适用条件与复杂度： 局部强响应满秩、可行材料 chart、状态可逆；每方向 p 阶约需 pP RHS
及低阶 Green actions，另有初始强基构造、有限端点新 LU。N 个内部自由度的 dense LU 为
O(N 3 )、每 RHS 为 O(N 2 )；矩阵自由/稀疏 3D 改用实际迭代和预条件费用，不外推固定比例。需
缓存场而非保留无限历史 LU。
概率接口： overlapping source images 先把 prior 贡献相加；仅用于覆盖同一材料区域的多个
数值 charts 再用 partition of unity 分摊，避免双计。两种“重叠”不能混为一谈。若无法计算
proposal density，不能给出后验权重。
强竞争： 普通 material retraction、Full‑J predictor–corrector、nonlinear profile、多起点/
RTO、LIS、iTSVD；不能只比较 frozen SVD。决定性实验是 E2 的有限域响应预测及新采集破补
偿，再看同费用有效候选或任务距离。

9.2   方案二：保留分层材料测度的任务积分

原始问题： 准确材料均值、事件和预测散射是否需要相同的分支概率精度？历史局部 Gaussian/
独立边缘会丢条件核；全局网格则漏窄 likelihood；普通样本数无法直接保证功能误差。
构造： 用 µ0 定义正确对象，把原子、regular charts、seam 与遗漏域分别积分；使用中心化任
务 defect 及每块 ab Ub 分配物理预算。可使用方案一的 charts，但没有它也能独立成立，因此这
是不同的数值机制。

  算法 2：task‑certified stratified integration

  输入：有界条件材料模型、任务及容忍度、先验分块、全域覆盖规则。
  1. 解析保留原子与 exact gauge 质量；为连续块建立 source‑CDF 或材料 chart 求积。
  2. 以独立 pilot 定位窄 likelihood，明确所有未覆盖块及 prior 质量。
  3. 同时维护 N, Z, Q = N − tZ 的上下界；物理节点携带 forward 误差及费用。
  4. 计算式 (21)；选 task‑weighted 上界最多且可降低的块细化。
  5. 需要时增加真实 Maxwell、缩小状态误差或搜索外部分支；每步更新总误差预算。
  6. 仅当总界小于 εφ 时认证停止；无可靠包络则输出经验收敛状态，不能自称证书。
  7. 更换为事件任务后重算振幅与误差，不能继承均值的资格。

适用条件与费用： 首先限于 3–4 维、有限支撑或可控 tail 的真实非均匀条件模型。每新材料节
点通常需要一次 LU 和全部源 forward；若求导只为自适应坐标，应检查其节省是否覆盖额外
RHS。不存在一般“降到 quotient 就克服维数灾难”的定理。
强竞争与原创性： source‑CDF 自适应积分、defensive IS/SMC、RTO、goal‑oriented quadra‑
ture、CoCoS 的 regular‑volume 思路。新贡献必须是 Maxwell 分支结构让可计算任务界更紧，
且同精度总费用更低。若只有人工 quintic 原子有优势，适合作为反例/方法附录，不能撑起一般
Maxwell TAP 主文。

9.4   R6 两阶段目标到底哪里不一致

Uniform 属性 u 与 Gaussianized 属性 x = Φ−1 (u) 描述同一 prior 分布；正确换元后 posterior
measure 相同，但 density 的最大点不保持不变。Native 与 Probit 各自坐标 MAP 的不同，不等
于其中一个 prior 自动写错。它说明先优化一种坐标密度，再优化另一种坐标密度，没有普遍的最
优工作分配理由。
Native warm start 可以帮助找到 basin，也可能把属性推向 box 边界，增加后续 Probit 工作。
R6 支持后一机制在当前配置中的描述性解释；Direct Probit 的竞争力使“缩短 Native”更像修
复原流程。若未来数据表明 Native 在强非线性或大尺度有稳定 basin 收益，再保留，而不是为两
阶段结构辩护。


9.5   更大二维与三维外推的界限

三维向量 Maxwell 增加状态分量、网格规模、频率和源数，稀疏/快速迭代的瓶颈与 TM24 dense
LU 不同。current RHS 复用可能更有价值，也可能被预条件重建、通信或非正规性主导。必须
记录 factorization/preconditioner、RHS、Green matvec、内存、训练、尾部搜索和 end‑to‑
end 时间；只用 N 3 或固定源接收比预测百分比加速不可信。首次理论资格可在 2D 建立；强 TAP
的最终物理论证宜补独立向量 Maxwell 小规模 witness 或清楚限制为 TM 材料研究。

12.2 哪些可以永久放弃，哪些只暂停

应永久放弃的是错误命题：noise‑ball 等于 posterior 支持；相容候选的计数或弧长是模式概率；
exact constant‑rank kernel 本质非可积；任意独立正确边缘都保持材料；latent 维数等于材料
更新算子秩；单点 J = 0 意味任务无信息；原子使 latent posterior density 不存在；通过 NI 与
未通过 NI 可直接推两方法显著不同。
暂时暂停的是具体低收益实现：R6 同一任务蒸馏目标家族的继续放大；无正确质量修正的四段轨
迹平均；未先排除简单 Direct Probit 的复杂 stage allocation；在没有可信 reference 前训练更
大 Full66 Flow。它们背后的概率输运、多解探索和任务计算问题仍然成立。

17   十五个核心问题的明确回答

 1. 从多解探索到任务计算，是深化还是漂移？
    材料商与概率体积是深化；任务统计是有独立风险证据支持的自然分叉；缩短 Native 当前主
    要是工程优化，未被前两者推出。不能把整个演化全部合理化，也不能全部否定。
 2. Maxwell 材料多解的正确数学对象是什么？
    带实际材料 prior 的可实现材料集合及 F 的 exact fibers/finite‑noise likelihood tubes；概
    率对象为 Ly dµ0 /Zy ，可含原子、不同维 strata 和重叠原像。单张光滑流形只在适当常秩区域
    成立。
 3. Dynamic weak directions 的原创价值还剩多少？
    作为泛化算法原则原创性有限；作为材料正则的有限幅度候选生成器，以及识别补偿、主导区
    间和采集冲突的入口，仍有实质价值。非对合现象不能单独成为论文中心。
 4. 如何区分 gauge 与真实 Maxwell 不可辨识？
    先验证材料差是否非零，再用材料度量分析 DG 与 DF ；有限等材料见证定义 gauge，单点
    DGv = 0 不够。必须记录材料变化、响应变化、可行 prior 与数值误差四者。
 5. 应否直接在材料商空间 Bayesian inference？
    统计目标应以材料测度定义。计算上，在 exact gauge 可积分且商核便宜的区域可直接做；
    generic 满秩、chart 复杂或核难算时保留 latent 并维护正确联合条件分布更好。不能在混合
    维商上强塞一个全维 Lebesgue Flow。
 6. Full66 posterior 为何未合格？
    已观察到高 SNR 下 importance overlap/ESS、链混合、强弱条件近似、绝对 response
    calibration 与预算问题。R6 又揭示条件依赖和材料奇性，但尚未证明哪一项是全部失败的唯
    一根因。有限 Gaussian likelihood 下 latent posterior 仍对原 Gaussianized prior 绝对连
    续；Flow 不是因材料原子而数学上不可能。方法仍需更好的条件结构、覆盖与成本设计。
 7. 什么概率体积真正必要？
    正确材料 prior 权重、影响指定任务的分支质量，以及遗漏区域的任务贡献界。只求材料任务
    可积分掉 decoder fiber；要模式概率、事件、主动测量或 latent 事件时不能删除相应核与质
    量。不要恢复所有 latent 密度，也不要任意删体积。
 8. rank、effective rank、conditioning 与任务信息是什么关系？
    rank 是局部代数维数；effective rank 相对 prior、noise、可行幅度；conditioning 量化
    局部反演稳定性；任务信息还取决于任务函数与全局分支概率。正则单峰线性近似时可相互联
    系，临界、对称、多模态及分层时差别很大。

    真实材料补偿的有限有效域、共享采集补偿冲突及其对任务可区分性的界。高阶递推和最小二
    乘恒等式自身是先例；需要把可验证常数、物理约束和 finite‑scale 用途连起来。
13. 哪条线较快完成有说服力算法论文？

    不能承诺强 TAP 已具备。
14. 哪些永久放弃，哪些暂停？
    永久放弃错误推论，见原创性节；暂停具体无增量的大训练、无权重轨迹平均与过度阶段优
    化。真实多解、正确概率输运、材料函数量与动态弱几何仍值得研究。
15. 写一篇、两篇还是先证明核心？
    先证明并检验一个核心：材料补偿为何有效、何时失效、怎样被新采集破坏。随后 A/B 分成
    两篇或以自然的共同算法合并；C 暂为模块。当前不写覆盖所有 R2–R6 的统一大论文。



18   最终科学陈述

  有限观测约束的首先是一类材料的电磁响应，而不是一幅唯一材料图像。同一种材料可以有
  多种参数表示；不同材料又可以通过共同的物理补偿产生几乎相同的观测。研究的关键是，
  在正确材料测度上分清这两种不确定性，确定真实材料差异在什么尺度、哪种采集下才开始
  可见，并理解这些差异如何改变指定材料判断。由此产生的新科学问题是：材料间可补偿的
  响应关系，如何决定观测能够消除多少任务相关不确定性，以及为了达到该任务精度究竟需
  要计算哪些物理信息。 这条关系有明确的 Maxwell 机制和可证伪的数值入口；其完整理论
  与算法优势仍需下一轮集中验证。

19.3 可追溯性说明

Disintegration、coarea、隐函数约化、条件期望投影、Bayes‑risk 恒等式、adjoint 残差和分层
最优分配均有成熟来源。独立写出命题是为了证明本问题的适用边界，不是认领全部公式为新定
理。

递推得到首个可用残差系数及有限幅度区间；再用共享补偿冲突识别新采集的物理价值。是否足够
原创，取决于与高阶散射、profile/Schur information 和任务设计的比较。
