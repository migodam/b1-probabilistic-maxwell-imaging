# 普通预测—横向正确的有限探索

这里实现的是一个普通的一阶、可计费的探索机制。先沿弱方向制造一个材料不同的预测点，再用当前精确 Maxwell Jacobian 修正横向方向。它生成有限的候选材料云；优化步数、预算和候选资格都明确保留，不把候选云改称为后验。

实现：`agent_b/engine.py`。主线程负责物理排程、公共 RML 入口、协议冻结、预测封存和最终统计；本模块不含 Maxwell 求解器，不读取真值，不自行扩展预算。

## 1. 唯一共同正确器

给定探索帧 \(W\)，在选定帧的参考点有材料度量 \(G=M^TM\)、\(W^TG W=I\)。冻结弱坐标泛函

\[
C=W^TG.
\]

预测点 \(x_p\) 通过同一组预先给定随机系数生成。先令方向 \(v=Wa\)，再用解码器算术寻找 \(\|m(x+hv)-m(x)\|/24\) 为指定半径的第一可用括区。此阶段没有 Maxwell 调用；始终保留从公共锚点算起的 latent 半径 4 和原先验合法性。

在一次正确器的全部迭代中，约束为

\[
\boxed{C(x-x_p)=0.}
\]

每次实际 Gauss–Newton 步刷新当前精确 \(J(x)\) 和当前材料导数。由当前解码器商空间提升 \(P(x)\) 及

\[
Z=P\,\operatorname{null}(CP)
\]

求解普通一阶正则化子问题

\[
\min_z\ \tfrac12\|r+JZz\|^2+
\tfrac12\|x-\xi+Zz\|^2.
\]

RML 的数据随机目标额外把 \(r\) 改为 \(r-\eta\)。有限 Cholesky 阻尼只保证子问题的数值可解；计数和耗时单独记录，不当作 Maxwell RHS。

原生数字分支若状态提供 `reg_value/reg_gradient/reg_hessian`，则统一改用冻结的原 R11 TV-Huber/L1/ridge/属性正则器：目标为 \(.5\|r-\eta\|^2+R(x)\)，梯度为 \(J^T(r-\eta)+\nabla R\)，PSD 近似 Hessian 为 \(J^TJ+H_R\)。所有原生方法使用同一正则项；不能套用 P1 的 \(.5\|x\|^2\)。其 H0 只随机数据目标，不随机一个不存在的完整 Gaussian occupancy prior。

执行 P1 的默认 `full_coordinate_corrector=False` 保留上述商空间正确器。后续原生版本 N1 在第一笔原生物理调用之前显式设置 `full_coordinate_corrector=True`：H0 的 \(Z=I\)，弱臂的 \(Z=\operatorname{null}(C)\)，允许正则器在材料解码器零方向上移动；原生 box 活动约束也进入同一个零空间。探索帧和材料谱仍然剔除解码器规范。该版本变化不回填为 P1 已执行代码。P1 已执行点的材料导数满66列秩时，两种自由域本来相同。

### 原生 N2 的边界算法版本

主线程报告：N1 的45个运行均已保留，弱预测点被原生 box 合法性拦下，H0 也在活动约束或回溯阶段停止；这些运行只有每臂8 RHS 的锚点引用，且在任何原生真值评分之前结束。这是**边界算法实现未走出候选点**的证据，不能据此宣称 Maxwell 弱方向方法失败或材料空间缺少多样性。

N2 在任何真值评分之前另行声明，只修改有边界的标准预测/正确机制。`native_box_retraction=False`、`active_set_iterations=4` 仍是 P1/N1 默认值；N2 显式启用前者并将活动迭代上限至少设为参数维数加一。

N2 预测轨迹为

\[
x_p(t)=P_{\rm box}(x+t v),
\]

其中 occupancy 投影到 \([0,1]\)，属性参数沿其原坐标变化。材料半径通过这条**实际投影轨迹**的解码值求取，返回的也是实际投影点。输出记录 `retraction_norm` 和 `leaves_linear_weakspan`；发生投影后不再声称预测点仍在原线性弱射线或弱子空间中。此时应称为有界回缩弱方向提案，不能把它包装成严格线性弱方向延拓。

正确器随后仍保持实际预测点的固定弱坐标：\(C(x-x_p)=0\)。不再把未投影的 \(x+tv\) 当作约束原点。

N2 的活动集只加入尚未约束、且向外分量超过 \(10^{-10}\) 的 occupancy 坐标。已约束坐标的舍入残差不重复触发循环；没有新增活动坐标时采用当前解。每次加入仍与同一个 \(C\) 联合求零空间。

对内部 occupancy 坐标可能越界的步，先计算最大可行比例

\[
\alpha_{\rm box}=\min\left(1,
 \min_{s_i>0}\frac{1-x_i}{s_i},
 \min_{s_i<0}\frac{-x_i}{s_i}\right),
\]

再以该可行步进入原有四次实际下降回溯。忽略已受约束的 \(10^{-10}\) 以内分量，并记录比例；不把四次回溯消耗在一个本可直接缩到边界内的步上。目标、原生正则器、物理模型、候选资格和预算保持主线程冻结版本所规定的同一形式。

以上均为普通有界 Gauss–Newton/投影回缩机制，不是新的 Maxwell 原理。N1 原始结果不覆盖、不回填。N2 的材料结论必须来自随后实际逆问题运行；本代理没有再启动物理或新增边界比对测试。

步长同时满足声明的 latent trust 与材料 trust。最多四次实际响应回溯，只接受实际目标下降且仍满足固定弱坐标的点。解码器算术先检查合法性和实际材料步长，再进入物理预算。Native box 的向外活动坐标进入同一零空间约束；不通过截断物理参数破坏 \(C\)。

**不做径向回拉。** 对一个横向步再做非线性径向缩放，会改变冻结的弱坐标，进而破坏这个因果比较。候选最终半径作为结果记录；有限预测半径不是最终正确端点的等半径证明。

## 2. 四个方法的差别

| 方法 | 探索帧 | 正确器 |
|---|---|---|
| H0 / Full-J RML | 完整数据与先验随机目标 \((\eta,\xi)\) | 同一完整坐标普通 GN；没有冻结弱坐标 |
| H1 | 每个公共入口的初始弱帧保持不变 | 当前 J 的同一横向 GN |
| H2 | 初始帧与 H1 相同，在规定层只更新一次 | 当前 J 的同一横向 GN |
| HA | 由已付费缓存反馈条件触发，最多两次更新 | 当前 J 的同一横向 GN |

因此 H1 与 H2 的差别仅在探索帧刷新，不能把 H1 误写为固定 Jacobian 正确器。一次正确器内部始终冻结其 \(C\)；刷新只发生在预测步骤之间。

最终主线程协议为两个公共入口：原锚点，以及公共 RML 入口中按无真值规则选出的材料不同合格点。每入口三层、每层两个尝试，总计每臂 12 次；半径依次为 .02、.05、.10。公共入口生成成本先从每臂 5400 RHS 总额扣除，两个分支共享该臂剩余额度，不能各自获得完整预算。

单分支 `run_arm` 是便利入口；多个分支也可由主线程共用一个 `PaidEvaluator`，直接调用 `predictor`、`transverse_correct` 和 `weak_frame`。所有物理调用仍经根跨进程原子预付，不由本引擎“估算后补账”。本地另设相同的 RHS/LU 上限并保留最后一次 F 槽；失败尝试不退费。

## 3. 弱帧定义及前置负证据

纯数据材料有效弱帧会放大近乎材料零的 latent 方向。在已读取的缓存几何上，若干列的 latent 范数达到 \(10^4\)–\(10^5\)，不能直接把其线性 .02 材料单位步当作合法有限预测。

代理 A 的只读解码器审计表明，所测试纯数据 signed rays 中只有 12/272 能在 latent trust4 内达到 .02 材料半径；这并不证明整个弱子空间都不可用，因为某些更有效的混合方向可以走得更远。不能把有限射线失败升级为整类方法不可能。

主线程在候选物理运行之前冻结了显式先验感知加项。`full_prior` 等帧使用 \([JP;P]\) 的 SVD，等价于原 Gaussianized66 先验下的材料 Rayleigh 度量 \(P^T(J^TJ+I)P\)。该项是原先验，不是新增观测信息。纯数据模式和它的失败证据继续保留。

Receiver/pair/host 模式必须由当前或指定参考场的真实矩阵构造；普通 Native、Reciprocal、GlobalDual 是具体参数化和求解机制，不能仅靠名称替换而宣称同一个比较。

## 4. HA 的实际条件与记录

当前实现只使用已经付费的当前 J 和现成响应：弱子空间投影漂移、响应 secant 缺陷、上一层正确失败比例。阈值依次为 .25、.25、.5；达到任一条件才刷新，最多两次。Secant 缺陷为

\[
\eta_{\rm sec}=\frac{\|r(x+s)-r(x)-J(x)s\|}
 {\max(\|r(x+s)-r(x)\|,1)}.
\]

这些条件只说明当前线性化/探索帧可能过时，不构成材料覆盖下界。没有为触发检测新增 Maxwell 查询。

若连续两层没有新增与已有合格云相距至少 .002 RMS 的材料，则自适应停止。层内逐个更新比较集合，避免重复候选被多次计为新增。硬深度、候选数或预算先到便停止；未执行项明确记录。更丰富的任务范围策略若未进入冻结代码，不得在最终报告中冒称已经执行。

## 5. 输出和解释边界

`CLOUD.npz` 保存所有可用端点的完整材料、参数、原始 Phi、资格、层号、先验成本和无真值在线选择索引。无可用端点、回溯停止、预算停止、投影破坏弱坐标等状态保留在 `TRACE.jsonl` 和 `SUMMARY.json`。`initial_weak_frame` 的列数是实际运行的 rank；它不冒充独立的 R9 weak8 参考。

主资格是原观测 noise ball 与合法性，材料 distinct 用于云增长/覆盖统计；DeltaPhi 与先验增量作为继承诊断另记。无真值选择、文件保存、物理正确性与真值评分是不同步骤；只有主线程封存全部预测后，离线评分器才可以访问受控真值。

预算受限的正确器返回当前最好的合法实际下降端点，不宣称收敛。离散节点上的材料多样性、竞争响应和扩展范围，均不是连续 Maxwell 纤维、完整材料支持或总体后验覆盖的证明。

## 6. 已完成实现验证

显式非 Maxwell 圆曲线带一个解码器零参数：两个端点最大残差 \(4.44\times10^{-16}\)，固定坐标误差和零参数漂移均为 0。它针对约束实现，耗费 0 Maxwell RHS。

原生正则器接口另以已知最优解 \((.5,2,3)\) 的非高斯二次目标检查；在故意提供不相容的 Gaussian prior center/weight 时，仍由所给 `reg_*` 恢复该最优解，误差 \(7.13\times10^{-14}\)，且允许第三个材料零参数按正则器移动。它同样只验证接口，耗费 0 Maxwell RHS。

三个真实两格 TM-VIE 控制和固定点导数差分结果详见 `FIXED_POINT_SPECTRUM_AUDIT.md`，包含独立三实维控制中的显式被动连续曲线。其物理成本共 98 RHS、31 LU。主 576 格候选结果由主线程运行后填写，本文不预报成功。
