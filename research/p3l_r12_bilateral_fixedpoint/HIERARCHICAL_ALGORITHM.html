R12-BF：递归究竟增加了什么

这份文档先冻结可执行的区分，最终科学结论由主线程在读完结果后作出。所谓“新信息”仅指在新候选处实际求解得到的新响应或导数；观测数据 y 没有增加，不能把计算次数写成统计信息量或后验覆盖。

物理直觉与四个深度

一个局部 Jacobian 描述“站在这里，小幅改变材料，会怎样改变接收场”。把同一个 Jacobian 再做一次分解，就像把同一张局部地图放大或旋转：可以重新组织已有方向，却没有看到下一个位置的地形。只有真正移动到候选、重新求响应并刷新 Jacobian，才有机会发现原局部图没有刻画的弯曲和方向变化。即使刷新，也可能只是得到近乎相同的局部图；必须保存实际变化量，而不能以“递归了几层”代替证据。

  • H0：全坐标 RML 目标扰动参考，不施加弱坐标固定；真实随机 prior/residual targets 由主线程提供。
  • H1：固定分支初始探索 frame；校正器仍在新状态处使用实际 Jacobian，不能将本臂称为“全程只算一次 J”。
  • H2：使用同一校正器，在第三层计划中的第二层开始前刷新一次探索 frame；不是把同一矩阵重新 SVD 来计刷新。
  • HA：使用同一校正器，由在线响应的割线缺陷、探索 frame 漂移或失败率触发探索 frame 刷新，最多两次；连续两层没有新合格材料成员则提前停止。

执行器有三层、每层对应 .02/.05/.10 材料预测半径；“探索 frame 刷新次数”单独计量，既不等于层数，也不等于校正器的新 J 次数。共同 baseline 与最分散合格 RML 起点形成两个分支，每分支每层两提案，总计最多12提案。rank8/16/32 是宽度对照；同宽度 H1/H2/HA 才隔离探索 frame 刷新。H0 的目标不同，不能将其与 H1 的差直接归因于深度。prior-aware frame 加项由主线程另行冻结，其来源/版本应随结果保留。

同一 J 的嵌套分解没有新增算子信息

设 J0 = UΣVᵀ，Q 的列张成某个已选子空间。对 J0Q 再做 SVD，得到右向量 W；回到原坐标的方向为 QW。故 span(QW) 包含于 span(Q)。同样地，若已知完整 J0，任何确定的重复 SVD、Schur 补或旋转均是已知 J0 的函数。它们可以重排、截断、重新加权已知信息，不能凭空提供 J(x1)。

注意两个边界：首先，把 initial weak8 扩展为同一 J0 的 weak16 确实扩展了试探空间，不能声称“没有增加方向”；它只是没有新增物理求值。其次，弱特征值接近或重根时单根奇异向量可任意翻转/旋转，因此比较投影算子，不比较带符号的单根向量。

刷新与有限割线的可检验证据

使用同一个原始白化与打包方式，记 f(x)=W F(x)。实际求得 x1 后，保存：

  1. 实响应变化 Δf=f(x1)−f(x0)，线性预测 J0Δx，以及割线缺陷 e=Δf−J0Δx；报告 η=||e||/max(||Δf||,1)。分母的 1 表示一单位白化响应，避免零响应差导致无穷比值。
  2. 若已支付 J1，报告 ||J1−J0||F/max(||J0||F,1e−30)，以及梯形预测缺陷 ||Δf−(J0+J1)Δx/2||。这些是有限节点诊断，不是节点间误差上界。
  3. 对弱空间正交基 Q0、Q1，报告 ||(I−Q0Q0ᵀ)Q1||F/√rank(Q1)、投影差 ||Q1Q1ᵀ−Q0Q0ᵀ||F 和主角余弦。所有基必须在相同参数度量下比较。
  4. 对已封存候选 Δx，报告其到 initial weak8 张成空间的相对距离。若另有材料切向基，可再给材料度量下的距离；二者不能混称。参数离开 weak8 不意味着远离其非线性解码像。

η 大只说明初始线性图对这条有限割线不准；η 小也不能认证远处没有其他分支。投影转动不意味着材料覆盖变好。真正的覆盖评价仍在封存后，用实际原始576维复材料计算。

实际执行器的 HA 在线规则

实现：agent_b/engine.py::run_arm。每层最多两提案，最多三层。第一层不触发 frame 刷新；此后若当前 frame 与候选 frame 的材料投影漂移≥.25，或前层最大割线相对缺陷≥.25，或前层失败率≥.5，则刷新，累计不超过两次。全局原子预算与局部 cap 始终优先。按材料 RMS>.002 贪心去重，连续两层无新合格成员则停止；同层候选也纳入贪心比较，避免同层重复虚增产出。报告中的实际阈值以每组保存的 Config 为准。

agent_c/adaptive_depth.py::DepthPolicy 另提供更丰富的候选规则：加入任务范围饱和条件及原子费用预估，η>.10/投影新颖度>.05 提示刷新；其状态为 PROPOSED_NOT_RUN，没有改变已冻结的在线执行器。不得把这个提案的阈值混入本轮执行结果。两套规则都是计算分配启发式，不是收敛/全支持保证。

先冻结预测，后读真值

R9 的32父对象已公开评分；固定其原始顺序前四个 R9V_FRESH_000..003 为暴露 DEV。它们在三条历史臂均未进入 ε=.075 材料管，足以检查“大但偏的局部云”这一失败机制，却不是新确认样本。数字 N1–9 是次要的设计对象，使用共同 baseline 与局部探索，不能替代 P1 覆盖主问题。
