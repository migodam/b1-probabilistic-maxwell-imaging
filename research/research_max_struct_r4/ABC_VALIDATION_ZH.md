# 原 Chat session 候选 A／B／C 的逐项验证

来源为 [CIE机制公式解析的完整引用](sources/CIE_SESSION_REFERENCE.md)。Chat 中的建议是待检验输入，不是证明或实验事实。这里沿用原 A／B／C 标签；`C_illuminated_localization` 是早期评分表中的历史程序标签，其科学归属实际是 A 的 T-completion/locality 对照，不是原 C 的有限射线。

## A：吸收局部多次散射，是否改变反演路径？

有限 VIE 为 `j=X(Einc+Gj)`。取实际四单元空间块 `Gin`，把 CIE 本构缺陷改为

```text
r = j − X(Einc+Gj)
Rexact = β[I+X(βI−Gin)]⁻¹ r
```

它保留同一物理状态零集，但非零缺陷处的优化目标改变。不是把旧等式改写后就宣布反演改善；本轮实现了相应 current 动作、包括变换材料导数的 readout、同一成熟双β调度和共同原物理 corrector。

从公式继续拆出 `D=I+X(βI−diag G)`、`L=D⁻¹XGoff`、`u=βD⁻¹r`，得到 `Rexact=(I−L)⁻¹u`。最小简化是 `Rplus=(I+L)u`，只需一次邻域交换，不需任何小 LU。已用24网格在整个公开材料盒内 `||L||∞≤0.16810`；因此变换可逆，尾项有显式 Neumann 界。界不证明成像成功。

公开开发弯条的全部端点由原 Phi 在线选择，再封存后评分：

| 路径 | RMSE/12 | Otsu IoU | 原物理相对残差 |
|---|---:|---:|---:|
| 成熟 sourcewise CIE，扩模并运行8000步 | .557674 | .255814 | .0977066 |
| 普通 global CIE，共同 corrector | .389183 | .422680 | .107821 |
| 只吸收 diagonal self，同强化内层 | .389418 | .422680 | .107821 |
| 精确四单元吸收 | .042654 | .928571 | .0009670 |
| 缓存版精确吸收 | .041691 | .928571 | .0009695 |
| 一次交换 Rplus | .041672 | .939759 | .0009679 |
| 同幅反相 Rminus=(I−L)u | .558703 | .257813 | .0976930 |

反相控制保留 `||u||²`、`||Lu||²`、metric 对角和逐次运算结构，仅翻转 `2Re⟨u,Lu⟩`。因此原物理相位相对于自身残差的方向，在这个对象和固定调度中有作用；不是“任意同强度反号耦合都能复制”。不能由一个反相控制证明所有随机耦合无效或真实相位普遍最优。

一次32网格诊断给出明确边界：onehop/global 都恢复，RMSE/12=.053068/.053102、IoU都为.935484、残差都约.0009705。A 在24网格的比较优势没有在该细化中保留；它自身并未失去恢复能力。因为离散脉冲、块物理宽度和噪声也变化，这说明表示敏感性，不能把它当连续 Maxwell 收敛或普遍超越 CIE 的证据。

此处单个开发对象不是成功率。独立六对象确认中，onehop/global/native8000全部4/6，两个新弯条都失败；onehop相对global材料NRMSE仅1胜5负。四种分块平移平均的后续已暴露开发修正也失败。原开发positive在Windows复验仍通过（NRMSE .04160、IoU .95181），所以该正例可保留，但它不是成熟普遍优势。最终表见 [中文总报告](RESEARCH_REPORT_ZH.md) 和 `results/CONFIRMATION_SCORES.md`。自项重整化、EBA 预条件 CSI、NIE/CIE、一般 T-matrix 变换都已有直接先例；具体一次空间残差交换的应用价值与原创建模价值分开评判。

## B：端口感知残差／隐藏 current 消元

完整自由 current 的纯端口罚函数可以解析消元，得到原数据目标的正比例缩放，加一个材料无关常数。若 prior 没有同尺度变化，则差别也包含相对 prior 强度。这个版本不能凭等式声称新凸化或新信息。

保留有限 state penalty `eta>0` 后，得到真正不同的材料相关 profile：

```text
C = S(I−XG)⁻¹
M = (eta I + lambda CC*) [eta I + (1+lambda) CC*]⁻¹
profile = 1/2 ⟨F−Y, M(F−Y)⟩ + unchanged prior
```

本轮实现精确 envelope 梯度，eta 从公开 host 固定，比较 lambda=0 的 state/WRI 对照和 lambda=1 的附加 port 目标，各250辅助步和同1000步 corrector。lambda=1 最终残差 .093255，却得到 RMSE/12=.533540、IoU=.244094；lambda=0 也未恢复。**测试的 B 没有成像优势**；低 residual 不能代替材料正确。固定 eta 的失败不否定全部 profile 方法，也不据此继续调 eta 到得到成功为止。

## C：完整有限材料射线与可见反馈方向

原有限响应公式复用了真实 Maxwell resolvent，未作 Born 截断。通过精确物理 Hessian 的 residual-feedback 项寻找协同方向，并将同方向完整有限射线与弱 GN 控制比较。

R3 失败端点的33维自由面最小曲率为 `+1.32513e−8`，全空间却有 `−3.14419e−6`。把负方向两种符号投影到合法 box 切锥后，曲率都变正；原来相互抵消的符号被约束破坏。四条既定射线没有降低在线原 Phi。随后对耦合 box 二次模型作两次固定500步修正，再用完整有限射线验证，仍没有改善。

因此 **这个 C 的方向生成和约束处理未能逃离该失败端点**。不是有限响应公式错误，也不是证明不存在其他协同路径。QP达迭代限、射线节点有限，没有全球最优证书。本轮没有用 GT 把真实材料差直接放进射线来制造成功。

## 真正保留下来的认识

一个有用的读出判别式是：实化本构线性化 `b−C dm`、正定残差 metric M 下，

```text
D_M − C† = (CᵀMC)⁻¹ CᵀM(I−Π_C).
```

逐cell共享源权重能在无prior、内点、精确根处抵消；空间非局部 metric 一般不能。它改变的是“当前 defect 中无法由局部实材料解释的部分”如何进入材料更新。实际一步是否改变还取决于右端 b；prior、活动约束和非零 defect 会超出这个局部命题。它是既有加权 LS／R3取消关系的结构精化，不是一个新的普适投影定理。
