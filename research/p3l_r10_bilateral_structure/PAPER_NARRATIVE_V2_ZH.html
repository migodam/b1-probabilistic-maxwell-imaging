固定双边散射算子的作用：幅度复用收益与材料可能性覆盖边界

论文叙事稿，2026-10-30。本版纳入 Fresh10 封存评分与独立复算、DEV 压缩扫描及另行冻结的 heldout-shape 计算核探针。当前证据支持有条件的计算收益，并给出候选覆盖的负结果；不构成论文级大样本确认。

备选题目：固定形状逆散射中的残差约束幅度复用；非线性逆散射中的双边结构与材料可能性。前者将已经得到支持的计算机制作为主线，把材料覆盖保留为独立负结果。

摘要

非线性电磁反演中，不同材料可以解释同一份含噪观测；有用的材料可能性集合因而需要真实覆盖证据，也需要可承受的计算成本。本文分别检验固定双边散射结构对这两个目标的作用。固定宿主精确消元将照明、内部传播和接收映射与材料相关 resolvent 分开；固定形状后，复材料幅度进入有理传递族。在已有 eigenpermittivity 与实现理论基础上，本文采用标准 block Krylov/Galerkin 压缩，并以完整状态残差及强制性估计约束白化端口误差和似然势函数误差。在八个开发形状选定 64 维后，十个另组锚点形状的 320 个幅度节点全部通过双门，无精确回退。实际每形状 32 次查询时，冷核总时长为 0.1150 秒，相比全阶 Schur 的 0.3173 秒与逐次 LU 的 0.2387 秒分别节省 63.76% 和 51.82%。另一个预测先封存、再解封真值的十对象实验，使用每臂八提案及相同完整坐标求解器比较完整 RML、仅形状 target 和固定双边协方差；RMS 容差 0.075 下覆盖分别为 3/10、3/10、2/10，共同 anchor 为 2/10，双边变体亦未显示明确动作误差收益。三个固定形状条件参考通过数值任务门，但不构成 Full66 posterior 资格。结果支持重复幅度计算的结构复用，同时限制本轮 target 启发式。64 维是经验有效阶，误差门是有限离散数值界；本文不主张新散射恒等式、严格最小实现、准确 posterior 或普遍高覆盖。

实际完成的 836 节点固定形状概率任务重放另节省 59.22%，保持原节点、权重和任务容差；历史网格构造仍被复用，故该费用结论不覆盖完整自适应积分流程。

1. 从物理问题开始

接收器只能看见材料激发出的部分散射场，同一份观测可能有多种材料解释。输出一张最佳图像容易掩盖这种不确定性；输出一堆不同图像则又可能只是把错误分散开。因此，材料可能性成像要回答一个更具体的问题：在有限预算下，输出的合法材料集合是否更经常包含真实材料邻域，或覆盖真实任务值，同时保持可用的范围与计算成本？

这个问题不必先解决准确 posterior。对预先声明的材料与噪声分布重复实验，候选集合的覆盖频率本身就有意义。但“没有提出 posterior 主张”也不能为低材料覆盖免责。集合需要被真正的 GT 与任务结果检验；宽度、点数和相容性均不足以替代覆盖。

R9 已展示这种区别。固定 weak8 在 32 个新对象上产生了许多合法相容材料，但主 RMS 容差 0.075 下只覆盖 6/32，共同 anchor 为 3/32；候选均值没有改善单幅成像。封存后几何分析提示方向遗漏和有限候选位置都存在，而保存同一路径更多点没有增加主尺度命中。因此 R10 改变随机提案目标和预算分配，不再把机器精度恒等式测试或同一 weak8 云扩容当作机制突破。

这一研究存在清晰的成熟先例。SOM/TSOM 利用固定传播结构组织电流优化；RTO、RML/rMAP 通过随机优化生成多个候选；LIS 和目标导向降维比较数据、先验与任务信息；T-matrix 分解和最小实现理论描述输入输出行为。本文检验两个窄问题：该结构能否降低固定形状的重复幅度计算成本，以及一个明确的双边构造能否在原非线性模型和有限预算下更合理地分配材料 target。标准数学本身不作为新发现。证据和冲突见 先例账本。

形状—材料分离还有更直接的先例：Forestiere–Miano 的 material-independent modes 和 Chen–Bergman–Sivan 的 eigenpermittivity 展开 已研究固定几何的可复用表示。因此本文把有理幅度分离作为已有结构，检验具体求解器、误差门和随机 target 设计的实际价值。

2. 科学对象与贡献层级

对观测 y，记 \(\mathcal C_K(y)\) 为原 decoder 支持内、通过原噪声数据门并按材料去重后的候选集合。anchor 也必须合格才计入。定义

\[ \mathcal V_{K,\epsilon}(y)=\bigcup_{m\in\mathcal C_K(y)}B_M(m,\epsilon). \]

主材料指标是重复对象实验中的事件 \(M_{true}\in\mathcal V_{K,\epsilon}(Y)\)。这个有限邻域并集既不是单次观测下的 posterior 质量，也不是逐像素上下界可以自由拼接出的合法图像空间。

可陈述的三项贡献具有不同资格：

  1. 一个有实测成本依据的固定形状计算机制：标准 block Krylov/Galerkin、复 Schur 幅度复用和完整状态残差门，在声明离散模型的重复查询中降低冷启动总核费用。数学恒等式和降阶组件均为已有方法。
  2. 一个可复现的候选负结果：在同一个完整坐标求解器下，仅形状和双边 target 变体没有提高相对完整 RML 的主尺度覆盖。分块 Schur 各臂共用，不作为新求解原理。
  3. 将经验有效阶与严格最小实现、有限材料覆盖与概率校准、固定形状数值参考与 Full66 推断明确分开。失败费用、数据暴露状态和条件适用范围完整保留。

3. 双边结构提供什么信息

精确固定宿主消元给出

\[ F(D)=F_h+O(I-DC)^{-1}DE. \]

O、C、E 和宿主响应固定，D 是空间变化材料。所有方法共享同一个精确离散 ROI 后端。对材料求导得到

\[ \mathrm dF=O(I-DC)^{-1}\operatorname{diag}(\mathrm dd)(I-CD)^{-1}E. \]

在宿主的一阶近似中，材料 Gram 为 \((O^*O)\circ\overline{EE^*}\)。与只看接收算子相比，它额外考虑哪些材料方向真正被照明激发；但它仍然不是全材料区域上的精确非线性 Fisher 信息。

若原材料允许 \(D=\delta A(\theta)\)，令 \(P^2=A\) 后有

\[ F-F_h=\delta(OP)[I-\delta(PCP)]^{-1}(PE). \]

同一形状的多次幅度评估可共享一次复 Schur 分解，不同形状则通常不能。该响应对幅度仍然是有理非线性，完整内层 profile 也不同于一次联合 GN 步中的幅度块消去。标准实现理论给出最小阶为可达—可观测商空间维数，等价于足够大精确 Hankel 的秩；后续压缩扫描测试 32、64、96、128 维，64 维是开发节点上最小的全通过测试阶，并在另组形状探针通过。它是经验有效阶，不是已经计算或证明的严格最小实现阶。

4. 本轮实际算法

三种新臂求解

\[ \Psi_{\eta,\xi}(x)=\tfrac12\|r_y(x)-\eta\|^2+\tfrac12\|x-\xi\|^2. \]

其中 \(r_y\) 使用原观测和原白化；\(\eta\) 是共同的 512 维标准 Gaussian 随机数；x 是原 Gaussianized66 表示，最后两维经 normal CDF 映射到原有界幅度变量。

FULL66_RML 在全部 66 维随机化 prior target；SHAPE_TARGET_RML_BLOCK 将两维幅度 target 扰动设为零；BILATERAL_TARGET_RML_BLOCK 再用固定宿主的双边 Gram 与 x=0 decoder pullback 构造前 64 维 target 协方差。三臂都优化全部 66 维，包括幅度。 “幅度 target 不随机化”不能被写成“幅度冻结”。

对 trace 为正的 64 维曲率 H，双边构造先取 \((I+64H/\operatorname{tr}H)^{-1}\)，将特征值裁剪到 [0.25,4]，再把 trace 归一化为 64，保留全部形状方向。裁剪与归一化是明确声明的启发式，不是推导出的准确 posterior 协方差。这里改变的是随机 target 分布，原坐标映射与二次正则 metric 保持一致。

三种新臂共享 anchor、随机数、完整坐标自由度和同一个求解器，每提案最多十二次 forward 与八个 Jacobian 状态。幅度块 Schur 是普通联合 GN 系统的等价求解，各臂相同。完整耦合非线性幅度 profile 为 NOT_RUN。每条路径从包括 anchor 的已访问状态中选取自身随机目标最小者，再对未经随机扰动的原观测检查噪声资格。拒绝、重复及失败尝试仍计费用。

完整残差约束的幅度计算核

每个固定原占比 a 对应 P=diag(sqrt(a))、B=PCP、L=OP、R=PE。从 R、BR 及后续传播构造正交 block Krylov 基，再对投影算子作一般复 Schur 分解；B 不要求厄米或正规。每个幅度重建完整近似状态 u_hat，计算完整 256 维方程的残差

\[ e=R-(\delta^{-1}I-B)\widehat u. \]

记 \(\beta=\lambda_{min}[(B-B^*)/(2i)]\)、\(b_\delta=\operatorname{Im}\delta/|\delta|^2+\beta>0\)，则计算

\[ \epsilon_w=\frac{\sqrt2\|L\|_F\|e\|_F}{\sigma b_\delta},\qquad |\Delta\Phi|\le\|\widetilde r_y\|\epsilon_w+\tfrac12\epsilon_w^2. \]

接受要求白化界不超过 0.01、势函数差界不超过 0.1，否则按冻结规则返回精确全阶结果并计入回退 setup 与求解费用。真实参考误差只用于核对，不参与接受。负 β 原样保留，材料损耗项在测试幅度矩形内提供正的强制性余量；没有假设离散 Im(B) 半正定。浮点特征值与残差未作向外舍入，因此不是严格浮点证书。该核尚未集成进材料候选求解器。

5. 已完成实验与裁决

A. 固定形状重复查询的成本收益

DEV 扫描使用八个已暴露形状、每形状三十个幅度节点。32 维为 0/240 通过并按回退政策分配已实付共同精确参考的成本（未另发起回退solve）；64、96、128 维均为 240/240 通过。64 维在三十查询的冷核总成本上比全阶 Schur 节省 69.78%，已计入 DEV 中较保守的基构造成本。32 维门失败不证明任意 32 维模型都不准确：当前界保守，基族也固定。

随后在另组形状构基前冻结 64 维，使用十个锚点形状、每个三十二个新原先验幅度节点。320/320 通过白化与势函数双门，无精确回退。最大实际白化端口误差为 9.13e-11，最大计算白化界为 8.01e-7，最大势函数差界为 8.32e-5。实际误差用于审计数值界，不作为重复恒等式精度的科学贡献。

B. 新 target 未带来覆盖优势

C. 固定形状条件参考不升级为 Full66

较早的全阶传递支线在另一计时窗口得到 Schur 节点中位数 0.552–0.781 ms、LU 1.963–2.282 ms，约二十一至五十八次幅度评估摊销 setup；它不是上述配对 heldout 冷核比较。最初三个条件参考不合格，另行冻结的 revision2 对三个条件任务均获得 NUMERICAL_FIXED_SHAPE_TASK_REFERENCE_PASS。这只是固定形状的数值任务参考，没有全支持证书。传递支线共计 69,784 RHS256、270 LU256，已含初次失败。Full66 posterior 仍为 UNQUALIFIED_NOT_ESTIMATED。该结果不能挽救材料覆盖负结果，也不要求先获得准确 Full66 posterior 才能研究有限集合成像。

随后实际执行同一已暴露开发形状的条件任务重放，完整复用其 revision2 合格细规则的 836 个节点与权重。64 维为 836/836 过门、零回退。两侧都重新建立形状算子并完成全部响应与求积，低阶费用为 0.117270 秒，精确 Schur 为 0.287601 秒，节省 59.2248%；evidence、幅度均值和事件概率均满足原任务容差。新增 6,688 RHS256、6,688 RHS64，无 LU256 或 RHS576。历史 profile、Hessian 与事件网格构造作为共同既有工作复用，未重新计时；所以节约仅针对这批固定节点的完整重放，不是整个自适应积分或成像流程。其资格为 NUMERICAL_FIXED_SHAPE_TASK_REPLAY，既非新条件参考，也非独立材料证据或全支持概率证书。来源：重放报告 与 保存结果。

7. 局限与解释原则

结论只适用于声明的有限离散 scalar-TM、材料 decoder、宿主、采集与噪声。条件幅度计算收益不证明全材料小实现。非对易性限制某些公共对角化，不意味着所有近似都无效；有限响应相容不意味着连续材料 gauge；能量必要约束不等于原 decoder 可实现性。

准确 Full66 posterior、完整非线性幅度 profile、transfer-aware 槽位分配、具体任务广义谱提案、压缩核集成进候选反演以及严格最小阶认证均为 NOT_RUN。本轮负结果限制实际双边 target 启发式，不能排除全部双边或任务导向方法。正结果限于声明离散问题中固定形状的重复幅度计算核，不证明端到端成像加速、新理论、未见形状统一误差界或总体覆盖提升。

最终裁决为：A，固定形状重复查询有费用收益；B，新 target 没有覆盖优势证据；C，条件数值参考合格而 Full66 推断未资格化。该裁决保留正结果的可用范围，也保留负结果的科学含义。
