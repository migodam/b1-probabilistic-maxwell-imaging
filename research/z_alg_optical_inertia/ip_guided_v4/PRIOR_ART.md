# 命题级先例与本稿的新增部分

| 已有命题或计算工具 | 在这篇论文里起什么作用 | 本文能多说什么 |
|---|---|---|
| Chew 与 Wang 在非均匀背景中重新计算 Green 与总场，发展 distorted Born 迭代 | 完整的背景场恒等式是出发点 | 对背景周围任意逐格实区间给出到既定多源观测的距离下界，在有界测量误差下检验整个假设。[原论文](https://doi.org/10.1109/42.56334) |
| 物理设计界及局部能量守恒，多激励需共用一份几何/材料 | 导出实部扇区、光学等式、局部乘子和跨照明限制 | 本文给出有限孔径下逆向的测量距离，并以未平均的单个物理电流计算负项可占的源维数。[Trivedi 等](https://doi.org/10.1103/PhysRevApplied.14.014025) · [Shim 等](https://doi.org/10.1515/nanoph-2023-0630) |
| 逐块实参数的二次约束、局部化乘子和鲁棒性检验 | 嵌套区间的权重传递是一个二阶扇区计算 | 通过它解释为何收到更窄的材料范围时已有数值方法竟会更弱，并从原波动方程验证条件下界实质改善。[Megretski 与 Rantzer](https://doi.org/10.1109/9.587335) |
| Haynsworth 惯性加法与特征值交错 | 状态正规时消元为源空间谱；在奇异时直接对带边矩阵取阈值 | 保存真实读数与局部本构后，在阈值处仅需验证一个足够大的正子空间；给出不定时的原生物理实例及可以复用的大域空间计算。[Haynsworth](https://doi.org/10.1016/0024-3795(68)90050-5) |
| SOM/FFT-TSOM 与 CIE 从电流域恢复材料 | 真实带噪数据上检查负模必要性、原方法的截断与材料读出 | 测得“整个负空间必须携带电流”可以成立，同时把这些方向塞入求解器依然会使留出预测恶化。[Chen](https://doi.org/10.1109/TGRS.2009.2025122) · [Zhong 与 Chen](https://doi.org/10.1109/TAP.2010.2103027) |
| 有限维 Calderón 稳定性与单调性成像 | 讨论有限观测、有限维例外空间与系数先验 | 对给定测量与给定区间输出距离或未定；全材料恢复及仪器加载误差仍需额外假设。[Alberti 与 Santacesaria](https://doi.org/10.1017/fms.2019.31) · [Griesmaier 与 Harrach](https://doi.org/10.1137/18M1171679) |
| 有界误差的集合反演、代数多根与逆散射线性化 | 描述搜集可能解、外包和排除间的区别 | 仅排除经全文方程证明不相容的区间，保留真实的有噪多解及生成池未覆盖真图的问题。[Jaulin 与 Walter](https://doi.org/10.1016/0005-1098(93)90106-4) |

正文给出适用的证明和 30 余项参考文献。术语、表格或一次严格计算本身不能确立首创。这里的原创性判断是与所核对研究的命题级对照，单纯的背景变换、现成谱不等式、非负 Born 投影、标准区间运算和 CIE 参数映射均已有直接来源。
