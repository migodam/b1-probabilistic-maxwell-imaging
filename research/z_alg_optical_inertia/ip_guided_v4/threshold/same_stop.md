# 同样按首个严格可行材料停止，整盒裁剪减少了多少工作

**八件中两臂均有 7 件严格入球，所有 8 件报告的材料数组与训练端口预测逐位相同。** 逐对象取十次配对运行的中位数后再加总，整盒裁剪使全波 LU 从 1,803 减到 1,409，却将在线墙钟从 0.258 秒增至 0.296 秒，增加 15.0%。七个达标对象的访问盒数完全相同，裁剪的节省来自唯一未达标的难例。

两臂使用八个已经曝光的确认对象、同一冻结 24² 标量 TM 算子和 49 个活动格、16 个接收×4 个源及各自的 1.25% 相对噪声球。每次实际生成同一 64 个样本并逐样本全波正演，按每盒的最优样本残差稳定排序。每盒从这个最优样本出发，同做 42 次以内的逐格有界原物理精修。首个经 Arb 认证残差处于同一个噪声球的材料立即结束，两臂未达标时都报告最佳已审计端点及失败状态。实验臂先按已定版的阈值证书检查全部 16 个盒，再按同一完整点排序跳过严格排除盒。每个对象交叉安排十次，每条管线各有五次排第一。新对照沿用已公开的材料与方法选择，属于回顾性配对比较。

各件裁剪臂与未裁剪臂的配对墙钟比先在各件取中位数，再在八件取中位数，得到 1.308 倍，CPU 同为 1.308 倍。20261125106 中，裁剪在十次配对里都更快，并以少 394 次 LU 确认同一个预算内失败；可行性仍由后续原物理求解决定。七个已达标对象的单次整盒证书墙钟中位数额外支付约 8.0–10.4 毫秒，裁剪未省掉首个达标前的任何精修。

逐例运行墙钟和 CPU 均包含候选生成、同样的 64 点全波排序、盒内精修和最终的物理端点 Arb 审计。阵列读入单列。在线裁剪用既定带舍入余量的一侧阈值证书，在线耗时已计入表内。离线又对 98 个排除逐一用 Arb 复核，十个含真值的盒均保留。独立 Arb 合同检验额外用 2.137 秒墙钟和 2.110 秒 CPU，含重新提出数值证书的完整额外复核墙钟为 2.198 秒。逐对象保存 49 格材料值、严格终点、访问顺序、全波分解与 RHS，以及从原模型算得的留出接收与留出源预测误差。
