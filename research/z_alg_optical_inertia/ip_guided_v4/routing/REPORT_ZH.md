# Born 证书、求解初始化和 CIE 续算的配对实测

**固定端口证书排除了 28 件主样本上的整个非负 Born 类，仍有 15 件从 Born 图启动全波迭代可得到更低的训练残差。** 28 件都是 400 MHz、2 m 方形、原生 96²、10 发 20 收和 10% 噪声。六件 optfresh 与 22 件 SRAP 按材料计数，两个来源的强散射读数均为已曝光样本。证书在线只使用当前读数、几何与已声明误差半径。分解真值和合成留出端口在各臂保存候选后读取。[28 件逐物结果](principal_28.csv) · [逐臂材料、端口与费用](paired_arms.csv) · [冻结合同](FREEZE_ZH.md)

## 线性类排除可以跳过终点拟合

对无损材料，令 $A(m)=S\operatorname{diag}(m)B$。固定复权重 $Z$ 在所有像素上通过向外舍入验证 $\operatorname{Re}\langle Z,A(e_i)\rangle\le0$。只要 $m_i\ge0$，该不等式就对整个锥成立。因而 $\max(0,\operatorname{Re}\langle Z,Y\rangle/\|Z\|_F)>r$ 足以排除全部可在球内解释观测的非负 Born 图，包括未设峰值上限的图。已知损耗角 $t$ 的测试把 $B$ 换成 $(1+\mathrm{i}t)B$ 后重做逐像素符号验证。线性测试的符号约束是对 $A$ 的严格验证。单格模型 $G=0,S=B=1,Y=0.5,r=0.01$ 的完整全波盒 $0\le m\le0.25$ 已被排除，同时 $m=0.5$ 的 Born 图精确拟合。[原几何权重和认证](../../physical_revision/born/extinction.py)

28 件的 L1 单侧距离为读数范数的 43.88%–61.94%。复用几何的一次读数中位为 0.142 ms，重新核验固定权重用 0.269 s。相同 28 件的历史严格 L2 在峰值上限 .50 全部通过，距离为 1.062–3.019 倍半径，在 .75 均待定，最高现有下界为 0.413 倍半径。L2 使用冻结的已验证收据，未把查询历史文件的时间记成新证书时间。L1 与 L2 都不含求解器的搜索轨迹或初值响应。[L2 适用合同、实值和严格出处](historical_l2.csv) · [独立准备与在线计时](summary.json)

路由规则遇到严格 L1 排除即交给真空启动的全波 L-BFGS-B。在未排除时，规则先用非负 Born 图，只有线性读数与该图的独立全波读数均进球才提前返回，否则从该图启动全波。下表同一原生前向，直接迭代用 24² 等块材料更新，Dual-CIE 使用原生 Fourier 电流与原生材料读出。两种启动的直接迭代共享 [0,4] 盒和 16 次目标调用。两种启动的 Dual-CIE 共享 [0,4] 盒、秩 15、前 16 个原 CIE 共轭梯度电流步和终点真全波核查。两个算法之间的状态表示及预算单位不同，记录早期轨迹边界。括号里的正演次数包括逐图原物理重审，CIE 的辅助 Green 作用、SVD 和 PR 步另记。[共同合同比较](paired_arms.csv) · [原成熟 Dual-CIE](../../../srap_cie_array_study_20261121/engine.py)

## 对照、紧凑环和暗室

- v3 的超弱椭圆原有明确 Born 拟合见证。在它的 2% 读数，本轮不读真图的求解也通过线性和独立全波两个点检查。超弱椭圆的 1% 读数以及峰值为 .04 的实物双盘对固定 L1 均未定。双盘的历史逐读数锥证书能排除全波生成数据的 Born 类。精确 Born 生成的同一双盘控制重复使用几何，按两个形状而非三个模式计数。本轮在 2% 找到 Born 球内点，但该图的全波读数没有通过双重提前返回检查。[历史独立控制和一侧区间](../../physical_revision/born/controls/RESULTS.md)
- 四件新增弱／中等几何的峰值为 .002、.03、.25、.8。L1 在较高两件通过。四件的 Born 初始化路径都改善了真空启动的全波残差和材料误差。它们是用于机制证伪的同格合成数据，保留偏移源／收端口评分。[弱／中等几何注册](FREEZE_ZH.md) · [逐例条件与路由](all_routing_cases.csv)
- 七件原 24² 环形观测为 12 发 48 收，原概率半径及 [.02,20] 反演合同。七件 L1 通过，历史 L2 在上限 5 排除五件。未排除的 `r14_new_0018` 有峰值 4.282 的离线可行见证。对应原生波数 (k=2\pi)、窗口宽 .96，(ka=4.265)。无冻结的独立留出端口。四个有损独立形状按两种电尺寸和各自三个损耗角配对。12 次 L1 均排除各自已知相位的 Born 锥，历史耗散、被动扇区和接收椭球收据按同一损耗合同匹配。本次全波拟合的实部和损耗角均按原参数限制，没有借另一损耗模型解释读数。[同一读数配对条件](all_routing_cases.csv) · [原紧凑环的严格收据](../../validation/max_struct/REPORT_ZH.md) · [原有损严格收据](../../ip_unified/numerics/loss/REPORT_ZH.md)
- 九个 Fresnel 读数用实验室逐源实收掩码、独立空场照明校准和原源／收留出划分。28 个 Manitoba 读数复用原金属标定的真实通道，重留四个发射和其他发射的一组实收。历史固定 Born 证书超过两种经验尺度的频率视图分别为 3/9 和 25/28，后者仍仅四个独立物体。重新拟合均未见留出值。Fresnel 源、收留出误差分别为 91.4%–116.8% 和 80.2%–97.9%。Manitoba 分别为 69.0%–104.8% 和 68.1%–107.9%。原 Born 门对原认证掩码，拟合指标对各自新的训练／留出划分。原四标定差或空场代理只给出条件峰值余量，没有统一加载误差上界，也没有逐像素材料真值。[实测条件峰值与端口表](measured_port_cases.csv) · [原实测 Born 认证](../../physical_revision/born/ports/REPORT_ZH.md)

## 原生 CIE 两件等宽电流干预

两件完整精细诊断为 32 发 32 收、2% 的 optfresh_01 和 optfresh_05。上限 $u=1$ 的历史严格 L3 划定的是同一原生状态 $K$ 的整体无权投影 $\|V_-^*J\|_F$，两件下界分别为 15.760 和 19.769。坐标能量 $\sum_{i,j} |\lambda_i(K)|\, |v_i^*(J-J_0)_{:,j}|^2$ 另含状态特征值和中心校正。L3 的总下限不能给每列单独分配必要份额。两类数值分别从实际存下来的格点全波电流计算。[历史严格投影条件](../../ip_unified/numerics/native/required_currents.json) · [当前逐步明细](cie_diagnostics.csv)

原生 Dual-CIE 使用相同秩 20 的 DPCS、100 列 Fourier 电流、同一构成误差目标与相同步数。只替换最外侧 Fourier 13 列为负模在保留列和 DPCS 之外的正交补，再运行相同迭代。未替换的 100 列已与整个原生负空间有 0.91°–5.47° 的主角，原算法并未把该空间全部置零。其优势发现是 CIE 读出的全图 L2 有小幅改善，两件分别 .959→.922 与 .819→.779。然而第 16 步训练残差分别由 (59.66r\) 变为 (60.45r\)、(53.31r\) 变为 (53.80r\)，留出复场也同时变差。第二件第 8 步两臂的紧公差 GMRES 均失败，表中保留，末步还能独立重审。物理材料截回上限 1 后，四个终点的负电流范数仍高于必要下界，端口距离全部超过 (65r)。满足必要总投影不能代替原物理余量判定。

用严格排除的峰值 .75 构造 $\beta=1/.75$ 是本轮测试的启发式。它降低终点训练残差至 $35.59r$ 和 $48.58r$。固定 $\beta=2$ 也实现相近改善，分别为 $36.48r$ 和 $51.21r$。两种都停在误差球外。本轮实测中，较小的参数影响早期轨迹，峰值证书带来的材料恢复收益仍待确定。[四臂实际状态、材料和端口](cie_diagnostic) · [对照图](routing_results.pdf)

## L4 在真实 CIE 迭代中的局部邻域测试

新增中等材料第 4 个 Dual-CIE 电流步的原物理残差为 (13.34r) 和 (19.03r)。以实际读出的材料为中心，上下各宽 .04 及全域所有 144 格可调时，新证书与现成 Neumann 变化界均未判定。曝光后缩到 .005，严格 L4 得 (7.970r) 和 (17.952r)，Neumann 同时得到 (5.599r) 和 (16.353r)。两种严格判断与普通点残差都执行同一重启，CIE 两条选中路径相同。L4 的验证增加约 .67–.79 s 候选成本，包括同盒原物理中心计算。原始不受限的 16 步路径离开两个局部盒，宽盒有 17 和 111 个越界像素，窄盒有 94 和 140 个。因此此处能排除声明的邻域，实验尚无依据排除整个迭代吸引域，也没有给出相对普通残差策略的净收益。[可复核逐臂计费和盒端点](early_exit_diagnostics.csv)

## 复现

从研究工作区根目录执行，使用已有包含 NumPy、SciPy、python-flint 和 threadpoolctl 的运行环境。运行程序只读原冻结观测；随后运行离线评分。配置和产物目录可在脚本参数中查看。

```sh
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1
r=research/z_alg_optical_inertia/ip_guided_v4/routing
for suite in native ring loss weak mild_mid; do python -B "$r/routing_run.py" --suite "$suite"; done
python -B "$r/cie.py" --branch principal --box4 --out "$r/cie_principal_common_box"
python -B "$r/cie.py" --branch diagnostic
python -B "$r/cie.py" --branch diagnostic --diagnostic-extra
python -B "$r/cie.py" --branch principal --box4 --steps 96 --full-schedule --objects optfresh_01 optfresh_05 --out "$r/cie_principal_longer"
python -B "$r/early_exit.py"
python -B "$r/early_exit.py" --halfwidth .005
python -B "$r/measured.py"
python -B "$r/score.py" --suite native --with-cie
for suite in ring loss weak mild_mid diagnostic; do python -B "$r/score.py" --suite "$suite"; done
python -B "$r/summarize.py"
python -B "$r/plot.py"
```
