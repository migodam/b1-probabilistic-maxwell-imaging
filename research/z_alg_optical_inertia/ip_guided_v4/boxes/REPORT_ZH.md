# 原生 Maxwell 读数排除含高反差的局部材料盒

一份原生 96² 盘体读数在**同一个 1,153 格支撑**内给出配对区分。峰值为 0.625 的真实全波材料落在原误差球内，严格残差上端为 \(0.999949982r\)。把区域换成名义峰值 4、逐格半宽 2.5 的非均匀材料盒以后，任何盒内全波状态的端口残差都至少为 \(1.728458102r\)。这一盒的峰值范围为 [1.5, 6.5]。中心扰动算子 2-范数下端为 5.143514，状态矩阵有 7 条负方向，32 束照明仍留下足够的共同信息排除整盒。接收核中另有一个单位方向的区域二次型不超过 −0.222015678，排除了在该区域权重下用任何正标量把状态矩阵变成正定的可能。

将冻结的二进制中心轮廓视为精确值后，归档盘在半宽 3.8643663194444446 首次进入同一个高峰盒。决定首次入盒宽度的是候选支撑中的一个实际真空格。保存的严格排除盒包含精确中心家族的半宽 2.4999999999999996 成员，因此第一次可能落入误差球的物理半宽在 [2.4999999999999996, 3.8643663194444446] 内。2-范数 Neumann 收缩临界半宽经独立区间核对为 [0.48604895922264324, 0.4860490078275396]，已排除宽度至少是其 5.143514 倍。该已排除盒同时取上端时，四次迹矩给出严格谱半径下端 1.086436。物理临界半宽、最佳二次型界和一般权重的最优值均未精确求得。

用同一个接收核方向另验通常的无损全域光学相等式。对 \(K = S^*S+\mu C+\tau(G-G^*)/(2i)\)，该方向的光学型上端为 \(1.4740\times10^{-17}\)。在 \(W=I\)、\(\mu>0\) 下，对所有 \(|\tau/\mu|<1.50626\times10^{16}\) 仍存在严格负方向。该范围按这里未缩放的全域光学算子给出。改变 \(W\) 和使用其他光学权重的最优范围仍开放。 [盘体宽度和光学对照](results/disk_radius.json)

## 固定非零外部的同一检验

对两份 optfresh 原读数另作假设：Born 峰处半径 0.245 m 的区域未知，相距 0.42 m 的半径 0.105 m 圆盘固定为对比度 3.25，其余外部真空。每个稳定选项保留两侧宿主位置，逐格半宽 1 至 2.5，等权和以中心实际总场功率得到的对角权重。最终两件均选择左侧固定盘。严格验证的盒覆盖 437 个未知格和 78 个固定格，半宽 2.5。等权取 7/32 条负方向，两个下界分别为 \(29.0061r\)、\(27.7301r\)。以中心照明强度调整权重得到 \(26.3552r\)、\(26.0977r\)。两个等权盒的中心扰动谱范数下端均为 2.27913，外部在计算中保持明确固定。从固定盘独立消元得到的区间端口，距原全网投影回放的中心预测不超过 \(3.56\times10^{-15}\)。固定盘是受检候选的一部分，未借用两件对象的真值。 [固定非零外部扫参与回放](results/followup_host.json)

## 下界和 Neumann 比较

设候选材料为 \(M+R D\)，其中 \(M\) 和 \(R\) 是逐格区间的中点和半宽，\(D\) 是对角实乘子且各对角元绝对值不超过 1。原场满足 \(E=B+GJ\)。逐格构成关系和任意非负对角权重 \(W\) 给出
\[
(J-ME)^*W(J-ME)- E^*RWR E\preceq 0.
\]
令 \(A=I-MG, F=MB\)。形成状态系数 \(C=A^* W A-(RG)^*W RG\)、线性项 \(P=A^*WF+(RG)^*WRB\) 和源系数 \(D_0=F^*WF-(RB)^*WRB\)。加入原接收残差后
\[
K=S^*S+\mu C,\quad L=S^*Y+\mu P,\quad
H=Y^*Y+\mu D_0-L^*K^{-1}L.
\]
Arb 核对低秩正修正后的移位 Cholesky、负方向及驻点剩余量。对照明空间的 \(H\) 取降序特征值，丢弃前 \(\nu\) 项，剩余各项与零取最大再求和，便是全波端口残差平方的下界。\(\nu\) 来自原材料支撑全部活动格的已核验惯性。

扰动比较从真实中心场 \(E_{\mathrm{bg}}=(I-GM)^{-1}B\) 出发。对 \(z=A(J-J_M)\)，迭代式为 \(z=D(R E_{\mathrm{bg}}+RG A^{-1}z)\)。用 \(T=RG A^{-1}\) 的 2-范数核对这一充分收缩条件。主表前四件在同时取上端 \(D=I\) 时，分别用严格的迹矩给出 \(\rho(T)>1\)，因此在整个盒上不能依靠该中心的算子 Neumann 展开。相同中心与支撑下，初扫最后可严格验证收缩的半宽为 1、0.25、0.75、0.75。该处基于统一状态变化半径的三角下界在四例均为零，状态二次型正定下界仍分别达 \(70.74r\)、\(42.30r\)、\(40.65r\)、\(36.40r\)。这些是离散试值。

活动格 Green 块由原 192² 二进制频域符号做区间反变换后，按原 96² 坐标差取全部条目。固定真空格的电流恒为零，活动块消元等价于原系统。中心材料的区间解外带到全域，完整 FFT 全波回放保留在结果数组。24²、32² 用原保存密集 Green。全过程只在离线物理解验收时读原生成材料。

## 同一读数允许两份分离的材料

另用已曝光的六单元 GENERAL6_00 作非唯一性对照。这个原始合成观测包含三束独立入射和一个复接收器。使用 Q20 归档路径 16、17 的两份材料，复用原离散模型和原复读数。在此次半径 \(r=2^{-30}\|Y\|_F\approx7.63408\times10^{-11}\) 的误差球内，两中心用独立 Arb 全波求解得到的绝对残差上端分别为 \(1.602551\times10^{-15}\) 与 \(1.414930\times10^{-15}\)，均小于 \(2.10\times10^{-5}r\)。两个逐格半宽 0.05 的盒都在原 [0.5, 30] 材料范围内，第二格区间至少相隔 2.05966，两中心材料的 RMS 距离至少为 1.15879。该半径下至少有两个不同的物理解。 [观测及原算子来历与区间回执](results/ambiguity.json) · [精确表示的离散输入和中心回放数组](results/ambiguity.npz)

## 文件与费用

扫描保留 241 个盒、1,205 次双精度状态谱，耗时 124.48 墙钟秒和 125.04 CPU 秒。主结果严格核验为 396.71 墙钟秒和 583.71 CPU 秒。原生核一次 Arb 变换后供同一批读数复用。每项严格费用包含选定状态矩阵的独立组装与惯性、源端点、中心精确求解及原网格回放。验证谱半径时额外计矩阵矩、精确扰动右端和高阶乘积。盘体高盒用 150.45 CPU 秒，包括严格接收核方向、416 格低峰物理解及中心场。固定非零外部两件四项严格权重和独立宿主核验共 110.38 CPU 秒，浮点扫参另用 19.30 CPU 秒。零下端超集核验 98.52 CPU 秒，浮点扫描另用 2.83 CPU 秒。22 项保存的中心材料状态与复端口另从结果数组逐项回看，原物理状态方程的最大相对缺陷为 \(6.11\times10^{-16}\)。完整分项、较早失败尝试及日志见 [费用账](results/costs.json)。
