# 连续单束比较的附加尝试

七件 R14 上权重网格内的单束比较得到零个上限 5 的证书。要把这个事实推广到连续的单束权重，旧稿 §3 有一个更强的充分条件。为此，另将原稿的构造用于这批已公布的复场。这里允许拟合每个单位相干输入的残差位于原联合误差半径内。此项跟进发生于固定权重实验之后，未改变阈值或通过数。

从公开接收矩阵的截断右逆生成均值电流 X，遍历截断阶数 1–48，再用原稿的九种正则参数在接收零空间中降低光学二次型。可用充分条件为同一个 X 满足两项严格矩阵不等式，且其端口误差的谱范数小于给定半径。七件的候选全未满足两项符号条件。最佳候选的负光学矩阵最小特征值约在 −0.0199 至 −0.00995 之间。单线程浮点搜索约 1.24 秒。这个符号结果只淘汰了此次构造，连续全族的单束可行性仍未知。因此主文在 R14 报告固定权重的严格分离与预定网格的比较。

从此目录执行 python -B global_witness.py，读取旁边 MAX-STRUCT 目录的公开数组，输出 [逐例浮点结果](proposal.json)。
