## 观测、算子与离线核对

SRAP 的 24 件原材料各有一个全环 PW360_10x20 视图。前一轮已在光学链用过 007、010 两个材料，因此将它们的全部视图从迁移分母排除。其余 22 件沿用原公开 \(Y\in\mathbb C^{20\times10}\) 和 10% 的原 Frobenius 采样半径，完整保留数据值和顺序。冻结的四个 2×2 或全局配置与两个 4×4 配置来自 optfresh 的原证书。 [冻结规则](FREEZE_ZH.md) · [原 SRAP 数据发布](https://github.com/migodam/b1-probabilistic-maxwell-imaging/releases/tag/srap-cie-array-study-20261121) · [复用的 4×4 惯性证明](../../submission/single/coherent_general_verified.json)

每个半径统一向上扩大到 \(\delta+10^{-6}\|Y\|_F\)。在线结果完整写盘后，按 SRAP 原生成函数及冻结种子重构 96² 真材料。原生成器的全环 \(B,S\) 与 Green 频谱均逐位等于提交版保存的 96² 数据。重构材料的 32² 面积平均与 SRAP 历史评分数组也逐位相同。离线 Arb 审计直接在原细网材料上约束真正演端口残差，22/22 原细网真材料落在扩大球内。最小严格余量为 \(3.767\times10^{-6}\)。原采样半径下为 11 内、11 外，最大所需相对补量约 \(6.60\times10^{-10}\)。22 件真材料的细网峰值为 2.50958 至 4.06211。 [真材料可行性审计](offline.json)

## 原生区间复算与计费

六份已核定的状态算子各共享一次 30 列驻点计算。针对矩阵 \(A=K/\mu_0\) 的共同右端 \([S^*/\mu_0,ZB]\)，数值驻点只用于提供试向量。区间算术对其原生 Fourier 作用验证缺陷 \(R\)，把驻点二次值和缺陷压缩为 30×30 矩阵。每个 \(Y\) 通过 \([Y;I]\) 代入，利用继承的正谱地板和重新验证的负谱地板给出源矩阵的双侧界。残差证书丢弃前 \(\nu\) 个源特征值，累加剩余正源谱再开方。正定配置的同权最优相干单源由最大源特征值给出。负惯性为四个的配置已经耗尽单源容量。原证书的材料假设仍包含全部 9,216 个材料坐标。 [在线复现源码](online.py)

## 复算顺序

从本目录用 NumPy、SciPy、python-flint、threadpoolctl 和 Matplotlib 执行。原始公开包在 SRAP 归档的 data/public 目录。紧凑包只存 22 份原复观测和绝对采样半径，可独立复算在线证书。离线步骤另读原生成器和其已公开的评分数组，须在在线证明封盘后运行。

```sh
python -B online.py --public-bundle public_observations.npz
python -B offline_feasible.py
python -B summarize.py
```
