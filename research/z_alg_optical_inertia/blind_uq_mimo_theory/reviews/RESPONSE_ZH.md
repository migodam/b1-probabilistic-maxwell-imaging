# 独立审查怎样改变了实验和结论

Neon 通过专用命令行研究项目打开了实际源码、压缩矩阵、结果表与理论推导，检查了固定算子的两个方向、频率权重、区域生成和误差上包。四次命令行调用共收到三份完整意见。第一次在审阅材料后超时，保留了本机工具轨迹，没有可引用的结论。第二、三、四次均正常返回。下表说明哪些结论因复审而改变。[第二次意见原文](neon_02.md) · [第三次意见原文](neon_03.md) · [第四次数字与量词审查](neon_04.md)

| 疑问或建议 | 查到的证据与采取的行动 |
|---|---|
| 8×8 分开两幅图，是否证明盲区域一定有材料？ | 审阅者指出两份中心专为 6×6 寻找，不能用于估计总体成功率。对两个已给定的 1,024 格材料盒分别计入签名二阶支持与三阶余量，再独立寻找相交材料。名义与 0.25 Ω 不确定性下均证明半宽 0.02 可分；半宽 0.05 时在同一硬件扰动下存在共同读数。第二次审阅引用的较早半宽结果保留在原评语，当前数字以完成的两侧计算为准。 |
| 在盲区域中，证明峰值全宽是否只是单格尖峰？ | 对同一冻结区域比较整区归零与连通子区每格至少为 2。九个对象有落球的两种材料，原生两件的高值连通区为 156、218 格。另一路显式 96² 状态复算了 156 格斑块和同一区域的连续单格峰值路径。持续可行的路径数与只有端点的数量在主表分列。 |
| CIE 收敛与拟合是否混淆，暗模惩罚的效果是否来自多花了时间？ | 补做双参数更紧停机、单参数三个连续稳定窗口、相同更新和墙钟前缀、简单脊罚和随机接收核。稳定 CIE 图仍有 7.23–12.15r 的原全波残差。降低受罚电流并未稳定改善区域内外材料误差。 |
| 是否存在盲区偷看真值、掩码不同步或零端点漏报？ | 自动分割与拟合只由训练读数和 CIE 图驱动。比较图换为稳定终点时发现三处旧区域数组，逐像素核对后重做对应的一侧计算。最初的联合拟合曾将仿真档的清洁读数也载入内存，目标、初值和梯度均不使用这些键；读取已改为白名单。主文的统计由相同的最终区域重算。 |
| 为何部分复数区间的端点误差显示 NaN？ | 审阅者指出，两份原生读数的范数平方向外舍入后可能稍微跨过零，直接开方会得到空值。将区间与数学上必然的非负半轴相交后再开方，重算两个区域并要求严格 JSON 拒绝 NaN。原 Bernstein 二次式和独立全波余量始终有效。原结果保存在本地更正目录。额外的 32² 复核还触发了原状态残差保护：连续读取两个材料、先求第二个材料的伴随时复用了第一份 LU。现按材料数组核对缓存，重新完成两份验证。 |
| 为什么仅从左弧发、右弧收？能否同成本改变得到的信息？ | 采用 Neon 的双向测量建议，设计了相同功率/通道/发射数的两侧交错布局，前瞻冻结几何和噪声后再产生新复读数。七对固定材料全部分开。随后把两个布局的两个误差球同时纳入全波优化，另设同预算无约束对照。联合区域归零在一件中可行，强斑块在三件中可行；三类代表均经独立原方程复核。 |
| 用单一共享标定方向的灵敏度差能否放大分离半径？ | 若检验要求两种材料面对同一已辨认的仪器，从投影的一阶式确可把两侧核范数之和收紧为灵敏度之差的核范数。对一个未知仪器的观测反推材料，每种材料通常允许各自配合一种与校准数据相容的仪器。该更紧条件须绑定共同校准信息。本文保留可分别变动的安全分离界，并给出同一台仪器也可产生的宽盒相交。尚未用实验室加载校准建立更大的实机半径。 |
| 训练残差在离散模型里成立，能否解释真实天线？ | 增做 32² 与 96² 相同物理材料或粗化表示的读数差，独立查验 Manitoba 实测的通道切换路径和两次空场。模型差多次超过原噪声球，故明确将严格陈述限于原算子。开放或短路端接的额外校准需要实机数据，本轮没有采集。 |

**最终数值复审。** Neon 核对 24/28 个两端、7 个连续路径及双布局的 21 个端点，并确认范数平方与非负半轴求交是有效的区间操作。关于原生首要区，文中的 0.813r / 0.668r 来自独立的伴随误差复核，先前只链接了整条路径较宽的 0.823r / 0.678r 上界。正文已列两组结果并分别直链。依照最后的意见，全段二次式归一化的展示数也改用向上端点转换，重新逐个复算 50 个已通过的原始单格路径。强互耦比较现在逐行说明候选都出自 48 Ω、各档绝对噪声地板相同且相对信噪比会变化。初次回放在 144 Ω 全数落空后，实际按照 144 Ω 的新读数重新拟合 c02 的第二区域，严格同时找到 0 与 4.5。我们还对 28 个区域都计算了相容材料的**区域平均值**差异，以回答单格尖峰能否完全解释观察结果。

三份原始评语保留审阅时的数字、质疑和建议。本文在意见之后又完成原生首要亮区继续拟合、跨阵列区域核对以及联合双布局实验；最新端点及其文件位置由最终逐区域表给出。没有把模型审查替代独立算术验证或作者的科学判断。[最终结果与修订后的判断](../BENCHMARK_REPORT_ZH.md) · [复核脚本](../diagnostics/verified_wave.py)
