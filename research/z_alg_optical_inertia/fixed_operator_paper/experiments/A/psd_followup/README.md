# A 组 · 两次 PSD 基线复核

## 真空消元后冷启动凸搜索

统一对所有方法精确消去已知 `χ_i=0` 的格，保留同一算子、材料盒、端口读数与误差球。固定检查 `b=0`、名义宽度比 3 的全部八个结构对、每对两份读数和每份的两个候选盒。按公开编号逐盒运行，全部 32 个判定及独立重放先于打分冻结。源方向的数目为 16，独立单位仍是八对。

|方法|排除|有严格见证|未决|
|---|---:|---:|---:|
|原 A 组 B，未精确消去真空格|0|18|14|
|原种子式 B，精确消去同样真空格|13|18|1|
|冷启动独立 B，精确消去同样真空格|14|18|0|
|原带边惯性 C，精确消去同样真空格|14|18|0|

冷启动 B 与 C 逐盒一致。16 个对方盒中得到 14 个严格排除、2 个严格可行的不同材料。单独的 Hadamard 源矩阵支路达到 14 个排除，共用空间 PSD、共用带符号光学等式和独立原源支路分别达到 12、10、11 个。

凸程序为每个保留材料行独立提议非负扇区权重及可正可负的光学等式系数。对正状态块 `K`，最大化带边矩阵源块可扣除的 Hermitian 下界的迹。原源和 Hadamard 支路可按源模式分别选择权重，后者的独立源模式系数在原源坐标下对应非对角源矩阵。提议从空状态启动，未使用旧惯性银行的权重。Arb 192 位用原数组重求 Schur 补并核验正状态的 frame 及实际对偶下界，原源/Hadamard 变换的组合按整数基重放。

Clarabel 初跑的病态锥失败已保留。所有 32 个节点用相同的位移余量、按接收方程量级归一的搜索系数上限以及冷启动 SCS 重新跑过。提议锥的正性位移和系数限幅只影响搜索，验证根据原二次型。为避免信号迟到把进程墙钟拖过 10 秒，最终全部节点统一在 9.4 秒处停止在线工作，保留独立重放余量。仅验证后的数值用于判定。该次有限搜索没有求尽所有源矩阵乘子。

32 盒冷启动 B 的提议和在线证明共 198.88 秒，独立重放 0.327 秒，单盒含设置和重放最长 9.345 秒。C 提议 0.209 秒，严格证明及重放 0.0168 秒，单盒最长 0.0114 秒。旧种子式 B 同真空对照的提议、严格证明、重放分别为 0.194、0.177、0.242 秒。

## 全部 2,688 节点上的正 Schur 尾谱

保持主盲测合同及其原生格，不做上述真空消元诊断。依次扫描主比较每个节点原先共用的 72 组乘子。若原状态块 `K` 被严格证为正定，物理残差 Gram 支配相应的 Schur 补 `H`。因此可用任意精确正交投影 `P` 得到残差平方下界 `tr(PH)`。取浮点正谱方向组成列阵 `F`，再用 Arb 严格验证列秩并计算 `tr((F*F)^(-1) F*HF)`。这保留了 `tr(H_+)` 候选实际可用的全部正方向，最终排除由严格下界越过噪声线决定。

重放以原材料二次块展开重新组装，并验证保存的正状态 frame 及投影。加强版 B 保留旧 B 已重放的证书，不读取真值。此比较检查固定权重银行的全部浮点提议，对能过噪声阈值的候选实施严格证明，可在首个严格成功后停止该节点的进一步验证。数据无法据此给出所有合法 PSD 乘子的最优性结论。

193,536 次提议中有 85,998 个浮点正状态块。1,026 个盒通过严格投影下界和独立重放。原 B 已排除的 925 个盒包含在其中，故加强版 B 取得 **1,026 排除、1,488 见证、174 未决**。原 C 有 1,116 个排除。两者的排除差从 191 个降为 90 个。原 C 使用正状态权重取得且 B 漏掉的 28 个判断全部补回，另有 73 个盒能用其他正状态权重排除。增量提议 34.158 秒，在线严格证明 14.840 秒，独立重放 12.045 秒。

随后逐个验证余下 90 个 C 独有排除的全部 6,480 组同银行权重。6,446 组 `K` 有严格负方向，另外 34 组正定状态的 `tr(H_+)/r²` 上界最高为 **0.9643882241**。逐权重审计无未决，耗时 17.66 秒。这 90 个盒由 84 个结构条件和 6 个同支撑幅度条件组成，原 C 证书的负惯性为 2–6。该结论限于冻结银行。它和真空消元后冷启动 PSD 可复现的结构子集结果同时成立。[逐权重上界核验](positive_tail_upper_audit.json)
