# 实验 B · 有限孔径下的空间材料集合

在 12×12 网格的三个合成材料中，允许核心、边缘和弱背景在各原生格独立变化时，分别排除单盘 55/64、双盘 22/32、环 43/64 个候选中心。每个对象各找到一个与原始读数相容的中心见证。原生 96×96 真空外部合同在 256 个候选中心中排除 247 个，找到一个见证，其余 8 个未决。三组粗网密集检查同一个像素是否可能达到高值时，全部 432 个单格假设中排除 0 个。空间范围和点峰值两个结论都来自相同的对象读数。

## 合同及数据

每组使用七束平面波、九个环上接收端，以及一个覆盖全部源和接收通道的 Frobenius 噪声球。小网格采用相同的等面积圆盘脉冲标量 TM 算子，边长 2 m，135 MHz，入射角 −64° 至 63°，接收角 −73° 至 71°，合成噪声为净读数范数的 3%。原生实验采用存档的 96² 物理网格和填充 Fourier 乘子，400 MHz，选取实际源阵列的角范围 −67.5° 至 67.5° 以及接收的 −78.75° 至 67.5°，噪声 4%。源、接收和噪声的精确数组、碰到角度端点时的实际索引均随实验保存。四个对象独立生成。同对象的盒、背景条件和证书重复是配对检查。源系数矩阵是所选入射字典的单位矩阵，接收端使用存下的通道归一，无额外白化。小网格平面波幅值为 1，原生入射保留存档的 \(\sqrt{10/32}\) 归一。每个噪声球的存储半径在确定性加噪范数外留了净读数范数的 \(10^{-6}\) 正演算术余量。

- 未知中心合同。在每个中心标签 $c$ 上构造核心 $I_c$ 与外形 $O_c$。核心材料逐格属于 $[0.75,1.375]$，外形内的边缘逐格属于 $[0,1.375]$，余域逐格属于 $[0,b]$，其中 $b=0,1/32$。单盘以 $c$ 为中心。双盘以 $c\pm(2,0)$ 为中心，方向和间距固定。环以 $c$ 为中心并留一格中孔，弱背景情形中孔也属于 $[0,b]$。具体半径定义见 [构造函数](run.py)。原生盘的核心半径 2 格、外形半径 3 格，核心下限 2.125，全局上限 3.125，外形之外确知真空。
- 预定形状幅度合同。核心轮廓值 1，边缘 1/2，外部为零。每个轮廓非零格可以独立落在该轮廓值乘上 $[0.5,0.75]$、$[0.75,1]$、$[1,1.25]$、$[1.25,1.5]$ 或 $[1.5,2]$ 得到的区间。同一箱内可有空间起伏。结果覆盖这五个闭区间合同和各自完整中心窗。小网格单盘与环的未排除带并包为 $[0.75,1.5]$，双盘为 $[1,1.5]$。三组均在 $[1,1.25]$ 找到一个见证。
- 任意高值存在合同。对全 12² 网格逐格构造 $\{\chi_i\ge1\}$，其余格自由落在 $[0,1.375]$。任一区域内存在一格达到阈值，对应区域所有此类盒的并集。三组对 144 个盒逐个检查，得到单盘 5 格、双盘 10 格、环 8 格见证，其余未决。找到多格的见证可能来自同一个材料。全域低峰盒 $[0,0.625]^{144}$ 同样未决。原生 9216 个任意高值胞元的全域并集超出本轮预算，全部保留未决。

树根覆盖 [冻结配置](freeze.json) 声明的所有整数格中心。每个树节点按成员盒下端逐格取最小、上端逐格取最大，等价于对同质核心合同取 $I_C=\bigcap_{c\in C} I_c$、$O_C=\bigcup_{c\in C} O_c$。划分的是中心标签。对象可以跨越不同中心子窗的边界。一条祖先排除证书覆盖该子树所有中心，单个见证只赋给经箱约束验证过的一个中心或一个高值胞元。见证从盒中区间点出发，用固定预算的原物理约束最小二乘提议。真空见证可在同一中心的弱背景大盒中重放，也可用于满足具体单格高值事件的原材料重放。网格、盒和数据由不同文件提供，在线程序只读取 [public](public)；真值生成文件由离线评分的独立运行读取，保存在 [offline](offline)。

粗网单盘与双盘的实际见证残差上限分别为 $0.960380r$ 与 $0.962710r$，环为 $0.954453r$，原生盘为 $0.979336r$。所有合成对象的生成材料都保留在其合法真值路径上。原生 105 个访问节点中有 21 个因当前节点外形保留超过 64 行而直接下钻，最终完成 256 个中心的覆盖。其 70 个排除节点以原生存储 Fourier 乘子的 Arb 逆变换独立重放。三个粗网合计重放 459 个排除节点，并抽取每对象 12 个从全维空间独立重放。四组共重放 33 个带标签的见证，包含同一材料在不同合同中的重放。[紧凑机器结果](results/summary.json) · [逐中心和逐胞元标签](results/map_centers.csv) · [独立重放记录](results/independent_replay.json) · [重放实际正负框架](results/independent_replay_frames.npz)

未知背景在 $[0,1/32]$ 的结果是在允许全域背景变化的盒上验证。合成生成材料使用真空外部，背景扩张因此是一项配对的合同变化。任意高值未决区域同时反映当前扇区证书的局限和任意材料盒的自由度。现有零排除可判定为方法本轮未给出该类保证，真实高值相容性的直接证据仅来自已现场验算的见证。96² 结论适用于声明的 16×16 中心窗、固定真空外部和存储离散算子。连续模型误差与器件误差需要各自的统一上界。

## 固定迹机制与用时

在小网格的公共盒 $[0,b]^n$ 中，取统一实扇区权重 $w>0$，光学乘子为零。公共状态块

$$K_b=S^*S+w[I-(b/2)(G+G^*)]$$

通过 $w(1-b\lVert G\rVert_F)>0$ 严格验证。每个候选只在 $k$ 格更改材料端点。令 $T$ 选出这些格的 $(j_i,(GJ)_i)$，$E$ 补入对应的入射迹。局部改变量 $D$ 的每格对角首项为零，非对角项为 $-w(\ell_i+u_i-b)/2$，若该项非零，各有一个正、负方向。代码使用一次公共 $K_b$ 验证求解获得联合迹 Gram。对每个阈值 $t$，比较约化带边矩阵

$$
R_t=\begin{bmatrix}
-D^{-1}-TK_b^{-1}T^* & E+TK_b^{-1}L_b\\
(E+TK_b^{-1}L_b)^* & C_b-L_b^*K_b^{-1}L_b-t I_s
\end{bmatrix}.
$$

把完整带边矩阵加上辅助块 $-D^{-1}$，分两种顺序消元得到 $n_+(A_t)=n+n_+(R_t)-k$，$n_-(A_t)=n_-(R_t)-k$，零计数不变。源块始终保留 $tI_s$。在实际准用 $j$ 上同时验证 $n_+(R_t)\ge k+j$ 与 $jt\ge r^2$。浮点框架由 Arb 校验 Gram 和正性，每个最终节点保存实际阈值、权重、计数、裕度和盒端点。母合同公共算子和源接收矩阵同一，速度差来自相同证书的重放方式。原生真空分支先使用精确约束 $j_i=0$ 删除候选外部，验证缩小后的原带边矩阵，将其列为独立的原生代表性算例。

|---|---:|---:|---:|---:|---:|

## 复现入口

从研究根目录使用带 numpy、scipy、python-flint、matplotlib、threadpoolctl 的 Python。预先完成上层 P0；程序读取通过回执后执行。已经保存了生成后的公开数组，在线重放可以直接使用它们。环境中限制 BLAS 与 Arb 为单线程。

```bash
B=research/z_alg_optical_inertia/fixed_operator_paper/experiments/B
python -B "$B/run.py" prepare
python -B "$B/run.py" online
python -B "$B/run.py" score
python -B "$B/replay.py"
python -B "$B/benchmark.py"
python -B "$B/plot.py"
```
