# 接收方向 SOCP｜旧数据反事实检查

在 C 配对诊断的同一个单束菜单上，SOCP 把 86 个已严格区分动作的方向间隙全部扩大，但没有增加严格区分的动作。原中心方向和 SOCP 均为 86/120，两种能量各为 43/60。此处的 120 个动作来自六个合成材料、两种配对能量约定和各自十个允许角。材料和观测没有增加。

### 如何比较

冻结每个类原来选定的响应椭球、两束旧读数、候选角、新束能量及诊断噪声半径。原始提案、排名、采集和读回文件保持原样。可用的原中心方向取自已保存的二进制数组，未做区间检查的原候选用同一冻结规则从旧数据重建。两种方向都执行这次完整的 192 位 Arb 检查，所以原方向的重新核验分母也是 120。

对同一候选角输入 \(a\)，令 \(d=(C_{a,2}-C_{a,1})a\)。用 CVXPY / Clarabel 实际求解以下二阶锥问题：
\[
 \max_{\|w\|_2\le 1}\left[
 \operatorname{Re}(w^*d)
 -\sum_{i=1}^2\sqrt{a^*\Theta_i a}\sqrt{w^*R_i^{-1}w}
 -2\sigma\|w\|_2\right].
\]
求解器只产生二进制方向。独立重放从原解析 TM 模型、旧读数和冻结权重重建两个椭球，检查联合源秩、具体方向和两类含噪支持端点。单束支持用直接的标量平方根式。严格边要求两个支持区间有正间隙，无需使用求解器目标值。两个进程只读旧数据及成对的公开候选盒。

### 核验结果

| 能量合同 | 菜单 | 原方向已检查 / 严格边 | SOCP 已检查 / 严格边 | 新增 / 丢失严格边 |
| --- | ---: | ---: | ---: | ---: |
| 追加能量 | 60 | 60 / 43 | 60 / 43 | 0 / 0 |
| 固定总能量 | 60 | 60 / 43 | 60 / 43 | 0 / 0 |
| 合计 | 120 | 120 / 86 | 120 / 86 | 0 / 0 |

共同 86 个严格边的单位范数间隙增量下界均为正。最小值 \(1.2865\times10^{-6}\)，中位数 \(2.1355\times10^{-5}\)，最大值 \(7.4985\times10^{-5}\)。另有 32 个 SOCP 返回的方向范数小于 \(10^{-8}\)，不报告其单位范数间隙。这里比较的是具体可复核方向，未做全局最优性的区间证明。该结果仅回答同一菜单的旧数据预测，提案和实际决策数据不变。

单线程保存的方向提议时间为 0.881 秒墙钟、0.844 秒 CPU；核验为 0.213 秒墙钟、0.212 秒 CPU。附带的五类标签图测试仅是组合逻辑小控制。四个严格边构成两个团 \(\{A,B,C\}\) 和 \(\{D,E\}\)，最坏存活类数上界为 2。未证明和负间隙的两条边被忽略。若类面积为 \(1,2,3,4,5\) 且互不重叠，最坏面积上界为 8（回执向上舍入）。这一控制没有新的物理读数。
