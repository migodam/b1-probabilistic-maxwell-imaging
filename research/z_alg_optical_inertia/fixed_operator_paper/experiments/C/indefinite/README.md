# 单像素光学权重与可达接收集合

先取原 6 例新增能量合同的旧数据。对两个能解释旧数据的小盒，使用冻结几何，按统一顺序选择第一个能严格验证的非零负惯性权重。单格光学乘子、全域实部扇区权重按固定列表检查。旧数据和公开盒是唯一输入。无需再生成未来读数。

12 个类均得到一个负方向，旧块饱和且接收块正定。在每个物体的 10 个新角度上，都严格找到了位于两类预测椭球的公共点。对这些具体权重没有任何接收投影能分开两个椭球。公共点不等于一个两类都能散射出的实际值。原冻结正定权重已在同条件下作出严格分离。

运行 `python physical.py`。逐例权重、中心插值、两侧严格正裕量、物理源角和时间保存在 results.json，原六个前瞻试验未改动。
