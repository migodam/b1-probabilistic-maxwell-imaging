# 六件新强散射材料

扫描读取 [公开观测清单](public/manifest.json)，每条记录给出几何文件、G 文件、公开复端口矩阵 Y、全局物理对比度上限 4、实际采样噪声的联合及逐源半径。S 与 B 来自几何文件。阵列与噪声级别在材料内配对；本批有六件材料，24 份观测。

[生成器](generate.py) 从 SRAP 同一标量 TM 约定独立构造 96² 前向场，再用 32² 原物理算子求面积均值材料代理。六件中代理完整多次散射与一次 Born 场之差，以完整散射场归一化为 4.06–6.86。细网 GMRES 方程相对余量上界为 9.91×10⁻¹¹，属于数值解的一致性记录。各对象的代理细粗场差为半环 12.4–28.4%、全环 14.2–35.4%，分母为相应细网干净场范数。该差比最小噪声级大，且只针对个例面积均值代理。按物理外推使用时，需要覆盖全部允许材料的误差界。

离线 `evaluation/` 按观测保存细网干净预测、粗网代理预测、两者间差，以及代理预测到含噪观测的范数。对象级文件保存细网材料和粗网材料。半径的归一化、相对比例、种子和布局见[冻结合同](FREEZE.md)，[实际生成与前向费用](evaluation/generation_receipt.json)为 3.29 秒墙钟、3.18 秒 CPU 的单线程本机运行。

[细网真材料可行性复核](FINE_FEASIBILITY_ZH.md)验证保存的 96² 离散算子。24/24 真材料观测均进入按 `10⁻⁶||Y||F` 扩大的采样球，全部 35 条细网区间排除的余量仍为正。粗网代理差另行计算。
