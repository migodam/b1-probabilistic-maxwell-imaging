# Frozen Task 3 protocol

Physical hypothesis. A strict native lower bound `d_u > r` rejects all real material maps in `[0,u]` under the stored full-wave model. It can trigger a contrast-cap release before a reconstructed residual reaches the noise scale. A crossing decides a class for the full-wave map. The Born map requires a separate test. Useful switching requires comparison at common costs with fixed low, high from the start, and ordinary discrepancy.

## Common inversion

Inversion reads only public complex data and acquisition, radii and pre-existing strict decisions. Projected L-BFGS-B minimizes the sum of normalized half squared physical residual, a fixed 10⁻³ mean-squared first-difference penalty on the smooth update grid and a weak 10⁻⁶ mean-squared material penalty. Material is a tensor-product bilinear interpolant on 16, 32 and 48 nodes per side. All objective and gradient evaluations use the actual 96² forward equations and the adjoint of the full constitutive state solve. All arms start from zero and use identical stages, numerics, charge, and saved checkpoints. Adjustable contrast cap is the sole method input that changes between arms. There are 20 / 30 / 44 full-wave objective-call slots per stage. The last-stage refinement uses all nodes. A residual-only rule releases when the best audited fit to date has remained above 2.5r at the end of the first stage. The search budgets and stage boundaries agree in every arm. The class-exclusion rule releases before the first full-wave application when verified. The high-from-start path uses the same broad cap and therefore exactly equals the data-triggered branch when it triggers. Keep both arm names, with shared computation identified. Fixed-low retains the cap to the end. Choose each arm's minimum regularized objective in the final grid, retaining the smallest full-wave residual separately if selection differs. Report numerical state residual, full FFT / state / adjoint cost, wall and CPU by arm. A terminal residual discrepancy uses independent reconvergence on the same stored operator; approximate fits outside the noise ball do not become legal explanations.

Conventional discrepancy can also inspect the final low-cap solution, which is tested for a residual in ([r,2.5r]). The online control threshold is fixed at 2.5r to operationalize this tolerance. A result outside that envelope cannot support the requested subtle false-image example. All costs for a substantive time-ratio claim must include cache amortization and distinct physical fitting costs.

On original materials, score continuous material relative L2, inside relative L2, background RMS, peak, clean train field and newly simulated offset transmit/receive views when the exact public geometry can be constructed. These additional fields are synthetic checks on withheld angles. The held-out observation is never used to initialize, select or tune. References and withheld views are read only after online fits are written.
