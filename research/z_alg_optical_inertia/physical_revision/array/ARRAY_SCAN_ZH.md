## 角向带宽与剩余源谱

2 m 方形区域边长为 \(2.667\lambda\)，包围圆 \(ka=11.848\)，外场角向带宽尺度 \(2ka=23.695\)。32 发、32 收数值矩阵均满秩。相对奇异幅度门槛为 10% 时，入射算子和接收算子分别保留 23、24 个方向；门槛为 1% 时均保留 29 个。最弱方向相对幅度仍有 0.00247、0.00266。第 24 阶附近观察到带宽衰减，有效方向数随精度门槛变化。 [空间带宽原论文](https://doi.org/10.1109/TAP.1987.1144024) · [外场自由度原论文](https://doi.org/10.1109/8.29386)

固定全局乘子时，\(A=K/\mu=I-u\operatorname{Re}_HG+t\operatorname{Im}_HG+S^*S/\mu\)，\(\nu=n_-(A)\)。把源矩阵 \(H_Y=Y^*Y-\mu L^*A^{-1}L\) 的特征值从大到小排序，舍掉前 \(\nu\) 条，剩余正特征值求和、开方得到距离。若 \(\nu\ge s\)，距离为零。若 \(\nu<s\)，仍要用剩余正谱累加出的距离与误差半径比较。

| 原生负方向数 | 0.75 | 1 | 1.25 | 1.5 | 2 |
|---|---:|---:|---:|---:|---:|
| 不加接收与光学项 | 19 | 21 | 25 | 36 | 45 |
| 稳定光学权，20 收 | 4 | 16 | 20 | 22 | ≥39 |
| 稳定光学权，32 收 | 4 | 13 | 16 | 20 | ≥34 |

这些负方向数由区域、上限、接收和乘子决定，与生成物体无关。接收项半正定且秩至多为 \(p\)，对固定乘子至多移除 \(p\) 个负方向。

- **增加发射有时足够。** 0.75 处固定光学权在两种阵列均有四个负方向。2% 噪声下，20 收的六件中位距离/半径从 10 发的 0.189 升为 24 发的 1.613，32 发至 1.645。32 收依次为 0.345、1.766、1.798。24 到 32 发的增量较小。本轮两环的接收角并不嵌套，且只用一个电尺寸。
- **源谱有剩余，正谱仍太弱。** 在 1.0、32 发时，两种接收数各自最强的筛选提案均出在物体 04、2% 噪声。原生复算时，20 收有 \(\nu=15\) 和两条剩余正谱，距离/半径为 0.13703。32 收有 \(\nu=13\) 和七条剩余正谱，距离/半径为 0.30106。32 收、1.25 和 1.5 的最强筛选提案经原生复算为 0.11331 和 0.01494。20 收在 1.25 的一个原生提案满足 \(\nu=20<32\)，同时正谱尾部严格为零。
- **负方向也会耗尽源谱。** 在 2.0，继承的稳定光学权在两种阵列上都有超过 32 个原生严格负方向，所有测试的发射数都不足以保留源谱。每种几何和上限另筛了同样 825 个标量乘子和六个固定设计。任何单个提案的零距离或有限筛选不通过，都留下材料可行性未决。 [原生有符号源谱](source_spectra.csv) · [原生与筛选对照](summary.json)

## 能量、噪声与复算

网格为 \(96^2\)，全环半径 3.75 m，首发与首收均为 0°。每束幅度按 \(\sqrt{10/s}\) 缩放，在等驻留时间、波阻抗和参考孔径下总入射能流相同。接收数据与算子按 \(\sqrt{20/p}\) 归一化至共同求积口径。同物体在重叠的收发角对共用噪声方向，1% 和 2% 按相对 Frobenius 幅度配对。半径加 \(10^{-6}\|Y\|_F\) 消纳正演误差。旧 10×20 数据、算子及半径逐位复用。 [冻结设计](FREEZE.md) · [观测清单](observations/manifest.json)

从本目录执行以下命令，依赖 NumPy、SciPy、python-flint、threadpoolctl 和 matplotlib。仅数据准备读生成材料。后续使用公开数据与几何，批量求解共同收发列，并检查原生驻点缺陷及其对源谱的影响。

~~~sh
python -B prepare.py
python -B screen.py
python -B verify_native.py --receivers 20
python -B verify_native.py --receivers 32
python -B verify_native.py --receivers 20 --high-grid-controls --equilibrate
python -B verify_native.py --receivers 32 --high-grid-controls --cap 1 --cap 1.25 --cap 2
python -B verify_native.py --receivers 32 --high-grid-controls --equilibrate --cap 1.5
python -B bare_inertia.py
python -B refine_gaps.py --receivers 0
python -B refine_gaps.py --receivers 20
python -B refine_gaps.py --receivers 32
python -B summarize.py
~~~

Apple M4 上进程 CPU 实测为 96.6 秒用于数据准备及生成材料误差球审计，26.2 秒用于投影筛选，20 收与 32 收主原生流程分别为 312.4、256.3 秒。高上限网格复算、原生正谱间隔补算、初次未收敛重试的逐项时间见机器结果。初始数据准备的噪声逐项匹配容差过紧，已调整到舍入量级并重算前两个物体。两路初始原生证明在修正源谱区间的归一化时中止，各约 35 秒。不同进程并行，墙钟不能相加。
