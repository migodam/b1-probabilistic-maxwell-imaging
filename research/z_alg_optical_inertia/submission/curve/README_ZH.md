## 两套固定的 4×4 权如何迁移

单源比较从旧 2% 的 01、05 两个公开观测优化出两套 4×4 权。每套权冻结后原样应用于六件材料和全部五个配对噪声。由单源比较复用已证明的 \(K/\mu_0\succeq 2^{-10}I\)，每套只对 30 列共同右端 \([S^*/\mu_0,Z_0B]\) 做一次正演格点上的线性求解与完整 Arb FFT，其中 \(Z_0=\operatorname{diag}((uD_\mu+iD_\lambda)/(2\mu_0))\)。每份观测的右端由拼接矩阵 \([Y;I]\) 从共同右端线性生成。驻点二次值与缺陷范数的 Gram 都可先压缩为共同的 30×30 矩阵，然后逐份公开观测代入。

01 来源的权仅在 01 上于 0.5%、1%、2% 通过，05 来源的权仅在 05 上于同三级通过。两支共六次通过全部也由同权的单个最佳相干照明通过，六个案例均落在 2×2 支的成功集内。该比较沿用公开旧样本，支持的是固定乘子的交叉应用观察，独立对象数仍为六。 [60 条严格结果与同权单源上下界](fixed_blocks.75.json) · [单源原证明](../single/coherent_general_verified.json)

## 观测来源与真材料可行性

对每件对象取已发布的 96² 全环干净场 \(Y_c\) 与原 2% 观测 \(Y_2\)。离线构造 \(Y_p=Y_c+(p/2)(Y_2-Y_c)\)，其中 \(p=0.5,1,2,5,10\) 按百分点计。2% 逐位复用原观测及原已审计半径。这个配对 10% 与原独立抽样的 10% 是两份不同数据。公开数组仅存复观测，公开清单存 Frobenius 半径及 \(10^{-6}\|Y_p\|_F\) 补量后的半径。每个球的真材料可行性用 \(\|Y_p-Y_c\|_F\) 的区间上界加原真正演与存档 \(Y_c\) 的误差上界核对。六件各按一个材料计数，五个噪声级别属于配对测量条件。 [30 个公开输入](observations/manifest.json) · [离线区间审计](observation_audit.json) · [原真正演证书](../../results/theory/fine_feasibility.json)

## 搜索与原生证明

先用原生 Green FFT 作用于低 Fourier 模式、\(S^*\)、\(B\) 及其 Green 像，构造候选子空间。每个上限扫 25 个全局光学比值与 33 个正实乘子，共 825 个全局状态配置。对每个公开观测分别取合法源尾部改进。2×2 象限以同样的步长同时比较仅实部、仅光学、两者联合的全局与分块梯度。主目标是保留的正特征值之和。它为零且仍有可用照明时，尝试提升第一条带符号保留特征值。在三个较高上限所有筛过的全局配置都耗尽照明，故此梯度起点缺少可保留的源尾部。相同 \(\nu\) 的几组过小实乘子提案遇到原生迭代停滞，用可稳定求解的公开全局种子和相同分块梯度做了回退。 [候选与成本](search.json) · [全局回退](recover_global.75.json) · [空间回退](recover_local.75.json)

正例由独立区间算术对全部 9,216 个材料坐标证明。令 \(\mu_0\) 是正归一化尺度，\(m_j=(D_\mu)_{jj}/\mu_0\)，\(t\) 为各块归一化光学权的均值，\(z_j=(u(m_j-1)+i((D_\lambda)_{jj}/\mu_0-t))/2\)。用 \(Z=\operatorname{diag}(z)\)、实数 \(a,\sigma\) 和 \(\beta>0\) 表示两路 Fourier 场 \(Fx\) 与 \(FZ^*x\)。对每个模态 \(g\) 计算

\[
 \mathcal C_g=\begin{bmatrix}
 1-u\operatorname{Re} g+t\operatorname{Im} g-a & -\overline{(g-\sigma)}\\
 -(g-\sigma)&\beta
 \end{bmatrix}.
\]

原生 \(K/\mu_0\) 等于上述二路符号、接收低秩项及对角
\(a+m_j-1-2\sigma\operatorname{Re} z_j-\beta|z_j|^2\) 的和。未保留的 Fourier 模态满足 \(\mathcal C_g\succeq0\)，逐个用 Arb 检查其 Schur 补，故可给出 \(K/\mu_0-\gamma I\succeq D+\Phi C\Phi^*\)，其中 \(D\) 为严格正的对角项，\(\Phi\) 包括截取的 Fourier 列、同列乘 \(Z\) 及接收列。全局权简化成一路 Fourier 场。\(C^{-1}+\Phi^*D^{-1}\Phi\) 的严格负子空间经区间算术核对，从而界定 \(K/\mu_0\) 在 \(\gamma\) 以下的最多方向数。完整 Arb FFT 在试向量上独立核对相同数量的严格负方向，因此实际惯性和正谱间隔同时得到证明。

在原 96² 方程上数值求驻点 \(X\)，然后对其缺陷 \(R=(K/\mu_0)X-L/\mu_0\) 使用 Arb FFT 复核。源矩阵下界由 \(H_0-\mu_0\|R\|_F^2/\gamma\,I\) 给出，\(H_0\) 以 \(X\) 处的二次值计算。只积加丢弃前 \(\nu\) 条后的正源谱下界。图中填实的标记表示严格跨过误差球，0 表示该复算的提案缺少正的保留谱下界。 [原生算子](native.py) · [独立区间验证](envelope.py)

## 复算命令

从本目录用同一套 NumPy、SciPy、python-flint、threadpoolctl 和 matplotlib 执行。先前的干净场与真材料只对第一条命令开放，后续证书计算均从公共数据重新载入。

```bash
python -B generate_observations.py
python -B search.py --out search.json
python -B verify.py --cap .5 --arm global --out global.5.json
python -B verify.py --cap .75 --arm global --out global.75.json
python -B verify.py --cap .75 --arm local --out local.75.json
python -B verify.py --cap .75 --arm global --stable-recovery --object optfresh_02 --object optfresh_03 --object optfresh_06 --out recover_global.75.json
python -B verify.py --cap .75 --arm local --stable-recovery --object optfresh_02 --object optfresh_03 --object optfresh_06 --out recover_local.75.json
python -B focus_global.py
python -B fixed_blocks.py
python -B summarize.py
```
