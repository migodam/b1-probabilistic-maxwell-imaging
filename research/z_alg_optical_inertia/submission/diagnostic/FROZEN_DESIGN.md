# Frozen diagnostic design

Test whether a conventional ridge-regularized reconstruction can miss a peak that the same noisy measurements require. Compare the complete VIE residual of that single iterate with an existing residual lower bound for every material below the same cap. This is a diagnostic on two exposed synthetic objects.

1. Archived matched 24² ring `r10_twod / r10_twod_0001 / r10_twod_0001 / r10_twod` with 12 illuminations and 48 receivers. The existing positive certificate excludes cap 5 against the frozen CN99 radius. Historical single- and dual-CIE noninitial archived physical checkpoints and budget states start at peak 19.682602, and the saved task-constrained Gauss–Newton states have peak at least 14.4922. The low-peak saved CIE array is just its constant initialization.
2. Native 96² `optfresh_01__pw180_10x20__n02`, first lexicographic object in the six-object, pre-existing half-ring 2% cell with all six certified above 0.5. This uses the 10 illuminations, 20 receivers, saved public Y and exact stored Fourier operator, with the generation-error-expanded radius used in the prior certificate. No native inverse iterates for this observation were found in the study tree. This is synthetic data saved from a full-wave model and a fixed noise draw.

Run the same conventional nonnegative Tikhonov Gauss–Newton policy on both observations. Initialize to zero, penalize `λ ||m||²/2`, and fix `λ = 0.1 ||DF(0)||₂²`, so ridge is a tenth of the maximum curvature at the background. Set no upper box in the inversion. In each outer iteration minimize the real/imaginary stacked linearized least-squares objective plus the same zero-reference ridge under nonnegativity. Use 128 accelerated projected-gradient steps starting from the current material, with step denominator `||DF(m)||₂² + λ` and standard FISTA momentum. Backtrack from the proposed material with dyadic steps, keeping the first strict decrease in the full regularized objective, up to ten trials. Stop on a failed line search, relative objective decrease below 10⁻⁶, or after 12 outer updates, and report the actual endpoint and full path regardless of the final peak. Native solves use the full FFT VIE at relative tolerance 10⁻¹⁰ and ring solves use dense LU. If confirmation of a solution fails, record the failure. Do not select a checkpoint or change the penalty after seeing peaks.

Write candidate materials, complex fields, and numerical readout before opening either reference truth file. Recheck the endpoint's extrema from its stored binary64 array with interval arithmetic. Independently evaluate the full-wave residual on the same model and compare it with the pre-existing observation radius and proof bound. Afterwards show reference material and internal/background errors. The truth is already exposed in prior work and the protocol is a follow-up. The observed phenomenon will be called an endpoint-specific diagnostic irrespective of success or failure.
