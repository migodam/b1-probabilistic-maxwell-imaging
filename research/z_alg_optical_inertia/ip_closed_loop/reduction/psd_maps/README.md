# 同一地图合同下的连续正定权重对照

在五个 32² 宽环形节点和一个原生 96² 宽环形节点，旧不定权重库的排除均可重放。同一有限权重库的正定分支排除 0/6。放宽为连续正定权重，再经 192 位验证，严格排除 1/6。该正例是 32² 第一个弱背景环形观测的节点 510，正定权重的严格余量为 0.59271，旧离散不定库的余量为 0.19712。另四个 32² 节点各有一个原网格接收零空间向量，其两个组能量均严格为负，证明该两组正半定权重族在这四个节点没有非零可行权重。原生宽环形节点的正定结果保持未决。两个原生窄盒均有正定排除，严格余量分别为 1.44735、1.21027。

## 公共输入和选择

全部数据取自地图实验的新公开弱背景原始 7 发 9 收复数观测，同一 Fourier 算子、数组和 3% 噪声球。搜索程序只读取 `maps/public/` 及已有地图的余量或公开中点拟合残差。候选位置在搜索前写入 [冻结清单](freeze.json)。32² 取四个观测各一个旧不定排除中位余量，第一个观测再取一个最弱正余量。原生宽环形取公开中点残差中位位置，另取原生窄环形、窄双夹杂两个最大残差位置。宽盒用核心每格 $[3,5]$、边缘每格 $[0,5]$ 和独立外部 $[0,1/32]$。窄盒的核心为 $[3.75,4.25]$，边缘区间乘以 0.5，外部保持同样未知背景。比较的矩阵与原带边地图同一，包含零延拓下合法的真电流。

## 连续优化和验证

材料权重取两个独立的非负标量。背景权重记为 $\mu>0$，候选框内权重为 $\mu\kappa$，$\kappa>0$。用固定 Fourier 迹 Gram 求出不含数据项的状态负惯性、接收 Schur $P_0$、中心响应及源能量项。对同一组系数，最终状态的负惯性是物理状态负数减去小接收矩阵 $I+P_0/\mu$ 的负数。两数都经一侧验证且相等时，才接受正定状态。源舒尔取七列全部正谱之和，最终量是其平方根减实际噪声半径。局部连续搜索以浮点目标选择候选，旧一侧余项在同次提议中计量。粗比值搜索的边界是 $\kappa\in[2^{-19},2^5]$、$\mu\in[2^{-20},2^8]$，在可行接收区间内一维连续优化 $\mu$。32² 宽盒随后对 $\log_2\kappa\in[-13,0]$ 加密为 105 个初值，并再搜索可行区间附近。所有候选、数值未过关和开销随逐盒回执保存。

对数值最优和已有最佳一侧权重，用 192 位 Arb 从原 Fourier 乘子重新构造背景能量、迹 Gram、源和接收耦合。原补块和每个压缩、求逆、惯性判断均用验证算术。以全源正谱的浮点特征框架为提议，区间计算 $\operatorname{tr}(V^*HV)$，再除以 $\|V^*V\|_2$ 的区间上界。这样得到 $\operatorname{tr}H_+$ 的一侧下界。节点 510 的严格式使用 $\kappa=0.0036821972241252577$、$\mu=0.04547519474642115$。该节点较松的原浮点误差上界只得到负余量；原 Fourier 区间重放确定了正定符号和正余量。[细化搜索](refined_broad_32.json) · [192 位逐项重放](exact_replay_refined_32.json)

在原网格取试探电流，用精确接收 Gram 求解投影出 $Sj=0$。区间计算分别上界外部和框内组能量 $u_0,u_1$。若权重得到正半定状态，归一比 $\tau=\kappa/(1+\kappa)$ 必须满足 $(1-\tau)u_0+\tau u_1\ge0$。第一轮将试探电流限制在候选框及其附近，各样本的必要区间仍有交集。第二轮在 32² 的全部 1,024 个原物理格上找到了以下反例。每行的两个上界来自同一个精确接收零空间向量。[局部试探](dark_cone.json) · [全域试探和原数组](dark_cone_full_32.json)

两种能量同时严格为负时，任意非零非负权重对都会得到负方向。整体权重任意接近零，该方向仍严格为负。换成任意半正定接收权重也不能改变该方向，因为 $Sj=0$。两个材料权重都为零时，数据项可由任意接收拟合电流消去。验算所用接收 Gram 可逆，因此零权重本身不给排除。工况只覆盖这两个分区共享的扇区权重，独立逐格系数、光学乘子和其他多源约束另属不同族。原生宽环形的局部试探未得到全锥结论。

固定源投影的补充 SDP 对两个标量仿射建模并计入同一完整接收数据。SCS 返回 `optimal_inaccurate`，原算子区间复算给该提议 $\nu=1$，因此它没有进入正定结果。用连续搜索找到的节点 510 正定证明独立保留。[求解及拒收回执](convex_probe.json)

```bash
P=research/z_alg_optical_inertia/ip_closed_loop/reduction/psd_maps
python -B "$P/search.py" 32
python -B "$P/search.py" 96
python -B "$P/refine_broad.py"
python -B "$P/exact_replay.py" 32 --refined
python -B "$P/exact_replay.py" 96
python -B "$P/dark_cone.py"
python -B "$P/dark_cone.py" --full32
python -B "$P/dark_cone.py" --replay-full32
python -B "$P/convex_probe.py"
```
