# 不定状态下的批量材料盒判定

固定 Green、入射、接收和噪声球，在两组已有强散射 TM 读数上比较**完全相同的一条材料排除规则**。一臂逐盒装配完整电流及带边矩阵并计惯性，另一臂一次预计算固定迹 Gram，逐盒只更新四维有效局部块。两条分支的公共状态均为不定。本实验给出局部盒认证与摊销证据。全视野覆盖和实际加测收益由论文的独立实验给出。

## 两个公共算子与候选设计

| 网格、原始读数 | 电流变量 | 固定真空或未知背景合同 | 公共负惯性 | 每盒原带边 → 约化维数 |
|---|---:|---|---:|---:|
| 32²，`shiftbox32_01__pw360_10x20__n02` | 1,024 | 0.35 m 中心圆内 $[0,2]$，外部每格未知 $[0,1/32]$ | 7 | 1,034 → 14 |
| 96²，`strong_ring350__pw360_32x32__n02` | 1,153 | 档案允许活动区内 $[0,3.1318359375]$，外部确知真空 | 9 | 1,185 → 36 |

两组为不同的仿真材料，均沿用已有 2% 带噪复读数。32² 真实生成材料是带缺口的双夹杂，原生 96² 是峰值 3.50 的空心环。相对于同离散模型的真实无噪读数，Born 误差分别为 285.57% 与 376.28%。两组生成材料各在自己的原物理噪声球内经过核验。它们均在本次数值机制试验的候选族之外。完整公开读数与选定网格索引见 [public_readings.npz](public_readings.npz)，离线生成材料的适用范围见 [物理对照](physics_controls.json)。

公共盒是每个域内的代数准备点。两组实验分别冻结 1,000 个移动支撑。前 100 个是对应前缀，每次改变三个格点的区间。两格保持中点、缩窄宽度，对应两个独立的非零秩一块，每个都有一条精确为零的电流迹行。第三格扩大上端，对应一个可逆的 2×2 不定块。因此每盒 6×6 更新只有秩 4。不同盒的改变支撑唯一，且任意两盒互不包含。公共盒没有通过本次阈值，且每个移动盒扩大了公共盒的一个上端，不能从公共盒的判定继承排除。两组使用同一 $j=1$、$t=1.001r^2$ 规则，权重和材料先验也在各自的两条计算分支中一致。

本次是对已有读数的数值机制试验。它用公开读数选择了靠近决定阈值的权重和公共范围，随后固定候选列表、阈值和独立重放节点。两臂共享冻结前的探索，计时从配置固定后的读数和模型加载开始。每批 100 与 1,000 个盒是两件独立材料的配对条件，排除比例只描述此工程测试。生成材料单独核验，无法从本批候选推断真值保留率或盲测排除率。

## 实测结果

| 网格 | 不同盒 | 严格排除 | 原浮点在线 (s) | 移动迹浮点在线 (s) | 移动迹 Arb 在线 (s) | Arb 冷准备和在线 (s) | 另含原矩阵抽样重放 (s) |
|---|---:|---:|---:|---:|---:|---:|---:|
| 32² | 100 | 81 | 52.413 | 0.00893 | 0.08976 | 95.831 | 234.408 |
| 32² | 1,000 | 757 | 870.609 | 0.11938 | 0.95454 | 96.696 | 381.962 |
| 96² | 100 | 51 | 82.954 | 0.02089 | 0.61439 | 140.305 | 238.383 |
| 96² | 1,000 | 472 | 1,157.239 | 0.25485 | 5.56143 | 145.252 | 341.644 |

在线列为两种状态与带边惯性计算的墙钟。冷费用含共同读数装载、候选生成及必要的浮点和区间准备。原物理区间重放按前缀分别抽取两盒和四盒。两尺度的 2,000 个盒全部得到完整 Arb 正负符号并与完整浮点计算一致。原矩阵独立重装的八个区间节点全部匹配，其中既有排除也有未决。100 盒的冷验证及重放超过对应浮点原计算，1,000 盒的实际总费用则下降。浮点两臂的在线速度用于同算术比较，区间成本单独列出。

强散射对照中，从每个批次的重放样本选一个已排除节点。相同候选盒的合法全上端扰动使中心 Neumann 算子的谱半径分别大于 1.001049 和 1.108350。其固定均匀扇区权重在精确接收零空间有严格负能量，因此任意正总缩放仍为不定状态。允许背景与框内可变权重的更强对照另见 [地图正定权重试验](psd_maps/README.md)。

## 数值验证的口径

- **浮点同规则。** 两臂把物理状态和带边矩阵各计一次正、负、未定符号。完整计算使用缓存后的原坐标矩阵和 Bunch–Kaufman 分解。约化计算使用一次固定状态求解，提取每盒所需的迹 Gram 和源耦合。
- **逐盒区间。** 用 128-bit Arb 检查公共主块的确切惯性、验证公共方程求解，在小矩阵上逐盒证明正负号。只有超出维数和噪声门槛才标为严格排除。未决标签保留兼容性未知。
- **独立原坐标。** 每种规模固定抽样四盒，重新由原算子和逐格端点装配状态与带边矩阵，单独核验全部符号。原生 96² 的 Fourier 乘子用 Arb 独立逆变换，严格施加所声明的外部真空后保留全部原生允许坐标。
- **奇异公共态。** 在精确有理回归中，公共态具有一正、一负、一零。一个真实秩一形式变化保留了状态零方向，但源耦合使带边矩阵没有零方向。第二种变化抬升了状态零方向。两种情况的有理精确合同和区间重放一致。主规模计时使用可逆且不定的公共状态。[奇异回归](pivot_regression.json)
- **物理对照。** 同一格点区间和观测中，从独立抽样选取一个已排除的盒来检验中点 Neumann 收缩。另用真实合法的全部上端扰动计算谱半径下界，并检查观测零空间内的负能量。检验的是同一空间权重族和普通中心展开，结论范围不延伸到一般空间 PSD 优化或加权扰动算法。[对照回执](matched_controls.json)

## 复算入口

从研究根目录执行。需要依赖 `numpy`、`scipy`、`python-flint`、`threadpoolctl`、`sympy` 和 `matplotlib`，版本见上一轮固定算子项目的 [requirements.txt](../../fixed_operator_paper/requirements.txt)。加载的原始数组来自同级 [ip_guided_v4](../../ip_guided_v4/boxes/)、[ip_final_v5](../../ip_final_v5/strong_control/) 和 [synthetic](../../synthetic/public/)。两种规模的原始浮点和区间验证均在同一 Apple M4 主机，BLAS 和 Arb 采用单线程。性能收据区分进程 CPU 和墙钟，批次之间有并行活动。

```bash
P=research/z_alg_optical_inertia/ip_closed_loop/reduction
python -B "$P/benchmark.py" --side 32
python -B "$P/benchmark.py" --side 96
python -B "$P/pivot_regression.py"
python -B "$P/matched_controls.py"
python -B "$P/score_physics.py"
python -B "$P/summarize.py"
```

`--count 100` 仅复算前 100 盒，并写独立结果文件。`--output-dir` 可保存新的计时回执目录。`--proposals-only` 仅检查浮点提议，用于数值调试。默认完整批量直接比较会用数分钟，独立区间重放另计。不同读数的时间不含重新生成已冻结观测的成本。结果字段包括共同读入、批候选生成、公共代数、固定迹浮点准备、原 Green 球重建、区间准备、每批在线和原坐标抽样重放。抽样区间费用不外推为逐盒原坐标区间时间。
