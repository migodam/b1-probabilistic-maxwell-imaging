# 最接近的命题和本次用法

| 已发表结论 | 本文采用它做什么 | 需要本文物理与数值证据的部分 |
|---|---|---|
| 两个已知散射矩阵的最优二分类相干入射由差矩阵的最大右奇异方向给出 | 实施已知类中心的相干对照。允许一般入射功率矩阵，进行广义本征分解 | 旧读数相容的两个未知材料类、全噪声球界、真实共同读数下的最低同时控制端口数。[Bouchet 等，原文](https://dbouchet.github.io/assets/publications/PhysRevLett.127.253902.pdf) |
| 复 Hermitian 二次约束较少时，半正定提升具有低秩最优点 | 对固定发射与两个二次响应外包证明秩一。需要严格可行与约束加权后强制有界 | 哪些二次型由 Maxwell 旧数据导出、是否非空、物理材料是否填满外包，以及实测前可验证的严格阈值。[Huang 与 Zhang](https://doi.org/10.1287/moor.1070.0268) |
| 带界不确定性下可设计输入来确保不同故障输出集合分离 | 采用最坏情形可分离性作为采集目标 | 非线性散射、未知逐格共同材料值、有限孔径及弱背景导致的输入输出可行集合。[Scott 等，原文](https://web.mit.edu/braatzgroup/input_design_for_guaranteed_fault_diagnosis_using_zonotopes.pdf) |
| 无源 Maxwell 电流满足局部功率约束，多场共用结构带来跨场关联 | 保留本构的区间扇区与不同照明之间的矩阵约束 | 有旧观测的逆问题、位置排除、暗电流证明连续两组权重的正定障碍。[Kuang 与 Miller](https://millergroup.yale.edu/sites/default/files/files/2020_12-Kuang2.pdf) · [Shim 等](https://doi.org/10.1515/nanoph-2023-0630) |
| Hermitian 带边惯性相加、投影谱交错、分块静态凝聚 | 在不定或有零模的更新上复用当前与总场的局部行 | 同物理算子上原维与压缩惯性一致、千盒完整计费，不能把经典消元重新命名为 Maxwell 定理。[Haynsworth](https://doi.org/10.1016/0024-3795(68)90050-5) · [Huynh 等](https://doi.org/10.1051/m2an/2012022) |
| 有界误差集合反演区分排除、可行、未决；采样与单调性定位各有自己的观测条件 | 将输出定义在制造规格允许的所有位置，用同一读数给 OSM 对照。原生有限孔径接收矩阵没有连续全孔径的观测信息 | 物理可行材料、可比较的正定/不定对照、位置类更新后的严格外包。[Jaulin 与 Walter](https://doi.org/10.1016/0005-1098(93)90106-4) · [Potthast](https://doi.org/10.1088/0266-5611/26/7/074015) · [Griesmaier 与 Harrach 勘误](https://doi.org/10.1137/21M1399221) |

参考文献中的 DOI 及卷页见 [references.tex](../references.tex)。本文吸收了小型复二次问题的精确性和最优相干入射这两条成熟结果。作者的原创性判断是针对整条“旧 Maxwell 观测约束未知材料类—可实现的必要界和事前充分界—取得新的全波读数”论证链，不主张检索已排除所有更早先例。

近年实验的设计也有具体借鉴。Guo 与 Liu 使用多频背散射，定量采样步骤借助 Born 表示；这里用单频有限孔径，Born 场误差大于 100%，评价对象是可行材料的整类排除。Schumacher 等用切点能量正则化三维障碍表面并检验形状重建；Borges 等在弹性薄板上分别测试噪声、有限数据和多个障碍对凸包与定位的影响。因此我们在同一张表中保留未知背景、噪声、边界裁剪和两个夹杂，明确检测中心与恢复图像的差别。它们的物理观测不同，不能用作本次阵列上同预算的直接对照。[Guo 与 Liu，§§3–5](https://arxiv.org/html/2604.25583v1) · [Schumacher 等，原文](https://arxiv.org/html/2512.14590v1) · [Borges 等，实验 §5](https://arxiv.org/html/2603.21477v1)
