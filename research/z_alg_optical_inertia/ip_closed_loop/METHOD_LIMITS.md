# 结论在哪些条件下成立

| 结论 | 直接依据 | 适用范围 |
|---|---|---|
| 排除中心 | 离散 Green、同一噪声球、整类材料的一侧距离界 | 给定尺寸、轮廓、取值公差与可达中心。每格可独立改变；扩大的形状族需要重新检验 |
| 找到可行中心 | 明列一份实材料，原方程残差、逆界与接收误差共同给出全波上端点 | 只证明这一材料存在；其余未决中心继续保留 |
| 四个位置需要不定检验 | 原 1,024 维存在接收零空间电流，背景与整块足迹的两个实部扇区能量同时小于零 | 两组非负实部权重的连续锥，允许任意正扫描缩放及正半定接收权重。额外光学乘子、逐像素乘子是其他比较类 |
| 给两个二次响应集合定距 | 两个复 Hermitian 不等式；严格可行，加权接收二次块强制有界 | 此时强对偶对二次外包精确。物理类通常只是其子集。实际严格下端点仅用弱对偶 |
| 同能量单角不能保证 | 同一对真实全波材料同时相容于旧数据，逐角存在共同新读数 | 对给定 15 个角度的任意因果单发序列，限固定总入射能量及整段新增读数的一个绝对误差球。独立可平均的随机噪声需重定模型 |
| 必要端口数 | 排遍较小支持给出物理不可能性，至少一组较大支持给出全类充分性 | 空间采样字典中的同时可控方向，能量采用域内入射场的 Gram 矩阵；真实馈电矩阵、驱动限制和天线效率需要测量 |
| 算时 | 同机墙钟和 CPU，区分准备、在线、独立原坐标复核 | 100 / 1,000 个更换的材料盒属于同一个原观测，不是不同物体。96² 快速更新计时允许活动的电流数为 1,153，弱背景全图另行计时 |
| 实测外推 | 七个原始暗室实物，留出接收弧，按探头校准重算 | 为已有读数的回放；实验没有重新配置物理相控阵。7 件实物没有被计入模拟盲测 |
| 网格 | 原生 96² 与 32² 分别使用自身完整离散算子 | 两个实际样品细粗差均大于接收噪声；目前没有给全部容许材料的连续离散误差上界 |

开发阶段的 20+2 个二类算例为按近阈条件挑出的机制算例。独立 12+2 个确认对象只用旧测量条件招募。起始固定能量、后续按旧数据调整能量、稀疏发射和修改的见证属于同一批对象上的配对实验。强头部结果只使用原生模型、相同入射能量、相同接收误差与额外采集前写入的命令。工程应用若允许任意二维缺陷、材料有损、三维场、仪器未知增益或非线性发射链，还需适配材料条件和仪器误差。

同轮廓的两参数全波拟合已经找对 18/18 个中心（1/18 份材料符合原噪声球）。本研究没有观测到中心点定位优于该对照。每个中心的整类排除与逐格可变的材料见证是不同的输出。[配对数据](maps/template_control/summary.json)
