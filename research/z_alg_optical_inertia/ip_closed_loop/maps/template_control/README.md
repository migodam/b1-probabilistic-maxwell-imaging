# 同模板全波位置对照

使用 16 件 32² 和 2 件原生 96² 实际弱背景对象的原始 7 发 9 收复观测。形态模板按同一个位置图实验提供，噪声球、格中心、边界剪裁以及全波离散算子保持一致。此次复用旧观测和全域名义排序。

每件对象先保留旧全波零背景名义模板残差最小的五个中心。对每个中心以核心系数 4 全波计算外部背景 $0,b/2,b$ 三个材料点。再从该中心误差最小的锚点做有界两参数非线性最小二乘。核心公用系数在 $[3.75,4.25]$，外部共用背景在 $[0,1/32]$。边缘格保留模板的 0.5 系数，背景也包含模板的孔。每次目标或有限差分计算都调用原离散全波算子。最小二乘没改进时保留原锚点。

拟合阶段保存选出的中心、两个参数、材料和端口数组。随后独立调用原算子复算该材料，检查电流方程，并给落在噪声球内的点做有界验算。评分阶段才读取生成中心。中心吻合、数值残差和取得严格物理见证分别统计。

## 结果

| 网格 | 三锚点中心命中 | 三锚点进入噪声球 | 有界拟合中心命中 | 有界拟合残差 / 半径 | 严格物理见证 |
|---|---:|---:|---:|---:|---:|
| 32² | 16/16 | 0/16 | 16/16 | 0.98539–1.07982 | 1/16 |
| 96² | 2/2 | 0/2 | 2/2 | 1.00426–1.00942 | 0/2 |

两系数拟合改善了全部 18 件的原始零背景名义残差，合并残差中位数为 1.03202 倍噪声半径。唯一严格见证为 M32-D04，端口残差上界为 0.98558 倍噪声半径。全波复算的最大电流方程残差为 $8.91\times 10^{-11}$。共执行 3,151 次拟合全波调用，逐对象拟合总计 67.89 CPU 秒，所选点的全波复算和有界验算总计 0.454 CPU 秒。几何加载和原算子复核设置费用另列于机器结果。试验报告给出了一个共用核心幅度和一个均匀背景参数的实际点拟合。逐格变化的材料、其他位置和其他先验仍由各自的物理契约描述。
