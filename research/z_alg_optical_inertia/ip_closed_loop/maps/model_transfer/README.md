# 两件原生材料的跨网格端口差异

用已经生成的两件 96² 实际弱背景材料，逐 3×3 格做面积平均，再放入冻结的 32² 全波算子。边长和频率均为 2 m、400 MHz，观测和真值来自原来的配对对象。

冻结的 32² 发射场与原生 96² 在重合格中心的相对误差为 $8.51\times10^{-16}$。七束均还原为 −67.5°、−45°、−22.5°、0°、22.5°、45°、67.5°。九行接收算子与各自的离散等面积盘公式相符。32² 原存未加权端口，原生旧阵列的相同角度行带 $\sqrt{20/32}$ 的接收归一。两种网格的积分单元不同。按单元系数和归一缩放共点列后，接收矩阵相对误差为 $1.96\times10^{-15}$。比较时用这项已知校准，将 32² 的预测值乘以 $\sqrt{20/32}$ 表示为原生端口单位。

| 对象 | 32²–96² 净场差 / 原净场范数 | 净场差 / 原噪声半径 | 粗网对原始读数残差 / 原噪声半径 | 充足配对半径 / 原噪声半径 |
|---|---:|---:|---:|---:|
| M96-R01 环 | 15.815% | 5.271 | 5.284 | 6.271 |
| M96-P01 裁剪双夹杂 | 6.768% | 2.256 | 2.441 | 3.256 |

表中配对半径取 $r+\|F_{32}(\bar\chi)-F_{96}(\chi)\|_F$，对这两个材料分别为 0.27826 和 0.10867，单位为原生端口的联合 Frobenius 范数。已施加的 3% 复噪声球不足以容纳这两次网格转移。同一材料类的统一跨网格误差上界需要另行验证。
