# 已有工作与本文能主张的增量

| 原文或命题 | 已经提供的数学或物理内容 | 本文在此基础上实际计算的量 |
|---|---|---|
| [Trivedi 等，2020](https://doi.org/10.1103/PhysRevApplied.14.014025)；[Angeris 等，2021](https://doi.org/10.1364/OE.415052) | 无吸收结构与光子设计可以用受材料和波动方程约束的二次型求性能极限。 | 观测复数矩阵已经给定。研究所有可能材料的接收残差能有多小，在每个物理电流实现上保留源矩阵的负秩。 |
| [Molesky 等，2020](https://doi.org/10.1103/PhysRevResearch.2.043398)；[Kuang 与 Miller，2020](https://doi.org/10.1103/PhysRevLett.125.263607)；[Shim 等，2024](https://doi.org/10.1515/nanoph-2023-0630) | 全局与局部电磁功率约束、多激励协同、空间分区都已有先例。 | 显式保留中心的局部本构行给出距离下端。反向计算使用全盒帧限制，能在一个明确网格上界定任取若干格点的这整个方法族。逐行本构等式与分区积分功率是不同约束。 |
| [Fan，1949](https://doi.org/10.1073/pnas.35.11.652)；[Tian，2013，推论 4.5 式 4.38](https://arxiv.org/abs/1301.2567v1) | Hermitian 谱的变分与二次矩阵函数的秩和惯性极值。 | 未约束的负方向能消去哪些源特征值是直接推论。专门结果来自完整材料关系如何限制这些方向，以及需要多少实际负模电流才能接近指定观测。 |
| [Douglas，1966](https://doi.org/10.1090/S0002-9939-1966-0203464-1)；[Boyd 与 Vandenberghe，2004](https://doi.org/10.1017/CBO9780511804441)；[Miller 等，2016](https://doi.org/10.1364/OE.24.003329) | 算子收缩分解、凸对偶与材料耗散因子均为成熟结果。 | 对物理接收器投影后，距离最优源矩阵乘子的每个特征方向可独立取权重。在同一复材料实验上对全部公共权重给出上端点，对独立权重给出跨越噪声的下端点。 |
| [Griesmaier 与 Harrach，2018](https://doi.org/10.1137/18M1171679)及[勘误](https://doi.org/10.1137/21M1399221)；[Albicker 与 Griesmaier，2023](https://doi.org/10.3934/ipi.2022032) | 对散射算子的有限维例外子空间作单调性比较可识别支撑。 | 本文的负空间位于内部电流，数据是有限噪声矩阵。输出是整域峰值假设与条件电流下界，未实现任意区域支撑定位。 |
| [Chen，2010](https://doi.org/10.1109/TGRS.2009.2025122)；[Zhong 与 Chen，2011](https://doi.org/10.1109/TAP.2010.2103027) | SOM 和 FFT-TSOM 对可见与不易观测的电流分解后反演材料。 | 对被测试的峰值类，可从数据判断某些状态模式是否允许在重建中完全删去；尚未证明将此信息用于迭代能提高材料图像质量。 |
| [Alberti 与 Santacesaria，2019](https://doi.org/10.1017/fms.2019.31)及[2022](https://doi.org/10.1007/s00205-021-01718-4) | 在指定先验和测量条件下可以得到有限观测的唯一性与稳定性。 | 在事先公开的整个材料盒内给出一次有噪观测能否排除某个峰值的具体数值；没有替代全域反演稳定性定理。 |
| [Bucci 与 Franceschetti，1987](https://doi.org/10.1109/TAP.1987.1144024)；[Ponge，2023，定理 6.12](https://doi.org/10.4171/JNCG/509) | 远场角向带宽有有效尺度。局域化负阶算子的有符号特征值计数服从 Weyl 渐近。 | 依给定二维体积分核导出固定频率、固定域、高对比度时的系数。外部角向尺度与内部面积尺度描述不同事情，不足以推断变频或有限网格必有特定拐点。 |

这些对照支持有范围的原创性判断。新意主要在可执行的物理比较和有双向证据的方法分离，文献检索本身不能保证绝对优先权。完整英文引用见[论文参考文献](references.tex)，卷页、文章号和原文入口保存在[文献元数据](reviews/reference_metadata.json)。
