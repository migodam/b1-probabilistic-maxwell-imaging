# 有损光学椭球的严格比较

固定有损合同下，0.6 m、12² 真实二维 TM 盘单元算例的两件独立材料，在已知损耗角正切 \(t=0.2\)、测试实部上限 \(u=1\) 时，接收椭球严格排除整个材料类。其中一件只用同一耗散椭球并把它乘任意非负标量加进残差二次式，始终无法排除同一个误差球。原生 96²、2 m 域上，接收椭球未能排除 2% 误差球。采用共同乘子的混合负空间矩阵帽，被同权完整耗散移位支配。

## 合同和输入

每像素 \(\chi_i=(1+\mathrm{i}t)x_i,\ 0\le x_i\le u\)。真空允许。活动像素满足 \(\operatorname{Im}\chi_i/|\chi_i|^2\ge\alpha=t/[(1+t^2)u]\)。令 \(R=\operatorname{Im}_H G\)、\(M=R+\alpha I\)、\(J_c=\mathrm{i}M^{-1}B/2\)、\(C_B=B^*M^{-1}B/4\)，则真实电流满足
\[
 (J-J_c)^*M(J-J_c)\preceq C_B.
\]
取 \(R_S=SM^{-1}S^*\)、\(F_c=SJ_c\)，接收椭球为 \(F_c+R_S^{1/2}V C_B^{1/2}\)、\(\|V\|_2\le1\)。下界大于 \(r\) 才排除整个材料类。椭球内的接收点只证明该外包可行。低峰材料控制经完整正演另验。

新有限网格含 0.6 m（\(0.8\lambda\)）和 1.25 m（约 \(1.67\lambda\)）两个域宽，各两件独立材料。原生使用六件已曝光 optfresh 实部材料和 v3 原样网格、32×32 全环。每个电尺寸的低峰对照取该组第一件实部的 \(1/8\)，不增加独立样本数。三个损耗角 \(0.01,0.05,0.2\) 共用冻结的复高斯方向，并对每个合同重新正演。2% 是相对于名义干净全波信号的范数比例，实际误差球还含 \(10^{-6}\|Y\|_F\) 余量。每个生成材料的全波数据均经区间验算进入相应误差球。有限网格用 Arb 区间定义精确离散 Bessel/Hankel 算子。原生沿用 v3 保存的精确表示 Fourier 乘子和收发数组，将辐射负谱限于 \(5.63972\times10^{-13}\) 的离散系数误差。所有候选盒的 \(M\) 保留严格正性。结论针对声明的离散算子。

## 同一耗散信息下的严格区分

loss_tm_01 在 \(t=0.2,\ u=1\) 时，2% 半径 \(r=0.056092164586853\)。接收椭球的严格下界 \(d/r\ge1.1791764\)。若以同一椭球推出的标量帽 \(\|J\|_2^2\le(\|J_c\|_2+\sqrt{\lambda_{\max}(C_B)/\alpha})^2\) 替换电流椭球，可验证帽内接收点的残差 \(\le0.53744r\)。

只用耗散约束且乘一个非负标量 \(\tau\) 时，消去自由电流所得小矩阵精确为
\[
 H_\tau=\tau\big[(Y-F_c)^*(R_S+\tau I)^{-1}(Y-F_c)-C_B\big].
\]
完整耗散移位的最强迹界为 \(\sqrt{\operatorname{tr}(H_\tau)_+}\)。括号内矩阵随 \(\tau\) 在 Loewner 序下降；区间 \([a,b]\) 的平方上界为 \(b\) 乘括号在 \(a\) 的正谱迹。Arb 用 101 个区间覆盖 \(0\le\tau<6.706761\)，其后可证没有正谱。所有 \(\tau\) 的严格距离上界 0.05602067794452884 小于 \(r\)。两条路线所用的物理信息相同。另加实部扇区的完整移位属于保留更多物理约束的对照，也能排除这个球。

同一 loss_tm_01 在 \(u=1.25,\ t=.2\) 时，实部扇区加完整耗散项的严格 \(d/r\ge1.2843972\)。最强已测被动扇区和固定相位等式候选分别约 \(0.5273r\)、\(0.8660r\)。单独接收椭球数值约 \(0.663r\)。该比较限于测试乘子。1.25 m 有限网格在 \(u=1,\ t=.2\) 的两件目标接收椭球严格上界低于 \(0.151r\)、\(0.084r\)，扇区对第二件仍严格排除。低峰材料的实部峰值低于全部试验上限，其完整正演进入误差球。


### 用源方向各自的乘子

将标量乘子扩展为 \(\Lambda\succeq0\)。对任意正交基 \(\{v_j\}\) 和 \(\Lambda=\sum_j\tau_jv_jv_j^*\)，\(\tau_j\ge0\)，接收椭球的平方距离至少为 \(\sum_j v_j^*H_{\tau_j}v_j\)。接收二次规划可严格可行时，对所有 \(\Lambda\) 的最大值等于精确平方距离。简单实现固定基、独立优化每个 \(\tau_j\)。令 \(R_S=U\mathrm{diag}(\rho_i)U^*\)、\(D=Y-F_c\)，该单方向目标的导数是
\[
 \sum_i \rho_i |(U^*Dv_j)_i|^2/(\rho_i+\tau_j)^2-v_j^*C_Bv_j .
\]
导数单调下降，可用一维二分；在零点处导数非正的方向价格取零。共享耗散 Gram 构造的成本相同。

第一件有限网格的同一正例 \(t=.2,u=1\) 中，\(D\) 的右奇异向量作为固定基给出严格 \(1.14159295r\)；按最佳共同标量候选 \(H_\tau\) 的特征向量定基，严格达到 \(1.16425935r\)。直接用入射端口独立定价只得到 \(0.57350793r\)。最后的对照显示，允许方向各自选乘子之外，选择哪些相干方向也有影响。这件物体的右奇异基二分步骤耗 0.878 毫秒 CPU，多个候选源基共享的预处理为 0.840 毫秒。共同标量候选搜索另耗 11.627 毫秒。接收椭球 FISTA 到达 2500 次迭代上限，用 0.319 CPU 秒产生提案。上述是测试机上的单例 CPU 费用，三条路线共享同一离线耗散 Gram。本例的最快严格正结果不依赖标量候选搜索。第二件同尺寸对象在两个数据基上的严格下界分别为 \(1.10601947r\) 和 \(1.22075458r\)，完整接收椭球下界为 \(1.23174028r\)。\(t=.05,u=.75\) 的近阈值正例上，共同价特征基也达到严格 \(1.01323652r\)。在 92 段区间上独立检查全部共同权重，得到严格上端 \(0.80975r\)。[全标量计算](finite_0_weak_loss_all_prices.json)对数值源基用极分解的正交因子作精确见证，Arb 有界扣除正交偏差。

## 共同乘子的混合定向帽

旧二次式写作
\[
 q(J)=H+(J-J_0)^*K_+(J-J_0)-[W_c(J-J_0)]^* W_c(J-J_0)-[W_f(J-J_0)]^* W_f(J-J_0).
\]
令 \(W_f\) 有 \(m\) 行，\(\Gamma_c=W_c M^{-1}W_c^*\)，\(Z_c=W_c(J_c-J_0)\)。任何 \(\tau>\lambda_{\max}(\Gamma_c)\) 都满足
\[
 \tau(J-J_c)^*M(J-J_c)-[W_c(J-J_0)]^*W_c(J-J_0)
 \succeq-\tau Z_c^*(\tau I-\Gamma_c)^{-1}Z_c.
\]
所以对所有自由 \(J\)，完整加入耗散二次式后的点态下界至少为
\[
 H-\big[\tau C_B+\tau Z_c^*(\tau I-\Gamma_c)^{-1}Z_c\big]
 -[W_f(J-J_0)]^*W_f(J-J_0).
\]
最后负项至多秩 \(m\)。每个完整移位自由 Gram 上图的可行点都满足右侧混合谱尾。完整移位的惯性公式在非奇异点恰为该自由上图的最优值，因而支配混合谱尾。移位矩阵负惯性也至多 \(m\)。若移位恰好奇异，可以右侧非奇异参数及连续的矩阵帽逼近；正定 \(M\) 使奇异参数孤立。该结论涵盖任意合法的旧权重及受控行分解，允许混合矩阵帽在低成本近似中使用。多个源方向各自取更紧的预算或非凸联合优化，仍有独立研究空间。

精确四单元被动互易模型取 \(G=\mathrm{diag}(\mathrm{i}/10,\mathrm{i}/10,25/26+2,25/26+1/100)\)，两个发收口为前两坐标，生成实部为 \((2,2,0,0)\)，\(u=1,t=1/5\)。旧惯性和全部受控的共同矩阵帽给零。保留大负方向为自由，控制小负方向，\(\tau=3/50\) 的下界为 \(0.85876678>r=0.5\)，同权完整移位达到 \(0.88993816\)。纯接收椭球有残差 \(\le0.45964311\) 的点。有理数脚本验证各平方量。该代数对照阐明机制边界。有限 TM 试验未发现能改变排除结果的共同参数混合谱尾。

## 原生 96²

六件高峰值原生材料和一件配对低峰对照使用 32 发32收，共 21 份分别正演生成、按物体配对的读数，全部见证进入误差球。数值接收椭球在所有试验上限 \(u=.75,1,1.25,1.5,2,3\) 都低于半径。最紧的 \(u=.75\) 椭球内接收点另用 Arb 验算，按上限单调性覆盖更宽材料盒。高峰值六件在最紧上限的接收距离严格上端点，按三个损耗角依次最大为 \(0.39480r,0.38317r,0.39085r\)。低峰控制的对应最大值为 \(0.45583r\)。旧被动扇区、完整耗散移位和已知相位等式的原生 Fourier 子空间筛选，在高上限 \(u\ge1\) 的最强提案小于 \(0.35r\)。108 个高峰值配对条件的不同源方向分别定价的筛选中，端口基最大为零，右奇异基最大 \(0.2281r\)，最佳共同价特征基最大 \(0.3894r\)，零价导数特征基最大 \(0.3692r\)。右奇异基样本 CPU 中位数 0.0022 秒，共同价特征基（含共同价搜索）0.0322 秒，FISTA 提案 1.194 秒。子空间提案的数字只负责挑选原生复核候选。\(t=.2,u=1\) 时两条代表性完整原生重放均小于半径。旧被动扇区在 optfresh_04 的严格距离上端点为 0.024044211557883，移位在 optfresh_02 的严格上端点为 0.027390403560468。对应的负惯性为 13 和 0。

## 复现

保留本目录相对研究目录的层级。Python 3.13 依赖 NumPy、SciPy、python-flint、threadpoolctl，作图另需 Matplotlib。在本目录运行：

~~~text
python run.py finite
python run.py native
python verify.py finite_0
python verify.py finite_1
python verify.py native
python finite_states.py
python pure_shift.py
python directional.py
python exact_control.py
python native_states.py
python native_states.py --replay --focus
python plot.py
~~~

输入 NPZ 含材料、带噪复测量、数值对偶提案。区间 JSON 含一侧回执、输入可行见证、定量误差和实际成本。主筛选也记载最大内存及迭代数。
