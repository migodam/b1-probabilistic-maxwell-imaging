# 基线复现与错题实证

**最需要修正的原文误读是停机量：NIE2016 与 CIE2019 都对逐源相对系数变化平方的平均值开方。CIE2019 原文的门是开方后小于 10⁻³，对应平方量小于 10⁻⁶；历史 `PAPER_CONTRACTS.json` 把它写成平方量门 10⁻³，不能再称原文规则。** 实际调用链却必须另查：R8 最终小型三维 Fourier-PR 对照固定执行 240 次更新，没有调用这个系数停机门，因而不能将它的材料误差归因于该误读。R8 二维 Foam 早期 v1/v2 的同类误用则已有明确修正，最终 v3 的阶段平方门为 10⁻⁴/10⁻⁶/10⁻⁶。

本次逐案复算还确认：R13 后续 A+ 已补齐同一批 48 对象，平均及共同实际 CPU 前缀上的材料收益确实保留；旧 U11 的 Mac/XINAN 同名结果采用不同阶段和 DPCS 秩；SRAP 主半环的全图误差改善不能等同于目标内部或拓扑恢复。下面逐条给出主张、偏差方向、修正状态和下次可执行办法。历史数组、源码和回执均未覆盖，没有新增物理实验。

## E01　平方停机量与开方停机量：2019 原文误读

**主张。** 令

**q** = (1/p) Σₛ ‖Δγₛ‖₂² / ‖γₛ,old‖₂²，**δ** = √q。

NIE2016 式(15)与 CIE2019 式(16)都使用右侧开方量。2016 首阶段 δ<.01、随后 δ<.001，等价于 q<10⁻⁴、10⁻⁶；2019 §3 的 δ<.001 等价于 q<10⁻⁶。直接核对了 [NIE2016 作者全文](https://www.researchgate.net/publication/296475773_A_New_Integral_Equation_Method_to_Solve_Highly_Nonlinear_Inverse_Scattering_Problems) §III.D.4/式(15)/§IV，以及 [CIE2019 出版社原文](https://www.mdpi.com/2313-433X/5/2/27) §3/式(16)。

**潜在偏差方向。** 若计算 q 却直接用 10⁻³ 截停，相当于允许 δ≈.03162，较原 .001 宽约 31.62 倍，可能提前结束当前阶段、改变 continuation 起点与费用。它可能让基线显得偏弱或偏快；没有配对结果时，不能指定材料误差一定变好或变坏。

**修正状况：已实锤错误，历史未覆盖。** R8 `delegated/paper_baselines/PAPER_CONTRACTS.json` 的 `CIE2019.coefficient_relative_change_squared_stop=.001` 与原文冲突；FBG-R3 基线审查中将平方量 `.001` 称原文类型的表述也须收紧。本次最初仅按冻结元数据理解该条，随后直接查原文发现并更正，当前复核 JSON 已同时保存“历史字段”和“原文正确转换”，不把旧字段作为原文证据。

**实际影响范围。** 已沿 `experiments/vector_pr240_fourier.py → src/vector_pr3d.py::optimize_pr` 核查 R8 `four_cubes` 的 `CIE_sourcewise` 与 `Dual_sourcewise`：固定 `range(outer=240)`，没有计算/比较系数 δ，也没有该循环的提前退出；两份原回执均有 cycle 0–239、每阶段 120 次及 `current_PR_steps=240`。其共同 corrector 均到 300 步上限，不是收敛证书。原 CIE 历史费用为 489 LU/47,460 物理 RHS，Dual 为 488 LU/47,340 RHS，本文只引用，没有再收费为新求解。较早 exact-current 16 次与 PR 48 次也属于固定 outer 的适配。SRAP 的 `vector/invert.py` 实际计算 `.mean().sqrt()` 并与 `.001` 比较，不受此元数据错误影响。

**下次可执行办法。** 标准化保存 `statistic=q或sqrt(q)`、逐源/全局聚合、分母时点、零分母保护、有效阈值和实际 stop reason。若要声称复现论文停机，再按同一输入/物理/预算/选择规则实现逐步 δ 和正确门、封存新旧 raw 后评分。现有 R8 三维路径没有逐步 γ 差值日志，不能事后推算何时过门；它也没有被错误门截停，因此本次不凭空制造“修正阈值改善成像”的实验。

## E02　R8 Foam v1/v2 的停机误用已经修正

**修正状况：已纠正错误。** v1/v2 partial 与失败费用保留、不入最终 v3 主表；记录说明修正决定早于这些分支的留出终点评估。修正没有让所有问题消失，最终仍有 corrector 达上限和材料尖峰。

**下次可执行办法。** 将每阶段 effective threshold 写入回执，不仅保存默认值；输出旧版到新版的配置差异和排除理由，禁止删除旧成本。若复用已有 v3，不为“验证阈值”重跑同一数据。

## E03　DPCS/Fourier：同一空间不等于同一 PR 算法

**主张。** 原结构为 `J=Jd+(I−VV*)Fγ`。DPCS 由接收谱/预定秩决定，Fourier 限制的是辅助电流，不是把材料变成数字 decoder。对 `(I−VV*)F` 做正交化而继续使用未经运输的欧氏系数 PR，会保留仿射族但改变系数度量、轨迹与系数停机量。依据 FBG-R3 `src/cie_tsom_baseline.py::fourier_apcs`、R8 `src/cie_fft.py`、`STATE_AND_COST_SEMANTICS.md` 与 `VECTOR3D_REPORT.md`。

**潜在偏差方向。** 把预条件后的路径当成原生 Fourier 路径，会错误归因恢复/速度变化；把 Fourier 列数直接当独立秩，会夸大自由度。固定 DPCS 在有限孔径还可能锁住被小奇异值放大的噪声，不能仅按同一秩号比较。

**修正状况：有意适配与已披露修正。** R8 初期三维使用正交 range；最终 240-cycle 对照保留 projected IDFT 原坐标。FBG 的小 4×4 校准里两级 Fourier 实际 APCS 都只有 4 维，不能说发生了容量扩张。需要区分完整 current 的复分量、冗余系数和独立实自由度。

**下次可执行办法。** 每阶段记录 DPCS 规则及实际秩、Fourier 列数、投影后秩/未知原因、坐标度量。改变截断时让两臂共用新截断，再评价材料，不能只给候选改善表示而继续用旧基线。

## E04　逐源 PR、global PR 与双 β 不可混名

**主张。** 逐源 PR/线步按 source 列分别计算；global 只有一个 PR 系数和线步。相应停止量 `mean(||Δγ_s||²/||γ_s||²)` 与 `||ΔΓ||²/||Γ||²` 一般不同。双 β 的 current/material 更新对应不同状态度量，不是同一个标量目标的单调块下降。R8 `src/paper_cie_fft.py` 的 `sourcewise` 分支、R6 `src/benchmark_solver.py::arm_config` 和 R13 `BASELINE_AUDIT.md` 可直接核对。

**潜在偏差方向。** sourcewise→global 与材料 readout 同时变化，会把 current 耦合的收益全记给 readout；同数值门也不提供同停机语义。`global_dual` 是 global-PR Dual-CIE，`physical_globaldual` 才是另一条原物理目标路径。

**修正状况：有意适配。** R8/R13 已分列命名。R13 同 16 的 global-Dual 参考保留了 0045 仍错而 A+ 恢复的实际反例，说明该例不能仅用 global current 解释；控制仅 16 件，不能外推全 48 的独立因果比例。

**下次可执行办法。** method ID 包含 PR 耦合、βcurrent/βmaterial、坐标及重置规则；需要拆因果时只改其中一项，保持历史和共同 corrector。没有完整旧 PR 记忆时只能叫合法重启，不能称精确续接旧动力学。

## E05　PRIORS：共同 prior、可行域和训练先验分别记录

**主张。** 二维常用目标为归一化数据损失加材料 smooth/TV，R8 `src/paper_physics.py::make_model` 明确：普通 CIE 族权重各 10⁻⁴，独立 `paper_nie/paper_lsie` 为零；对应 Regularizer 是差分能量均值与平滑 TV 均值，epsilon=.01。三维另用 smooth/L2；NN 训练分布又是额外先验。仅说“同 prior”不能抹掉这些合同差异。

**潜在偏差方向。** 普通点式 modified-contrast LS 不是加空间 prior 后完整材料子问题的最小点；对 r 加 ridge 又改变了对 m 的 prior。不同数据归一化、实/复材料、box、训练初值或多频平均都会改变有效 prior 比例。低范数 Gaussian latent 也不等于所有合法 decoder 真值具有典型先验概率。

**修正状况：有意适配，须逐臂标注。** FBG/R8 带 prior 的读出采用 bounded 内层优化；A+ 的有限候选/坐标更新比较实际完整辅助损失，不能称精确全局最小。R8 独立 NIE 无额外 prior，与带 prior 六臂不是单因素方程比较。NN 保留训练/验证生成与训练费用，不能称同测量就无额外信息。

**下次可执行办法。** 回执列出 data loss 系数、prior 函数/权重/网格差分归一化、实复范围与 box、初值来源、训练分布及费用。引用原论文结果时另给“论文合同”与“共同适配合同”两列，禁止跨列直接排名。

## E06　费用与充分运行：完成、截止、收敛分别判断

**主张。** 阶段完成或 `COMPLETE` 不等于物理梯度收敛。真实 CPU、task wall、队列历时、固定投影三角解/FFT/小系统、材料内循环、审计和共同 corrector 都是费用。R13 `BASELINE_AUDIT.md`、R8 `STATE_AND_COST_SEMANTICS.md`、SRAP `COST_LEDGER.md` 给出明确边界。

**潜在偏差方向。** 只比步数/LU会漏掉昂贵辅助工作；把内层 setup 再加到外层会双计；把并发 task wall 之和称总历时会夸大等待时间；把未测启动/失败记零会低估费用。wall 截断的坏终点不是已证实的严格局部极小。

**修正状况：已披露边界。** R13 i9 主 48：CIE 46/48、Dual 48/48 完成原 3000 步，G19 仅 1/48；这支持固定 CPU 表现，不能称充分运行的性能上限。同 16 的 M4 长预算另列，不与 i9 秒数硬拼。SRAP 二维 742 条轨迹原停止为 322 schedule complete/420 wall limit；约 5.366 CPU 小时只是二维反演小计，启动、生成、评分、开发和三维另计。

**下次可执行办法。** 同对象同机配对，保存有效截止、迟到原子操作和候选资格；主费用优先取外层唯一计时，内层作为分解。给出预算性能和完整日程参考两种答案，金额、电费、未测 overhead 保留 null 与原因。

### 光学乘子的搜索时间与摊销

单源十六区的 91.93–158.22 秒来自论文一的两件物体联合搜索及证明。把它用作每个物体、每份观测的固定认证费用会放大神经推理的提速。权重不变时，原生几何证明和收发响应可以跨物体复用。比较提议方法时，应分别报告冷启动、几何准备、逐观测提议与求证，并只用相同物体、数据、门槛及严格结论比较速度。一组权重的证书为零只表示这组权重给不出排除证据。[同数据的独立冷启动和完整账本](../z_alg_neural_dual_pilot/index.html)

### 光学惯性排除的三个不同上限

固定原生离散模型时，状态负惯性超过发射数会耗尽源谱。发射数超过负惯性只提供可用位置，剩下的正特征值仍需使距离超过实际半径。在 optfresh 的六件全环材料上，24 发和 32 发达到同样的 0.75 排除集合，32 发 32 收在上限 1 的最强筛选提案仅达到半径的 0.301 倍。此处的 \(2ka\approx23.7\) 描述角向带宽，32 列实际仍满秩。有限权重的距离上界不能充当某个低峰材料的可行见证。相同数据的非负 Born 模型、峰值受限的全波模型和门控后的具体反演程序需分别验收。 [阵列配对数据](../z_alg_optical_inertia/physical_revision/array/ARRAY_SCAN_ZH.md) · [Born 对照](../z_alg_optical_inertia/physical_revision/born/REPORT.md) · [反演对照](../z_alg_optical_inertia/physical_revision/inversion/RESULTS_ZH.md)

### 有损合同比较与负方向矩阵帽

**物理合同。** 固定损耗角正切时，只有活动材料 \(\chi=(1+\mathrm{i}t)x\)、\(0<x\le u\) 提供耗散比下界 \(\operatorname{Im}\chi/|\chi|^2\ge t/[(1+t^2)u]\)。真空仍允许。允许活动像素无损的合同缺少这个严格正下界，不能搬用有损椭球。18 个原生高峰读数沿用六件 optfresh 已曝光实部和几何，三个损耗角各用新的有损全波响应；四件有限网格新生成材料与这些对象分开计。[冻结材料和噪声合同](../z_alg_optical_inertia/ip_unified/numerics/loss/FREEZE.md)

**等信息比较。** 在 0.6 m 的二维 TM 例中，一件固定有损材料在 \(t=0.2,u=1\) 的接收椭球下界大于 \(1.17917r\)，同一耗散预算下所有共同非负标量乘子的上界小于 \(0.99873r\)。给相干源方向分别选乘子后，两个独立对象的严格下界均可超过半径。保留实部扇区再移位的对照额外用了扇区约束。只用一个共同参数控制部分负方向的矩阵帽，由同参数完整耗散移位支配。这个支配结论不适用于任意数据选定的多个源乘子。[同合同证据、完整移位支配证明与复算](../z_alg_optical_inertia/ip_unified/numerics/loss/REPORT_ZH.md)

**原生限制。** 原生 96² 的六个高峰材料在最紧试验上限 \(u=.75\) 时，严格接收椭球距离上端都低于 \(0.395r\)，更宽盒的接收椭球同样不能排除。此上端见证属于接收松弛。真正的低峰材料可行性由完整原生正演及其单侧误差界另判。无损的独立低峰盘只在它自己的观测球中核验，不能替代六件冻结对象。大域低上限拟合所需的负空间电流正下界对六件均成立，其前提是对应上限盒内存在符合该观测球的物理解。[原生接收区间](../z_alg_optical_inertia/ip_unified/numerics/loss/native_verified.json) · [真实电流与盘体对照](../z_alg_optical_inertia/ip_unified/numerics/feasibility/hidden_current.md) · [条件性必要下界](../z_alg_optical_inertia/ip_unified/numerics/native/required_currents.json)
