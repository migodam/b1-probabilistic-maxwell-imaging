# 实验占用的磁盘如何结清

**开工给每个作业一个归属，结题保留下次要用的唯一证据，回收可重建的工作文件。** 数据和大包落在已挂载的外置盘或任务专用的远端目录。外置盘临时脱机时，优先接续已经在远端的作业；等待原位置恢复后再归档。不要以同名目录在内置盘悄悄另建一份数据。

|资产|运行中如何放置|结题如何处理|
|---|---|---|
|采集原件、受限实测、冻结观测和独立真值|数据集登记持有者、来源和访问路径。评分方单独保管真值|保留原始文件、split、标定和可访问的恢复位置。数据许可证允许时沿原项目发布；限制共享时只发布取得方法及可合法分享的派生物|
|唯一的权重、失败端点、干预所需状态、首次代码和成本记录|与当轮预测、配置、种子和运行对应，避免只写进临时容器|保留实际可恢复的版本。重建成本很高或依赖缺失时，即使理论上能重跑也应留存|
|推送的仓库与 Release、大结果的远端镜像|决定哪份长期保留，记录压缩包的成员或拆卷顺序、必要依赖和恢复位置|已上传一个 ZIP 只说明那份传输完成。清本地包装前须知道源码、输入、失败状态和恢复说明各留在哪里；避免远端和本地同时删除最后一份|
|当轮可再生临时件|使用当前任务独占的暂存目录，为可清项登记具体保留副本或可执行的生成命令|先等作业退出、归档完成，再预览与清理。发生修改、属于另一个任务或含唯一脚本时保留|
|旧运行、旧包、旧工作树、共享缓存|只读盘点两端，分出当前活动作业、依赖、唯一恢复件和候选副本，消除父子路径重复计数|让所有者看到候选文件、大小、保留位置及预计收益后，在已明确批准的路径内处理。冻结源和老账本保持可追溯|

## 当轮暂存的实际用法

`scratch.py` 只管理它为**已经存在的本轮输出目录**新建的 `.maxwell-scratch`。以下例子中 `$run` 由实验负责人指向该轮目录；先运行实际生成或复制命令，再登记生成的具体文件。清理记录写在暂存区外的 `scratch-removed.jsonl`。

```bash
tool=research/experiment_handbook/scratch.py
python3 "$tool" init "$run"
python3 research/experiment_handbook/summarize_design.py --workspace . \
  --output "$run/.maxwell-scratch/design_cells.csv"
python3 "$tool" mark "$run" design_cells.csv \
  --copy-at research/experiment_handbook/results/design_cells.csv
python3 "$tool" clean "$run"
python3 "$tool" clean "$run" --apply
```

对于无需第二份保留副本的纯中间件，`mark` 也可用 `--rebuild '具体命令及其已保留输入'`。清理器只记录该说明，不替人执行或鉴定其可复现性。在 `--copy-at` 模式，实际回收时流式核对本次指定的两个普通文件。它不会扫描用户其他目录找重复件，不接管历史临时目录，也不递归删除目录。完整实验数据的来源、训练权重、唯一脚本和未登记件留在原处。[直接脚本](scratch.py)

## 历史空间如何决定

2026-11-21 的 Mac 外置盘与 XINAN 盘点列出 19 项互不重叠的历史包装副本。Mac 逻辑上限 7.99 GiB，XINAN 770.67 MiB。本轮的历史释放量两端均为 0。54 个已在远端清掉的旧包涉及本地恢复件；部分看似可删的运行目录还含唯一脚本。需要删除哪几项时，按当地原始路径逐项决定。完整机器清单、活动进程依据和恢复位置在本地 `communication/EXPERIMENT_STORAGE_INDEX.md`，公共手册保留机制及汇总。

估算时分别记卷实际可用空间、文件逻辑字节、可查到的分配块和候选互不重叠的上限。APFS 克隆、硬链接和快照会使逻辑大小高于实际可回收量。实际执行某次历史清理后，再记批准范围、成功/跳过文件、卷可用空间的前后变化与并发写入。单次共享预计算、Git 工作树、训练环境和持有唯一数据的本机不因“另一台也有同名目录”被整体移除。
