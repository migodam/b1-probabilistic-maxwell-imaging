# R8 实际使用的结构和边界

状态：本文件的代数属于 DERIVED / PROVED_UNDER_ASSUMPTIONS；性能判断另由已经完成的轨迹和封存后评分给出，不由公式推定。R7 Möbius/MM、Woodbury、Green 分解已冻结，不重复机器精度验证。

## 1. NN 改变起点，不改变 Maxwell 目标

沿用实 scalar-TM：J=X(Einc+GJ)，F(m)=S(I−XG)⁻¹XEinc。末端目标为 Phi=.5||F−Y||²/||Y||²+R(m)，R 与 box 在每个比较内固定。本轮沿用这个归一化目标，不能将它改称按测量 σ 白化的 Gaussian 负对数似然；噪声 discrepancy 单独报告。

这里二维J是CIE使用的相对contrast状态`J=mE`，即归一极化变量，不是以A/m²计量的物理电流。若恢复SI单位，在exp(−iωt)、背景相对介电εb的约定下，对比电流为`−iωε0εb J`。主组合成εb=1，长度按λ0归一，场与端口保留同一入射幅度约定；不把current范数、端口能量和材料范数的量纲混为一谈。实测频率与几何采用其原Hz/m合同。

令 T_Y 表示给定 PR 历史、材料读出、box、预算和 original-Maxwell corrector 的实际算法映射。普通与神经初始化分别是 T_Y(mconst) 和 T_Y(Nθ(features(Y)))。即使两者具有相同显式 R，后者仍使用了额外训练分布；不能据此声称无先验地增加观测信息。

监督平方损失倾向于条件均值。多解或弱可辨识时，它可能平均不同材料结构；条件均值既不必是小 Phi 的材料，也不必落在有利的优化区域。初值 Phi 的大小因此不能单独决定是否运行后续迭代。本轮直接运行所有已声明初值，再按相同原 Phi 选择已支付候选，最后独立评分。

若 F(m1)=F(m2)，任何只依赖同一 Y 的确定 NN 无法从信息上区分二者。训练分布能选择一种材料偏好，但不证明数据唯一性。初值更接近 GT、更快下降、到达新驻点和最终恢复四项分别统计。

## 2. 公开特征及费用

Born 对角 LS 特征为

b_i = sum_s conj(Einc_is) (S*Y)_is / [sum_r |S_ri|² sum_s |Einc_is|²]。

这是线性化的廉价物理特征，不作为强散射正演。接收 SVD 给 Jd=Vd Σd⁻¹ Ud*Y；令 Qd=Einc+GJd，构造 c_i=sum_s conj(Qd_is) Jd_is / sum_s |Qd_is|²，以及电流/总场相对能量。真实反演仍用完整 full-wave。网络仅接收这些特征、合法采集参数与坐标，不接收测试形状、support 或真 contrast。

对每源不同的 S_s，Born 分母改为 sum_s |Einc_is|² sum_r |(S_s)_ri|²，DPCS 逐源构造。接收伴随必须是每列 S_s*，不能用公共 S 截掉大多数实测通道来假装相同目标。固定预处理 SVD 和 Green 动作需要收费；虽无 LU，也不是免费。

一个有助于区分初始化与下游PR的现成结构是：**共同S、保留全部p列且采集元数据不变时，这些NN物理特征对右乘任意unitary源基变换不变。** 若E'=EU、Y'=YU，则Jd'=JdU、Qd'=QdU；Born分子、DPCS读出分子/分母及行能量都是行内积或行范数，右unitary保持它们。坐标、p与孔径标签不变，因此精确算术下确定性NN材料输出也不变。这里没有新的数值实验或原创不变量主张，只用已知Gram不变性定位差别：下游sourcewise PR若改变轨迹，不能自动归咎于这个池化初始化器。

该论证不包含p→k压缩、source-dependent接收mask、非unitary编码或重新定义源归一化。全局CIE也只有正确协变运输完整source metric时才能引用相关等变性；本轮sourcewise/global比较本身不等于又做了一次源基空实验。实测的逐源不同S_s不在上述共同S证明内。

## 3. 材料初值与合法辅助电流是两个实验

成熟表示为 J=Jd+U A，U=(I−VdVd*)F，F 是预定 Fourier 列。默认 NN 只改变 m0，仍保留 Jd 和零 APCS。额外联合初始化先计算 jphys(m0)，再解

A0=U†[jphys(m0)−Jd]。

这是同一仿射辅助族内的欧氏最小二乘投影，不能把任意物理电流直接塞入固定 DPCS。单次初值 full-wave 与已支付的初值评价复用，初始小 SVD 单独收费。后续所有 PR 历史仍以相同规则重置。

对任意 A，有

||jphys−Jd−UA||² ≥ ||Vd* jphys−Σd⁻¹Ud*Y||²。

因为 Vd*U=0。这个下界解释了为何物理正确的 NN 材料对应电流仍可能被含噪硬 DPCS 约束改变。它不保证联合初始化优于仅材料初始化。Atlas F-BI-020 已区分投影像和交集，本轮不将此投影结构主张为新数学。

更具体地，设 Pd=VdVd*、Pu=UU†，且 jp=jphys(m0)。投影位移的两个正交部分为

`δj = [Jd−Pd jp] + [Pu jp−(I−Pd)jp] = δjD + δjN`。

第一项为 `Vd Σd⁻¹ Ud*(Y−Sjp)`，由初始端口误差及接收奇异值共同控制；即使扩大到完整 APCS，它也不会消失。第二项来自当前 Fourier 容量，完整 APCS 时消失。物理本构缺陷不是电流 L2 位移本身，而是精确有限量 `(I−X0G)δj`。因此近似电流、端口和材料一致性是三个不同指标。

在无 prior、内点、实共享材料的普通读出中，令 `Qp=Einc+Gjp`。以每源公开权重 w 记，根处一阶读出变化为

`δm_i = Re sum_s w_s conj(Qp_is) [(I−X0G)δj]_is / sum_s w_s |Qp_is|²`。

此处的分母是总场能量；弱激发单元可把小本构扰动放大。它只是根处导数，有限投影需要重新计算 Q，且 box/prior/A+ 会改变读出。R3 已有根处 readout 导数及 β 独立性，本轮不是重复主张原创。R8 实际诊断重点是分解哪种投影误差占主导，以及它是否对应后续失败；未以该指标在线筛除初值。

### 3.1 保留物理 APCS 的固定仿射偏置

上述分解给出一个不增加优化未知量的接法。对已付费的初值物理电流 jp，固定

`Ja = Jd + (I−Pd)jp`，然后令 `J = Ja + U A`，`A0=0`。

Ja 是 jp 到完整硬 DPCS 仿射集合 `{J:Pd J=Jd}` 的欧氏正交投影。证法是任何可行 J−jp 的 Pd 分量都等于 Jd−Pd jp，正交补分量取零时达到最小范数。故初始位移只剩 δjD，原来的 Fourier 截断分量 δjN 被保留为固定偏置。偏置不随材料更新重算；每级仍只优化原来的 Fourier 系数，并沿用原 PR 重置和材料规则。最终完整 APCS 的可行电流集合相同，早期截断的仿射集合发生平移。

这属于**算法初始化/表示接线的修正**，不是新的 Maxwell 恒等式、观测信息或可优化材料自由度。必须计算一次固定 Pd jp 投影并存储 N×s 个复数；jp 已来自初值验收，因此没有新增全波 LU。相同结构也可以接普通 Dual-CIE，不能把所有收益都归给 A+。

尤其，删除 δjN 只保证初始电流欧氏距离不增，**不保证本构缺陷、Phi 或材料误差不增**。因为 `||B(δjD+δjN)||²` 中交叉项可能为负，B=I−X0G 不保持 Pd 与其补空间的正交性。纯代数反例取 `B=[[1,−3/4],[−3/4,1]]`，δjD=(1,0)、δjN=(0,1)：原缺陷范数为 sqrt(2)/4，去掉 δjN 后为5/4。这个二维矩阵反例只否定一般范数推论，不冒充具体 Maxwell 介质反例。实际效果仍须完整正演与轨迹检验。

本轮先在既有验证对象0、3上进行了8个固定对照，随后在尚未读取真值的全部42对象上冻结三种 NN 偏置接法（Dual、global A+、sourcewise A+），并保留原750项全部对照。新增126项是明确记录的机制扩展，不把开发诊断重新称为新盲测；后续不依测试评分修改偏置、网络或预算。另在其余6个既有验证对象上扩展24项，以检查负例。CS-Net 等工作已有学习非辐射电流再接 SOM/TSOM 的直接先例；这里可主张的贡献须落在具体投影损失诊断、简单修复及同成本证据上。

## 4. A+ 与 current 策略的严格位置

固定电流下继承 R7：RA=β(I+Dz Goff)(J−DzH)，z_i=m_i/[1+(β−Gii)m_i]，H_i=Q_i+(β−Gii)J_i。Goff 的零对角使单坐标条件残差对 z_i 仿射。状态二次驻点、端点、旧值经原 prior-MM 上界和完整原 loss 接受；只保证固定电流材料块的相应非增，不保证原 Phi 或材料误差非增。

R8 sourcewise A+ 仅把同一材料读出接入 sourcewise PR；global A+ 接入 global PR。两者共享 βcurrent/βmaterial、Fourier 空间、DPCS、prior 和 corrector。四格消融 sourcewise/global × ordinary/A+ 才能定位材料传播的独立增量。

若 NN 初值在 original-Phi 候选选择中优于所有辅助阶段端点，则 NN+CIE/A+ 的共同 corrector 实际从 NN 初值出发；与 NN+直接物理优化得到同一终点时，不能将其归功于 CIE 或 A+。必须报告被选 stage、辅助成本及直接物理控制。这也是新增全测试集 NN+physical 与解析初值+physical 对照的原因。

反过来，若辅助端点在校正前 Phi 更低，也不能推出它经相同校正映射 C 后更好。即使 C 对每个输入都下降，`Phi(a)<Phi(b)` 与 `Phi(C(a))>Phi(C(b))` 可以同时成立。这是优化映射不保持初始目标排序，而非额外物理信息。八个验证对象中出现 NN 直接校正良好、辅助选择 stage3 后失败的实际例子，故本轮冻结“校正后保留两支路”的公开 Phi 组合及等候选数均匀初始化控制。两支路全部收费；标准组合不主张新全局化定理，且较低终端 Phi 仍不能保证正确材料。

## 5. 三维的实标量与复材料资格

全矢量 dyadic Green 的各向同性自项为 sI3 时，单个体素的实 scalar contrast 仍共享 b=β−s、z=m/(1+bm)。三个极化分量和所有源叠成一个向量，零体素对角块 Goff 保证条件 RA=C+zD；求和后仍为 q|z|²+2Re(hz)+const，实 m 的状态驻点分子至多二次。因此实 scalar 3D A+ 可以从同一条件结构推导，不能以“把二维变量改名”替代实际矢量算子。

复 scalar m 的可行域是二维被动区域，z 不再沿实材料圆弧。实/虚 box 下可用合法的二维优化或分别推导坐标更新；本轮复材料臂采用明确的约束复材料读出，没有将实圆弧算法不加证明地移植。一般各向异性张量自项/未知磁性不在这个论证内。

部分填充单元的电静力极化率保持映射 χeff=3fχ/[3+(1−f)χ] 使 χeff/(χeff+3)=fχ/(χ+3)，属于标准 Maxwell–Garnett/Clausius–Mossotti 关系。它解释体积分数线性缩放 χ 与线性缩放极化率不同，不是新混合定理；是否改善 Mie 误差由独立数值参考决定，也不等于严格连续误差上界。

## 6. 实测、线性求解与不能省略的边界

空目标数据拟合的 source-free multipole 场满足成像域内背景 Helmholtz 方程，但有限角度继续延拓可能病态，接收喇叭响应也可能混入拟合。保留空场测量误差小不证明目标散射模型正确，必须另做已知参考物与独立电磁解检查。训练/保留散射通道不能用于重新拟合测试目标专属 gain。

Fresnel的另一个实际边界是材料可行集。真空背景下空气对应χ=0；继承合成host任务的χ≥.02会使每个非零总场的空气cell带有无法关掉的极化电流J_i=χ_i E_i。`.02`数值很小不构成散射误差可忽略的依据：8GHz的.2m ROI宽约5.33λ，广布极化经完整resolvent传播，不能用局部contrast大小替代端口影响。已知有限响应式`ΔF=S(I−X_tG)⁻¹ΔX U_0`说明这种影响还依赖背景场、接收和多次散射；它不保证降低下界一定改善任意测量，更不保证材料唯一。

本轮同锚点、同prior、同校准只改下界的实际对照提供了端口影响证据（8GHz留出约.266→.136），但峰值未降低。这个实验修正的是错误的材料集合，不是额外神经机制，也没有使用像素GT去限制support。重新从共同初值比较算法时，所有材料读出与corrector必须同时采用合法air0，不能仅在最后clip到0后冒充同目标优化。

同频真实材料的不同生成/反演网格会产生额外模型误差。噪声 σ 不能覆盖尚未量化的几何/自项误差；高质量线性 GMRES/LU 残差也不能认证连续 Maxwell。求解失败必须记录实际动作和时间，不能用伪造的有限 objective/零梯度冒充已评价状态。

## 7. 原论文全自由材料空间为何需要正则化信息

这是维数与恒秩定理的已知后果在本轮合同上的应用，不主张新的Maxwell唯一性定理。

原150/64 Austria比较有4096个独立实材料参数，但单频20照明×40复端口只有800复/1600实观测。因此实化物理Jacobian的秩至多1600，线性化核维数至少2496。若在一个合法材料内点附近有限forward唯一适定、可微且Jacobian秩r局部恒定，恒秩定理给该点的局部等数据流形维数4096−r≥2496。更一般地，连续映射不能把4096维材料开集单射嵌入1600维数据空间，故不能对完整开材料类宣称同数据唯一恢复。

这些陈述**不证明特定Austria真值存在同box多解**：真值有大量air边界单元，活动约束、已知几何家族等可能改变局部可行维数；本轮没有计算其受约束纤维。150²生成与64²反演还不使用同一个forward，粗网格参考材料不必精确解释观测。它们也不能替代Z-ALG已构造的特定有限模型非置换多解证书。

实际意义是：辅助current限制、正则、训练分布或early stopping都可能承担材料选择作用。移除这些限制后把原物理residual继续压低，可能是在拟合噪声或离散误差，并不天然改善材料。R8原论文对象的长corrector确实出现更低residual、更高材料NRMSE及contrast峰值接近20（真contrast3）。这个观测支持检查正则化/模型误差，不能只把失败归因于初始化或A+读出，也不能从低residual宣布恢复。

24²主确认、三维和实测有不同数据维数与prior，不能把此4096→1600维数论证直接外推到它们。有限噪声下若多个已付费候选都满足同一实际观测的噪声球，应保留候选差异与训练prior语义；单个较低Phi候选仍不提供唯一性保证。

上述 NN warm start、SVD、投影、MM 和有效介质公式都有先例。潜在论文增量仅可来自具体 A+ 更新的适用边界、与初始化的可检验关系，以及公平总成本下的恢复证据，见 PRIOR_ART_AND_NOVELTY.md。
