# 读取散射数据后，能否更快证明材料峰值？

本目录检验从复散射读数中能否更快证明材料峰值。报告给出 28 件留出材料的原生物理核验、整条连续权重线的能力界，以及额外 16 件材料上固定权重与逐物体调整的配对结果。
