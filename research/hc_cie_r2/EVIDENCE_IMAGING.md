# 有限材料跃迁试验

**结果：局部有限响应到机器精度，两版都未救回困难材料。** 第二版比较五个历史共败对象的 20 个配对端点，精确双块平均 NRMSE 为 .53197，普通续跑 .53211，Born 双块 .53199，同预算随机双块 .53181。原有 7 个合格端点在各臂均保留，33 个初始未合格端点均没有新增通过。结论限于这批曝光材料、2 CPU 秒预算、固定 4×4 块及本次步幅。

本线检验从已保存的错误材料端点出发，以发射场、接收场和公开数据残差选择联合有限改动，能否在相同新增计算时间内恢复原有方法漏掉的材料。在线全程使用原来 576 个实材料自由度、原 VIE、原测量、原材料盒及原 smooth/TV。运动在小块上提名，后续可在全材料空间调整。

## 物理公式和比较

写当前材料为 \(m\)，原电流方程为 \(L_m j=D_mE_0\)，其中 \(L_m=I-D_mG\)，\(U=E_0+Gj\) 是同一个已求解的全场。材料改动 \(d\) 只支撑在 \(J\)。由相减得到 \(L_m(j'-j)=D_d(U+G(j'-j))\)。定义 \(T=S L_m^{-1}\)、\(K=G L_m^{-1}\)，则精确端口差为

\[
\Delta Y = T_{:,J}w_J,\qquad
w_J=(I-D_{d_J}K_{J,J})^{-1}D_{d_J}U_J.
\]

块内重复散射由小线性系统求和，发射和接收两侧都继承原全波材料端点。候选包含 \(4\times4\) 固定网格块，每块加或减 2 或 5，再截入相同 \([.02,20]\) 材料盒。两个旧曝光弯条也使用此步幅。提名允许改变整个块，后续全空间优化允许破除块边界。结构约束只有提名时的块支撑，目标函数没有新增惩罚或先验。

对于两个块，先以单块签名 \(\Delta Y_i,\Delta Y_j\) 按 \(\|Y(m)-Y_{\mathrm{obs}}+\Delta Y_i+\Delta Y_j\|^2/(2\|Y_{\mathrm{obs}}\|^2)\) 排序，并加各自的原 prior 增量。其中交项 \(\operatorname{Re}\langle\Delta Y_i,\Delta Y_j\rangle/\|Y_{\mathrm{obs}}\|^2\) 区分相消和相长。该排序仅近似双块互散射及矩形边界处的 prior 交项。第二版增加“精确双块”，在有限签名最好的 48 个双块中用上式对联合支撑重算原 \(\Phi\)。局部系统最多为 32 阶。所有提名臂送出 12 个候选，候选都走独立的全 \(576\) 阶原 Maxwell 正演。精确双块的 48 次额外小系统另计，并占用同一 CPU 前缀。

|臂|进入共同原 Maxwell 抛光之前|
|---|---|
|续跑|从原保存端点重新初始化 L-BFGS-B 内存|
|普通重启|从原公开初始化出发，候选池仍包含经原正演审计的端点|
|单块|以单块有限精确端口响应排序|
|随机双块|从同一双块候选集合用冻结种子等概率提名，并按原正演结果选择跳点|
|Born 双块| 用冻结端点的一阶端口响应 \(T_{:,J}D_dU_J\) 排序|
|有限签名双块|各块响应精确求和，再以残差与端口交项排序|
|精确双块（第二版）|前 48 个有限签名提名重算原联合分式响应和原 prior|

所有抛光使用历史 R13 corrector 的 L-BFGS-B 接口和容差。各臂按相同 \(\Phi=.5\|Y(m)-Y_{\mathrm{obs}}\|^2/\|Y_{\mathrm{obs}}\|^2+R(m)\) 取最低已合法审计候选。旧起点只有已保存材料及端口，续跑重新建立局部优化器状态。公共 prior 为 smooth/TV 各 \(10^{-4}\)，TV \(\epsilon=.01\)，差分归一化宽度 \(19.5\)。

第一版仅在原 CIE 保存端点运行。新跳点先要比端点的 \(\Phi\) 低才参与抛光。只看公开端口残差时，0007、0016 的有限签名提名都未过该规则。第二版在打开材料真值前定下：保留原端点，同时让所有提名臂从本臂最好已审计跳点启动抛光，即使这个跳点的 \(\Phi\) 高于端点。增加精确双块消融，并在同材料的 Dual-CIE、A+ 与 G19 端点独立重复。比较的是固定 \(G\) 的端点局部有理响应，Born 对照提供了有限响应的消融，未形成全域固定曲率 \(\Gamma\) 的独立信息对照。

## 复现

在原工作区根目录运行。历史 R13、R6 的 `DATA_CONTRACT.md` 和 `REPRODUCE.md` 提供公开观测、算子及材料端点恢复入口。运行器直接读取这些原文件。所有在线运行写到新目录。下面示例两阶段先各自封存，再打开独立离线评分器。

```bash
PY=Gaussian/.venv_nn/bin/python
ROOT=research/hc_cie_r2
REPLAY=.artifacts/hc_cie_imaging_replay
$PY "$ROOT/src/imaging_run.py" --config "$ROOT/configs/imaging_v1.json" --out "$REPLAY/v1" --endpoint-index 0 --workers 2
$PY "$ROOT/src/imaging_run.py" --config "$ROOT/configs/imaging_v2.json" --out "$REPLAY/v2" --workers 2
$PY "$ROOT/src/imaging_score.py" --sealed "$REPLAY/v1" --out "$REPLAY/score_v1" --figures "$REPLAY/figures"
$PY "$ROOT/src/imaging_score.py" --sealed "$REPLAY/v2" --out "$REPLAY/score_v2" --figures "$REPLAY/figures"
```

每次原物理审计的材料列保存在 `PREDICTIONS.npz`，包括选定材料的复端口预测和原端点复端口。对应原 `D`、`R`、`Phi`、原物理残差/噪声半径、耗时、解算数及资格见 `TRACE.json`。候选选择索引在 `PREDICTION_SEAL.json`。材料评分、全图/前景/背景、连通分量和孔数、物理前缀与 Pareto 标识在 `score_v1` 和 `score_v2`。旧端点的已经花费时间另记，避免从不同设备的历史 CPU 秒推出本机加速。

历史依赖也可在同一解压根目录平铺。将 [输入路径清单](configs/imaging_history_inputs.json) 中相对路径放在该根下，设置 `HC_CIE_R2_INPUT_ROOT` 为根目录，再运行上面的命令。可自动使用之前的 R13/R6 工作树，亦可使用公共仓库的 `research/research_max_struct_r13` 和 `research/research_max_struct_r6`。实际在线依赖为两份继承物理源码、八个 R13 公共观测、两弯条的公开算子和带噪观测、与起点对应的保存端点。原端点的费用回执用于离线汇总。材料真值和历史评分注册仅由评分器读取。比对以保存的实际复测量为准。

同一批历史困难材料的独立广域诊断见 [原 Maxwell 材料负曲率](LANDSCAPE.md)。
