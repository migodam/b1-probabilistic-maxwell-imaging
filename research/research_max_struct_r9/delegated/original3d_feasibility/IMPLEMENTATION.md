# Original-scale implementation contract

The new implementation retains the original 3λ region, three offset radius-3λ source circles, 60 electric dipoles and 180 Cartesian receiver rows. Synthetic observations use a60³ grid and the inverse exposes every30³ real cell, with χ∈[0,4], zero air initialization, no added material regularization and equal relative data/current weights. This is an independent R1 CM+RR point-dipole DDA adaptation, not the authors' original cell-integrated implementation.

`configs/original_vector3d.json` was written before all new inverse runs. The primary paper's MathML Eq16 was independently verified: stopping is the square root of the mean source-relative coefficient change, below0.001. Undefined first-step zero denominators cannot trigger this stop. The exact Eq17 square-root material error is reserved for offline scoring after prediction sealing. The old flattened-text missing-radical error is recorded separately, with no inversions predating its correction.

The ordinary current step uses implicit P·IFFT, P=I−VrVr*, and its exact Hermitian adjoint, native orthonormal Fourier coefficients, PR+ directions, and a quadratic exact line step. MF6→10 transports existing Fourier frequencies and resets conjugacy. Orthonormal IFFT is a common scalar coordinate normalization across all arms; it is not APIC SVD whitening. DPCS retains receiver singular values≥0.1σmax using a180² receiver Gram eigensystem. The0.1 rule is an explicit noise-scale adaptation because the paper's exact L rule is unavailable.

The R9 vector A+ material proposal uses the same ordinary global current update as GlobalDual. Its readout uses disjoint2³ blocks, exact local off-diagonal DDA entries, and two sweeps of real Möbius-arc coordinate minimizations including admissible stationary roots, endpoints, and the incumbent. In addition it first proposes the ordinary CIE material value per block and accepts it only if the full fixed-current block A metric decreases. This additional seed proposal is recorded and costed; it is not claimed identical to the earlier R8 frozen A+ implementation. The final block metric is recomputed to guard against update roundoff. No dense material Hessian or full-Maxwell rank-one assumption is used.

Fine data generation may eliminate cells with prescribed χ=0 from GMRES unknown currents. This elimination is exact for that known synthetic material. It is prohibited in the inverse model. Inherited floating box fractions include tiny boundary values, so the active count is recorded as actually constructed rather than rounded to nominal cube volume. The full data-generation grid and physical extent remain unchanged.

The initial complete60³ FFT embedding was replaced by the active cells'44³ integer bounding box, padded to88³, while retaining original h=0.05, absolute coordinates, all19652 active currents, incident fields, receiver matrix and self term. This is an exact submatrix embedding because all exterior polarization currents vanish; it is not a44³-grid physical simulation and does not apply to the unrestricted inverse. A single full-versus-cropped Green action agreed to3.56e−16 relative error and reduced measured action CPU0.364→0.130s. Its complete2.062CPU-second cost is in `CROP_CHECK.json`. The original uncropped attempt was deliberately stopped after475.441CPU/546.093wall seconds. All costs and four completed RHS are retained under `generate_attempt1_uncropped_*`; their in-memory solutions could not be reused. Its interrupted-source GMRES callback count is unknown, while all actual Green actions and process CPU/wall remain charged. The restart checkpoints qualified source solutions and RHS in sealed storage and resumes only exact-matching material/active-index/RHS states. A separate FFT-worker probe showed no substantial gain and retained one worker; its2.151CPU-second cost is retained too.

Public observations contain noisy Y, scalar σ, expected noise radius and public domain/material bounds. Clean data and both grid truths are stored separately. Noise is new independent circular complex Gaussian noise with expected relative norm0.1, without rescaling the realized sample; it is explicitly distinct from the unspecified author noise implementation. Offline60³→30³ truth-response qualification is a single separate paid forward evaluation after public-data freezing, never an inverse input or grid selection.

The one required new-operator wiring check passed (see `RESULTS/original_vector3d/WIRING.json`): implicit adjoint8.34e−16, Green adjoint8.40e−16, current gradient relative error3.79e−10. It used no imaging solve. Its CPU/wall and FFT work are retained in `wire_COST.json`.

Run from the R9 worktree using the existing Gaussian Python environment. Each invocation sets all BLAS/OpenMP thread counts to1 before importing numerical libraries. The runner supports `generate`, `qualify-discretization`, `invert --arm NAME` and `offline-score`. Paid endpoints and predictions are retained at air and both stage boundaries; primary output is the final stage, with no GT choice and no added full-physics corrector. All GMRES RHS, failed attempts, iterations, physical residuals, setup arrays, peak RSS and CPU/wall are in per-mode cost receipts. Stage CAP is distinct from coefficient convergence.
