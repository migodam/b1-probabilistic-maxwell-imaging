# Full66 physics-supervised transport implementation

Implementation only. No fit or physical query has been launched by the worker. The parent owns release, the paid derivative preflight, experiment choice, KL derivation, and all scientific claims.

`src/p3r4/train_physics_transport.py` continues an existing explicit full66 spline or diagonal-Gaussian checkpoint. It preserves the raw-y or anchor-conditioned format, full66 output, frozen TRAIN statistics, optional fixed frame, anchor translation, and GN/random conditional-coordinate maps. It never accepts CFM numeric density as exact logq. Inference remains compatible with `load_density` / `load_anchor_density`; the refined checkpoint adds `refinement_contract` without changing its original format.

For a reparameterized current-density draw, the implementation evaluates exact algebraic `logq_x` with the actual network, TRAIN-normalizer, fixed-frame and conditional-map determinants. The training objective is the parent-specified inclusive NLL plus scheduled lambda times `Phi(x;y)+.5||x||²+logq_x`. No selected/corrected/resampled particle cloud is assigned the original density. The claimed exact representable optimum is a statement about the ideal objective; it does not establish calibration or attainable finite-fit performance.

The custom first-order autograd function copies only a physical microbatch of at most4 raw Gaussianized x vectors to CPU. For each serial point it calls unchanged `Target.evaluate(from_probit(x))` with `keep_fields=True`, then unchanged source-adjoint `Target.phi_gradient`, multiplying the two property columns by normal pdf(x_eta). It saves only the detached66-gradient vector for backward. Backward performs no oracle query. Immediate paid endpoints retain original current and field, while no in-memory Point/LU list is retained. Each forward is8RHS, each gradient8RHS; the service rejects a partial16RHS pair and clears receiver-transfer references after each point. This is a first-derivative bridge, not a second-order Maxwell operator.

Full likelihood/gradient always uses the **original complex128 observation**, read only from strict `OUT/inputs/online/<frozen-parent>.npz` containing observation/target_id/sigma. The release freezes directory identity and all1056 file byte/mtime identities. Loading checks target, noise, finite shape32x8, exact complex128 dtype, and that source-major float32 packing equals the existing NN joint y. The1056 cached Y arrays occupy4325376B, with no LU/current/GT cache. There is no fallback to unpacked float32 NN y. Condition features and TRAIN normalizers retain their pretrained values.

Each uniquely numbered `Book.jobdir/transport_queries/q*/BEFORE.npz` saves actual rawx66, original nativeY and nativeq **before** Full. AFTER records Phi, available gradient_x, endpoint reference, paid RHS and failure status. This preserves finite eta even if its floating-point CDF reaches0/1. Each reverse-training microbatch also saves actual current-model logq_x, rawx, prior energy, parent IDs, update/lambda and query indices before and after querying. Fixed validation microbatches have the same fail-safe record; every completed callback saves its actual32x4 raw draws/logq/components, and the common epsilon roster is retained. Failed fixed slots are never replaced. Point/cache release occurs even if persistence itself fails.
