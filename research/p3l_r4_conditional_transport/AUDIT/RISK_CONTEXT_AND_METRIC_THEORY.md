# 两个用于解释真实实验的数学边界

本页由主线程复核，先于新 locked 数据。结论是标准条件期望与坐标变换的应用，不作为新 Maxwell 定理。

## 局部图像模型为什么能从粗糙的全局特征受益？

材料损失使用实 Hilbert 内积 `Re(sum(conj(a)*b))/576`。令 C 为局部 CNN 实际看到的重建/物理特征 patch，D 为另一份仅由观测计算的粗糙全局材料统计。对理想条件均值，条件期望的正交性给出

`R(E[chi|C]) - R(E[chi|C,D]) = E ||E[chi|C,D]-E[chi|C]||_M^2 >= 0`。

有限训练的两个网络不一定实现理想条件均值，所以不保证实际收益；独立新 parent 的风险检验仍必需。若局部 patch C 不是整个观测的充分统计，D 即使单独重建很差，也可能为局部过渡相修正提供有用信息。

D 是 Y 的确定性计算，既没有增加测量信息，也不必是经过校准的 posterior moment。这解释了本轮必须加入普通 Gaussian 与直接 field-moment 控制的原因。如果这些便宜控制与 Flow 一样有效，不能把收益归因于 Flow 的概率正确性或 Maxwell 动态几何。

更不能用该恒等式证明某个实际网络等于真正 Bayes estimator。报告只称它为联合监督的材料风险动作。

## 有界 CFM 几何权重必须说明在哪个坐标中有界

原始 Gaussianized latent 为 x，现有网络训练标准化残差 r，并有 `x = center(y) + T r`。T 由已有 TRAIN normalizer/frame 确定；在本轮 coordinate-none 分支中不存在额外的状态相关坐标变换。

真实物理 Jacobian 在网络坐标中为 `J_r = J_x T`，其中 `J_x = J_q diag(dq/dx)`。用 J_r 的 SVD 构造

`W_r = I + 3 V diag(sigma_j^2/(1+sigma_j^2)) V^T`。

因此 `I <= W_r <= 4 I`。在原 x 坐标中等价度量是 `T^{-T} W_r T^{-1}`，它相对于原 baseline 度量 `T^{-T} T^{-1}` 的广义特征值落在[1,4]；不能把这个结果误写成原 x 的 Euclidean 特征值界。

若权重只依赖已观测的 y 及其确定性 online context，在给定 `(r_t,t,y)` 后是固定正定矩阵，则条件加权 velocity 平方损失的总体极小点仍是相应条件速度均值。这是有限容量的训练偏好，不是截断后验支持，也不是把噪声温度改成4倍。随机 frame 控制使用同一谱及固定正交旋转；所有66个速度分量保留。

本轮有界权重训练若没有独立概率或材料收益，应停止扩大；上述总体性质不保证有限网络训练成功。
