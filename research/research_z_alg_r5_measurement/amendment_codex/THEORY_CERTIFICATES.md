# Codex 修订：覆盖证书、临界点与可实施测量

这里给出本轮实际实现的充分条件及证据链。它们是标准代数、区间分析和测量设计工具在固定离散 Maxwell 结构上的组合，不是新的通用求根理论。

## 1. 对原离散系统建立精确坐标

单接收、k=2s 个实材料未知，固定 H∈C^(k×k), B∈C^(k×s), R∈C^(1×k)。输入 binary64 常数作为精确数；其后所有系数构造使用128位有向区间运算。定义 w=R(I−D_z H)^−1 D_z，则 wB=t，v=R+wH，w_i=z_i v_i。这里没有 Hermitian 转置。

选择可逆 s×s 行块 B_I，余下行 J。取 c=w_J，令 w_I=(t−c B_J)B_I^−1。于是 w=w0+cN 是整个仿射解空间的坐标，不依赖浮点 SVD 得到的近似零空间。B_I 的区间消元每个 pivot 必须排除零。W=[w0;N], V=[R+w0H;NH]。

将共轭 c 独立记为 d：F_i(c,d)=Σ_ab c̃_a d̃_b (W_ai conj(V_bi)−V_ai conj(W_bi))=0，c̃=(1,c), d̃=(1,d)。每个方程的浮点实正缩放仅改变单位，精确系数由缩放常数和区间运算包围。τ(c,d)=(conj(d),conj(c)) 保持零点集合。

## 2. 从局部根到整个材料 box 的覆盖

写 F=A(c)(1,d)^T。所有 (s+1)×(s+1) maximal minors 必须为零。它们次数至多 s+1。令 T 为所有次数恰为 s+1 单项式的系数块；在 k=2s 时它是方阵（s=2 为4×4，s=3 为15×15）。

若区间预条件检查 ||I−C_T T||<1 成立，则 T 可逆。模 minors 理想，每个 s+1 次单项式可写成≤s 次单项式线性组合。更高次乘积依次降次，故商向量空间由≤s 次单项式生成，维数至多 D=binom(2s,s)。这个结论同时排除了该 affine c 零点集的正维分量，不依赖浮点乘法矩阵是否精确对易。

如果另行认证 D 个复双线性根，且 c 投影框两两不交，就获得 D 个不同 minor 零点。上、下界相等：全部 affine c 零点已覆盖。**必须继续检查 d 恢复系数满列秩**：本实现对每个 c 框内的 A(c)[:,1:] 选择一个 s×s 子块做区间可逆性证明，排除同一个 c 上另有 d 或异常 fibre。首个开发版漏了此检查，已归档，不作为最终证书。

每根检查：

- Krawczyk K(X)⊂int(X)，且实部/虚部展开的最大行和收缩界<1；因此存在唯一复根。实现用 Σ(|Re M|+|Im M|) 上界，对应 R^(4s) 分量∞范数，不直接套用另一种复向量范数的常数。
- 如果框对 τ 不变，则唯一根必满足 d=conj(c)。若区间 d−conj(c) 排除0，则此 c 不可能对应真实材料；满列秩检查使该排除适用于整个 c fibre。
- 全部 v_i 的复区间排除0，才可恢复 z_i=w_i/v_i。τ 实性及 F=0 保证 z 为实数。区间判断其严格位于 [.5,30] 内或有坐标在外；边界/节点不清楚必须 UNKNOWN。
- 对 I−D_zH 做区间可逆性检查，排除清分母伪根。

任何有定义的原材料响应都映射到某个 affine c 零点。以上全部成功才声称给定 box 内所有 regular 实材料解覆盖。证书针对每个固定观测，**不是所有观测共同适用的统一 genericity 结论**。

12个冻结 case-arm 全部达到条件，名义 D=6/20 由实际证书兑现。它们是可复核的计算数学证明；实现用 mpmath.iv，并非已经由独立形式证明器或第三方软件复认证。

## 3. 一次新增源的全 fibre 分离结论

可实施源为外部线源权重 a，活动宿主场 b=B_dictionary a，h_a=w b。旧源组合 b∈span(B_old) 时，任何等旧数据的两根响应差严格为0。对可达源空间若每个根差对应的线性泛函非零，则有限个零超平面不能覆盖整个源空间：一般位置的一个源可区分有限根集。这是标准线性代数结论；功率及馈电限制必须另外满足。

本轮把完整覆盖的每个根框中 w 的区间传到 h_a，逐对计算复响应距离的严格下界 g。若旧数据精确、名义离散模型正确、真实材料在所声明 box 内，而新复观测的绝对误差小于 g/2，则所有候选误差圆盘互不相交；存在相容解时分支唯一。由于有覆盖，这个结论适用于整个声明材料 box 的**该旧数据 fibre**，不只是一份可能漏根的列表。

clean T0/T2/T3/T4 的冻结可行源 g 分别约 .004772363/.006661219/.001815220/.008564935。T4 noisy-center 的三根 g=.000229152，低于2(.0001+.00002)，即使把旧数据中心当精确值也不满足原合并误差标准。所有 noisy-center 结论都不能传递成旧数据也有噪声时的覆盖。

## 4. 为什么点根管在这里不是完整噪声答案

C(t) 对旧数据的实/虚分量是精确二次式；最高次 minor 块 T(t) 是仿射式，因为其唯一数据相关列是 b=0。把相关扰动先合并再预条件，T0 整个分量误差盒的加权收缩界降到 .370969<1。但20个独立简单根管均未通过统一包含检验。

随后对 T0 旧数据中心附近的真实材料进行了有界诊断，非 GT 选择：在 mcrit±1e−7 e_1 两端，实材料 Jacobian 行列式分别严格为负、正；整条线段上的 Maxwell 矩阵可逆，复观测误差上界均<.000102093<.00012。连续性保证线段内部存在 J_material 奇点，且它在声明的旧数据误差可行域内。

因此不能用“整个误差域上始终互异且 regular 的材料逆分支”假设来解释所有噪声可能性。这个障碍并非单纯区间过估计。**未认证 Whitney fold 的完整正规形/非退化二阶条件**；代码名字 fold 只是诊断标签，正式结论仅为 Jacobian 临界点存在。也没有证明新增源后仍不可辨识。

## 5. 修正源设计的实际优化问题

最大化 |d a|，约束 a*Qa≤1，||a||²≤16。若无约束功率匹配解违反馈电限制，不能直接把判别方向丢掉。本轮解 a∝(Q+λI)^−1 d*，用一维求根使两个约束同时饱和（本实例 λ>0）。Cauchy–Schwarz 对 Q+λI 给出 |d a|²≤d(Q+λI)^−1d* (1+16λ)，所得解达到此对偶界；这是标准 KKT/二次型工具。

分别用已覆盖根对差、临界点附近旧数据 J 的最弱材料方向建立 d。两者都只操作真实外部源 dictionary，没有任意指定 cell 内场。

在临界材料中心±1e−6 的六维小框内，对加一源的 J_aug 认证 ||I−C J_aug(X)||∞<1。对任意框内两点，积分平均 Jacobian 同样满足此界，故投影后的观测映射在该凸框内单射。pair/critical-mode 收缩界约 .06138/.06066。**这是一个小框内的 rank/单射结论，不是全部噪声可行域的唯一性。**

## 6. 完整物理状态和真正未知量

原宿主消元 m=m0+Pz 必须使用实际 cell 的坐标选择 P。J=J0+Uq，U=A0^−1P，q=(I−D_zH)^−1D_zB，H=P^TGU，B=P^T(Einc+GJ0)，R=SU。完整状态 n 与 k 不必相等。

H12 probe 用12个真实电磁状态，6个已知宿主 cell 与6个独立未知 cell。Q20认证的是浮点消元后 H/B/R/t 被视作精确数的模型，完整12维独立正演作浮点验收；未对消元舍入误差做区间传播。不要把这个较弱证书说成原12维离散矩阵的严格认证。Born偏离显著，仅作多次散射数值诊断，不是材料恢复证书。
