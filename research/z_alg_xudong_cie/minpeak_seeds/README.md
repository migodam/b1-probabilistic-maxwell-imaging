# 全孔径数据生成的两份初值

在原始观测 `optfresh_01__pw360_10x20__n02` 上，两种采样指标生成了可供后续原生求解器使用的材料初值。两份初值的 32² 完整 VIE 残差均高于同观测的零材料残差 4.5455232243。它们作为备用起点保存，未获得原生误差球内的可行材料。 [试算与费用回执](linear_sampling.json)

| 初值 | 常值内区对比度 | 32² 全 VIE 残差 |
|---|---:|---:|
| 双侧平滑 Picard | 0.75 | 4.9502347145 |
| 截断奇异空间投影 | 2.40 | 4.5740077717 |

计算只读公开 \(Y,S,B,G\) 和原扩大半径。对复矩阵 \(Y=U\Sigma V^*\)，左奇异空间用归一化的接收列 \(S_{:,i}\) 查询，右奇异空间用归一化的入射行共轭转置 \(B_{i,:}^*\) 查询。平滑指标是两个由 \(1/(\sigma_k^2+\beta^2)\) 加权的投影范数倒数的几何平均。截断指标采用保留奇异空间上的投影范数。此例的噪声阈值保留全部十个已测右方向，右侧投影因而为常量，截断定位来自接收侧。各指标平滑一个粗格后取前 28% 区域，保持 287 个粗格。每种区域分别在 0.75、1.5、2.4 和 3.2 四个常值上做完整离散正演，按粗网残差选出表内初值。

两份 NPZ 的 `m_coarse` 保存 32² 材料，`m_native` 保存逐格延拓至 96² 的材料，`m_seed` 保存该延拓在 24² 网格的面积平均。也保存同一粗格上的掩码和指标。重放执行 8 次 287 阶 LU、80 列物理右端，耗时约 0.11 秒。 [双侧平滑初值](optfresh_01__pw360_10x20__n02__smooth_picard.npz) · [截断初值](optfresh_01__pw360_10x20__n02__truncated_range.npz)
