# 原生有限格的候选区域剪枝

用同一材料盒内的所有共享电流作比较，证明某个区域假设不可能拟合观测。两份已公开开发观测各构造两个候选区域，前缀只读第 64 步 Dual-CIE 的材料和电流。候选选定后，在原生 96²、20 收 10 发的同一有限卷积模型上评分。每个正式轻型区域假设允许 4×4 分块中的一个方块有对比度 0–4，方块外为精确空气。规则还保留一个全域上限 20 的候选和一个全域上限 0.50 的对照。剪枝与未剪枝的算法必须执行同样的盒约束。 [阈值与配对开发回执](frozen_development.json)

| 观测及区域 | 声明半径 | 接收单侧严格下界 | 照明单侧严格下界 | 双侧严格下界 | 全状态复核下界 |
|---|---:|---:|---:|---:|---:|
| 01 半环 2%，按前缀排序 | 0.101327 | 0.527500 | 0 | **1.388934** | 3.003645 |
| 01 半环 2%，平移竞争者 | 0.101327 | 1.630877 | 0 | **2.563958** | 3.612082 |
| 004 半环 10%，按前缀排序 | 0.495069 | 2.217760 | 0 | **2.673584** | 3.728513 |
| 004 半环 10%，平移竞争者 | 0.495069 | 0.284157 | 0 | **0.993714** | 3.052030 |

两侧同时取弱方向时，四个区域假设均越过半径。只取接收弱方向时，004 的平移区域仍待判。只取照明弱方向时，四个下界都为零。全状态直接复核用同一原生子块及冻结乘子，给出更强下界，成本也更高。四区轻包络的开发负例仍保留。将四个方块内的上限设到 4，外部设为零或 .05，尝试的近似都耗尽可用照明。单块的 .05 背景容许 01 的平移分支得到一次严格排除，下界 .1499588，另三条未严格排除。 [单侧消融](ablation_development.json) · [完整四块对照](development.json) · [正背景对照](development_uniform_soft_one.json)

每个相干照明都受同一个局部能量上界。合并实扇区和光学式后，在一个 24² 原生方块上证明 \(A\succeq 0.008999999999975347 I\)。所有 16 个同尺寸平移方块复用同一 Green 子块。对给定方块，入射弱方向的 \(B_HW\) 限制可激发电流，接收弱方向的 \(V^*S_H\) 限制这些电流进入数据的量级，最后保留实测的 \(V^*YW\)。用原生矩阵与正误差上端复核两个方向的范数。对半径外的严格证书才调用 `PRUNE`。 [公式、模型扰动与误差半径](THEOREM.md)

## 可复算费用

重复回放里，全部 16 个平移位置共用的原生 Green 与 Cholesky 间隔首次约 1.1–1.7 秒，单块方向评分约 0.010–0.019 秒。冻住的直接复核用时约 1.49–1.55 秒每块。Paper 1 的全域 .50 控制使用一个已归档的有符号傅里叶型，半环冷启动墙钟 5.76 或 8.93 秒，重复数据评分约 0.8–1.1 毫秒。并行负载下的实际差异保留在两次回执中。四块试验的每条筛选约用 2.8–3 秒，全部保留。正背景 01 平移严格证明用了 13.97 秒。首次双侧试算已成功验收四条区间值，末尾 JSON 存储遇到 NumPy 整数格式错误，随后重新回放并完整存档。 [初次回执](fast_first.log) · [区间回执](fast_development.json) · [冷与复用口径](frozen_development.json)

在含 NumPy、SciPy、python-flint 和 threadpoolctl 的工程目录环境中，从本目录运行。所有命令使用公开已存观测和前缀。

```sh
python -B frozen_replay.py
python -B fast_replay.py
python -B ablation.py
```

中央 8×8 网格内取中央 6×6 个块的预定广域控制，在 48 个新公开观测上全部保留。全环与半环的受测傅里叶型最少负方向数分别为 49、54，超出十束照明的预算，所以每个同几何的剩余读数沿用这份与数据无关的筛选结果。18.24 CPU 秒包含两个几何的筛选与所有公开数据读取。后续真材料覆盖比例从单独的封存后评分得出。 [纯公开广域对照](holdout_public_broad.json)
