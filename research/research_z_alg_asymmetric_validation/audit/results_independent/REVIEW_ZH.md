# Z-ALG 保存结果独立复核

结论：**`PASS_SAVED_ARRAY_AUDIT`**。对已保存数组、逐目标报告和成本账本重新做乘法、范数、奇异值和行列式核对，未发现 E1/E2 已声明端点的质量标志与数组不一致，E4 已保存局部密度和积分汇总也一致。此结论保留以下边界：径向全路径的秩停止规则未由保存数据逐点验证；E2 延拓节点没有独立 NumPy 重解收据；区间证书只覆盖狭窄的固定 binary64 系数模型局部图。科学主张和最终 GO/NO-GO 由主线程决定。

账本快照截止 `seq=51558`，共 16 个 run，包含已完成的 70 位高精度复核 run。审阅没有重做高精度物理求解或区间包围计算；它们仍是原执行者的收据。本目录 `AUDIT.json` 是机器可读结论，CSV 保留逐目标和逐 run 数据，不把 3 个参考情境扩张成总体抽样。

## E2：搜索结果和报告修复

33 个已付费起点中 31 个达到完整固定标签响应质量阈值，仅发现 1 个合并根类。2 个不合格起点没有被当作排除域外根的证据。两个往返数据路径共 64 个保存节点，返回材料 RMS 分别为 9.18e-16 和 1.80e-15。没有建立全盒唯一性、有限覆盖数或非平凡 monodromy。

33 个 multistart 端点有新鲜独立 NumPy 解。延拓节点的执行代码使用新鲜 LU full forward 和 J，并未调用独立 NumPy 分支；本次乘法残差审阅也不创造新的独立重解收据。两类证据应分别标明。

## 区间图证书：严格限定固定 binary64 系数

静态审阅 `src/interval_chart.py` 的论证结构：先用 `B=I-RA` 的区间上界建立 Neumann 逆包围；显式累加一至八阶项并以 `||R|| d^9/(1-d)` 控制尾项；再在实材料 dependent box 上检查加权映入与压缩。近似逆 R 和 Rj 可作为任意预条件器，最终区间界检验其充分性。中心目标的 binary64 误差通过中心残差项保留，而没有被假定精确为零。半径最初由普通浮点数选取不影响后续针对这些固定半径重新建立的区间不等式。

独立检查终端输出的维度/分区、合法盒余量、映入比、压缩比和 Neumann 条件，未发现破坏上述固定系数局部论证的实现错误。这里**没有重跑区间运算**；状态是 `STATIC_ARGUMENT_AND_TERMINAL_OUTPUT_CONSISTENT`。

这些量仅支持所声明 dependent box 中、每个 free 值对应一个根的局部图结论。它们包围的是保存/执行所用 binary64 Green 系数和 binary64 target，**不是 Hankel 超越函数系数误差证书，不是连续 PDE 证书，不排除别的全局分支，也不提供条件概率的全域质量**。更早失败的较宽盒尝试仍被保留。

## E4：保存节点的一致性

legacy：新算的 32 阶结果对齐输入中缓存的 64 阶结果，缓存 64 子树与原输入一致。重新用保存标量计算 new32/cached64 和 new32 direct/quotient 差，均与收据一致。实际 RHS=10，闭式 equivalent=6164。没有新算 64 阶，也没有把历史缓存时间当新耗时。

local：4/6/8 阶分别保存 32/72/128 节点，总计 232 个配对节点。使用保存的 J、材料和 tangent 重算 `p/|det Jdep|`、`p*sqrt(det(T^T T))/prod(sigma(J))`，再重做积分加权，均与保存报告一致。局部密度质量约 99193.9512、材料事件概率约 0.5039523093；6→8 阶的质量相对变化约 1.12e-16、均值最大变化约 2.67e-15、事件变化约 2.23e-16。它们是数值收敛和两种同局部量表达的一致性证据。

这里积分半宽 **0.05**，大于 P0 已区间认证的 **0.00625**。因此不能把窄区间证书扩展成整个积分 tile 的覆盖证明。全局缺失质量仍为 **UNBOUNDED**，原始完整 noisy posterior 仍为 **NOT_COMPUTED**。local phase 付费 4427 超过 planning allocation 3500，但 planning 字段不是硬上限；应公开这项偏差，不能说逐阶段预算按原计划完成。保守总量和逐 run 硬上限均未超。
